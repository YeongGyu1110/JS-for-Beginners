# 목록과 표 (List & Table)

## 개요
웹 페이지를 만들다 보면 쇼핑몰의 상품 목록, 요리 레시피의 순서, 혹은 학생들의 성적표처럼 <b>여러 개의 데이터를 깔끔하게 나열하거나 정돈하여 보여주어야 할 때</b>가 많습니다. 단순히 문단(`<p>`)이나 줄바꿈(`<br>`)만으로 이 많은 데이터를 정리하기엔 한계가 있습니다.

본 문서에서는 연관된 항목들을 그룹지어 나열하는 **목록(List) 태그**와, 엑셀이나 스프레드시트처럼 데이터를 행과 열로 반듯하게 맞추어 보여주는 **표(Table) 태그**에 대해 학습합니다.

### 이 모듈에서 배울 내용
* 순서가 없는 목록(`<ul>`)과 순서가 있는 목록(`<ol>`), 그리고 목록 항목(`<li>`)
* 용어와 그에 대한 설명을 묶어주는 설명 목록(`<dl>`, `<dt>`, `<dd>`)
* 표를 구성하는 기본 필수 태그 (`<table>`, `<tr>`, `<th>`, `<td>`)
* 표의 구역을 의미론적으로 나누는 태그 (`<thead>`, `<tbody>`, `<tfoot>`)
* 셀을 가로세로로 병합하는 속성 (`colspan`, `rowspan`)

---

## 1. 목록

목록을 만들 때 가장 중요한 규칙은 <b>"목록의 전체 껍데기(ul, ol)"와 "목록 안의 각 항목(li)"을 세트로 사용해야 한다는 것</b>입니다. 항목(`<li>`)은 반드시 껍데기 태그 안에 자식으로 들어가야 합니다.

### 순서 없는 목록: `<ul>` (Unordered List)
순서가 중요하지 않은 항목들을 나열할 때 사용합니다. 예를 들어 장바구니 목록이나 웹사이트의 메뉴바를 만들 때 주로 쓰입니다. 브라우저는 기본적으로 항목 앞에 까만 점(Bullet)을 찍어줍니다.

```html
<h3>장보기 목록</h3>
<ul>
    <li>사과</li>
    <li>우유</li>
    <li>식빵</li>
</ul>
```

### 순서가 있는 목록: `<ol>` (Ordered List)
요리 레시피나 회원가입 절차처럼 순서가 반드시 지켜져야 하는 항목들을 나열할 때 사용합니다. 브라우저는 기본적으로 항목 앞에 1, 2, 3... 숫자를 자동으로 붙여줍니다.

```html
<h3>라면 끓이는 순서</h3>
<ol>
    <li>냄비에 물을 500ml 넣고 끓입니다.</li>
    <li>물이 끓으면 면과 스프를 넣습니다.</li>
    <li>3분간 더 끓인 후 맛있게 먹습니다.</li>
</ol>
```

> [!TIP]
> **목록 안에 목록 넣기 (중첩 목록)**\
> `<li>` 태그 안에는 단순히 텍스트뿐만 아니라, 또 다른 `<ul>`이나 `<ol>`을 넣어 하위 목록을 만들 수도 있습니다.
> ```html
> <ul>
>     <li>과일
>         <ul>
>             <li>사과</li>
>             <li>바나나</li>
>         </ul>
>     </li>
>     <li>채소</li>
> </ul>
> ```

## 2. 설명 목록 (dl, dt, dd)

일반적인 목록과 달리, <b>'용어(단어)'와 그에 대한 '설명'</b>을 한 쌍으로 묶어서 나열할 때 사용하는 특별한 목록입니다. 사전이나 Q&A(질문과 답변) 게시판을 만들 때 유용합니다.

* `<dl>` (Description List) : 설명 목록 전체를 감싸는 껍데기입니다.
* `<dt>` (Description Term) : 설명하고자 하는 '용어'나 '질문'을 적습니다.
* `<dd>` (Description Details) : 용어에 대한 상세 '설명'이나 '답변'을 적습니다. 브라우저는 기본적으로 `<dd>` 안의 텍스트를 약간 들여쓰기하여 보여줍니다.

```html
<dl>
    <dt>HTML</dt>
    <dd>웹 페이지의 구조와 뼈대를 만드는 마크업 언어입니다.</dd>
    
    <dt>웹 브라우저</dt>
    <dd>HTML 문서를 읽고 해석하여 화면에 그려주는 소프트웨어입니다.</dd>
</dl>
```

## 3. 표 만들기 (table, tr, th, td)

HTML에서 표(Table)를 만들 때는 엑셀처럼 칸을 먼저 그리는 것이 아니라, <b>"가로줄(행)을 먼저 하나 만들고, 그 줄 안에 들어갈 칸을 차례대로 채워 넣는 방식"</b>으로 코드를 작성해야 합니다.

1. **`<table>`**: 표 전체를 감싸는 가장 거대한 껍데기입니다.
2. **`<tr>` (Table Row)**: 표의 <b>가로줄(행)</b>을 하나 만듭니다.
3. **`<th>` (Table Header)**: 가로줄 안에 들어가는 **제목 칸**입니다. 브라우저는 이 칸의 글씨를 굵게 만들고 가운데 정렬해 줍니다.
4. **`<td>` (Table Data)**: 가로줄 안에 들어가는 **일반 데이터 칸**입니다.

아래 코드는 2개의 행(가로줄)을 가진 간단한 표를 만듭니다.

```html
<!-- border="1"은 표에 임시로 테두리를 긋는 속성입니다. -->
<table border="1">
    <!-- 첫 번째 가로줄 (보통 제목들을 넣습니다) -->
    <tr>
        <th>이름</th>
        <th>나이</th>
        <th>직업</th>
    </tr>
    
    <!-- 두 번째 가로줄 (실제 데이터를 넣습니다) -->
    <tr>
        <td>홍길동</td>
        <td>25</td>
        <td>개발자</td>
    </tr>
</table>
```

## 4. 의미론적 표 구조 (Semantic Table)

웹 페이지 레이아웃을 짤 때 `<header>`, `<main>`, `<footer>`를 썼던 것처럼, 표 안에서도 <b>머리(제목), 몸통(본문), 꼬리(요약/결과)</b> 영역을 의미론적으로 나누어 줄 수 있습니다.

데이터가 아주 많은 거대한 표를 만들 때 시각장애인용 리더기가 표의 구조를 쉽게 파악하게 해 주며, 화면 스크롤 시 제목 부분만 고정하는 등의 고급 기능을 구현할 때 반드시 필요한 구조입니다.

* **`<thead>`**: 표의 제목 열(보통 `<th>`들이 모인 줄)을 감쌉니다.
* **`<tbody>`**: 표의 실제 핵심 데이터들이 모인 줄들을 감쌉니다.
* **`<tfoot>`**: 표의 맨 아래쪽, 주로 총합이나 요약 정보가 담긴 줄을 감쌉니다.

```html
<table border="1">
    <thead>
        <tr>
            <th>과목</th>
            <th>점수</th>
        </tr>
    </thead>
    
    <tbody>
        <tr>
            <td>국어</td>
            <td>90</td>
        </tr>
        <tr>
            <td>수학</td>
            <td>85</td>
        </tr>
    </tbody>
    
    <tfoot>
        <tr>
            <th>총점</th>
            <td>175</td>
        </tr>
    </tfoot>
</table>
```

## 5. 셀 병합 (colspan, rowspan)

엑셀에서 여러 칸을 드래그해서 '셀 병합'을 하듯, HTML 표에서도 특정 칸을 가로세로로 늘려서 병합할 수 있습니다. 
이때는 태그 안에 <b>속성(Attribute)</b>을 추가하여 몇 칸을 차지할 것인지 숫자로 적어줍니다.

* **`colspan` (가로 병합):** 하나의 셀이 좌우로 여러 열(Column)을 차지하게 늘립니다.
* **`rowspan` (세로 병합):** 하나의 셀이 위아래로 여러 행(Row)을 차지하게 늘립니다.

```html
<table border="1">
    <tr>
        <!-- 가로로 2칸을 혼자 차지하는 제목 셀 -->
        <th colspan="2">회원 정보</th>
    </tr>
    <tr>
        <!-- 세로로 2칸을 혼자 차지하는 셀 -->
        <th rowspan="2">홍길동</th>
        <td>010-1234-5678</td>
    </tr>
    <tr>
        <!-- 앞의 '홍길동' 셀이 아래까지 밀고 내려왔으므로, 이 줄은 td가 하나만 있어도 됩니다. -->
        <td>서울시 강남구</td>
    </tr>
</table>
```

> [!IMPORTANT]
> **표 작성 시 주의사항**\
> 셀을 병합할 때는 전체 칸 수를 주의해야 합니다. 만약 윗줄은 3칸인데 아랫줄은 2칸만 작성했다면, 표의 레이아웃이 찌그러지거나 빈 공간이 생기게 됩니다. 가로줄(`<tr>`)마다 들어있는 칸(`<th>` 또는 `<td>`)의 개수(병합된 수 포함)가 모두 일정하게 일치하는지 항상 확인하세요.
