# 하이퍼링크 (Hyperlink)

## 개요
우리가 매일 인터넷을 하며 이 문서 저 문서를 넘나들고, 쇼핑몰에서 상품을 구경하다가 결제 페이지로 이동할 수 있는 이유는 무엇일까요? 바로 웹 페이지들이 서로 거미줄처럼 연결되어 있기 때문입니다. 이를 가능하게 해주는 기술이 <b>하이퍼링크(Hyperlink)</b>입니다.

HTML(HyperText Markup Language)의 **HyperText**라는 단어 자체가 바로 '일반적인 순서를 뛰어넘어 다른 문서로 연결되는 텍스트'를 의미합니다. 즉, 하이퍼링크는 HTML의 존재 이유이자 웹(Web)의 핵심 그 자체입니다.

본 문서에서는 글자나 이미지를 클릭했을 때 다른 곳으로 이동하게 만들어주는 `<a>` 태그의 상세한 사용법을 알아봅니다. 외부 사이트로의 이동, 내 웹사이트 내부에서의 이동, 새 창 띄우기, 그리고 같은 페이지 안에서 특정 위치로 점프하는 앵커(Anchor) 기능까지 하이퍼링크의 모든 것을 깊이 있게 다룹니다.

### 이 모듈에서 배울 내용
* 하이퍼링크를 생성하는 `<a>` 태그와 필수 속성 `href`
* 외부 주소(절대 URL)와 내부 페이지(상대 경로) 연결의 차이
* 현재 탭이 아닌 새 탭에서 링크를 여는 `target="_blank"` 속성
* 고유 식별자(`id`)를 활용하여 같은 페이지 내의 특정 위치로 점프하는 방법
* 이메일 앱이나 전화 앱을 곧바로 실행하는 특수 링크 작성법
* 이미지를 클릭 가능한 버튼(링크)으로 만드는 방법

---

## 1. 하이퍼링크의 기본: \<a\> 태그와 href

HTML에서 하이퍼링크를 만들 때는 <b>`<a>` 태그</b>를 사용합니다. 이 태그의 이름은 배의 닻을 의미하는 <b>앵커(Anchor)</b>에서 유래했습니다. 닻을 내려 다른 문서와 현재 문서를 단단히 연결한다는 의미를 담고 있습니다.

태그 사이에는 화면에 보여줄(클릭할) 텍스트를 적고, 시작 태그 안에는 <b>`href` (Hypertext Reference) 속성</b>을 사용하여 이동할 목적지의 주소를 반드시 적어주어야 합니다. 

```html
<!-- 클릭하면 구글 메인 페이지로 이동하는 링크 -->
<a href="https://www.google.com">구글로 이동하기</a>
```

브라우저는 `<a>` 태그로 감싸진 텍스트에 기본적으로 파란색 글씨와 밑줄을 그어, 사용자에게 "이것은 클릭할 수 있는 링크입니다"라는 시각적인 신호를 줍니다.

---

## 2. 외부 링크와 내부 링크 (경로 설정)

`href` 속성에는 `https://...` 로 시작하는 외부 웹사이트의 주소뿐만 아니라, 내 컴퓨터나 서버에 있는 다른 HTML 파일의 경로를 적어 넣을 수도 있습니다.

### 외부 웹사이트로 연결 (절대 URL)
인터넷 상에 존재하는 특정 사이트의 정확한 전체 주소를 적습니다. 어느 컴퓨터에서 열든 항상 동일한 사이트로 이동합니다.
```html
<p>궁금한 점이 있다면 <a href="https://ko.wikipedia.org">위키백과</a>를 참조하세요.</p>
```

### 내 웹사이트 내부에서의 이동 (상대 경로)
내가 만든 웹사이트 안에서 '메인 페이지(`index.html`)'에서 '소개 페이지(`about.html`)'로 이동하고 싶을 때는, 이전 미디어 챕터에서 배웠던 **상대 경로**를 그대로 사용합니다.
```html
<!-- 같은 폴더에 있는 about.html 문서로 이동합니다. -->
<a href="./about.html">회사 소개 페이지 보기</a>

<!-- 상위 폴더로 나가서 contact.html 문서로 이동합니다. -->
<a href="../contact.html">고객 센터 문의하기</a>
```

## 3. 새 탭에서 링크 열기 (target)

기본적으로 `<a>` 태그를 클릭하면 **현재 열려있는 브라우저 탭의 화면이 목적지 페이지로 바뀌어 버립니다.** 

하지만 내가 쓴 블로그 글을 읽던 사용자가 링크를 클릭했다고 해서 내 블로그 화면이 닫혀버리면 곤란할 때가 있습니다. 이때 원래 화면은 그대로 두고 <b>새로운 탭(창)</b>에서 링크를 열도록 지시하는 것이 바로 <b>`target="_blank"`</b> 속성입니다.

```html
<!-- 현재 탭에서 네이버가 열립니다. (원래 보던 페이지는 사라짐) -->
<a href="https://www.naver.com">네이버 (현재 탭에서 열기)</a>

<!-- target="_blank"를 추가하면 새로운 탭이 팝업처럼 생성되며 그곳에서 열립니다. -->
<a href="https://www.naver.com" target="_blank">네이버 (새 탭에서 열기)</a>
```

> [!NOTE]
> `target` 속성에 들어갈 수 있는 값은 `_blank`(새 창), `_self`(현재 창 - 기본값) 등이 있습니다. 실무에서는 외부 사이트로 내보낼 때는 주로 `_blank`를 쓰고, 내 사이트 안에서 돌아다닐 때는 `_self`를 씁니다.

## 4. 페이지 내부에서 점프하기 (내부 앵커)

`<a>` 태그의 아주 강력한 기능 중 하나는 다른 문서로 이동하는 것뿐만 아니라, <b>"현재 문서 안에서 스크롤을 훅 내리거나 올려서 특정 위치로 순간이동"</b>하게 만드는 것입니다. 위키백과의 '목차'를 클릭하면 해당 단락으로 휙 넘어가는 것과 같은 원리입니다.

이 기능을 사용하려면 2단계의 작업이 필요합니다.

**1단계: 도착 지점에 고유한 이름표(`id`) 달아주기**
HTML의 모든 태그는 `id`라는 속성을 가질 수 있습니다. `id`는 주민등록번호처럼 한 문서 안에서 **절대 중복되면 안 되는 고유한 식별자**입니다.
```html
<!-- 문서 저 아래쪽의 특정 제목에 'chapter-3'이라는 id를 부여합니다. -->
<h2 id="chapter-3">제 3장: 하이퍼링크의 역사</h2>
<p>이곳은 문서의 아주 깊은 곳입니다...</p>
```

**2단계: 링크(`href`)에서 이름표(`id`)를 호출하기**
`href`에 주소 대신 <b>우물 정(`#`, 해시) 기호와 도착할 `id`의 이름</b>을 적습니다. 
```html
<!-- 문서 맨 위쪽에 있는 목차 링크입니다. 클릭 시 chapter-3로 화면이 스크롤됩니다! -->
<a href="#chapter-3">제 3장으로 바로 건너뛰기</a>
```

> [!TIP]
> **맨 위로 가기 버튼 만들기**
> `href="#"` 처럼 해시 기호 뒤에 아무것도 적지 않거나 샵 하나만 달랑 적어두면, 브라우저는 이를 <b>"현재 페이지의 맨 꼭대기로 올라가라"</b>는 명령으로 해석합니다. 대부분 웹사이트에서 제공하는 [맨 위로 ⇧] 버튼은 대부분 이 원리로 만들어집니다.
> ```html
> <a href="#">맨 위로 올라가기</a>
> ```

## 5. 이미지 링크와 특수 기능 링크

### 이미지를 클릭 가능한 버튼으로 만들기
`<a>` 태그는 텍스트만 감쌀 수 있는 것이 아닙니다. `<img>` 태그를 `<a>` 태그 안에 통째로 집어넣으면, 그림 전체가 클릭 가능한 거대한 하이퍼링크 버튼이 됩니다. 쇼핑몰의 광고 배너가 작동하는 원리입니다.

```html
<!-- 이미지를 클릭하면 구글로 이동합니다. -->
<a href="https://www.google.com" target="_blank">
    <img src="google-logo.png" alt="구글 로고 배너">
</a>
```

### 이메일과 전화걸기 링크
스마트폰으로 웹 서핑을 하다가 고객센터 번호를 클릭했더니, 전화 앱이 켜지며 번호가 자동으로 눌려있는 것을 본 적이 있을 것입니다. `href`에 웹 주소가 아닌 <b>특수한 프로토콜(명령어)</b>을 적어주면 가능합니다.

* `mailto:` : 사용자의 기본 이메일 프로그램(아웃룩, 메일 앱 등)을 열고, 지정된 주소로 메일을 쓸 수 있게 세팅합니다.
* `tel:` : 스마트폰에서 클릭 시 자동으로 전화걸기 화면으로 넘겨줍니다.

```html
<!-- 클릭 시 이메일 전송 창 띄우기 -->
<a href="mailto:contact@mywebsite.com">운영자에게 이메일 보내기</a>

<!-- 클릭 시 전화 앱 실행 (모바일 환경에서 특히 유용합니다) -->
<a href="tel:010-1234-5678">고객센터(010-1234-5678)로 전화 걸기</a>
```
