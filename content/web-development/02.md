# 실습: 첫 HTML 파일 만들기와 Live Server 활용

## 개요
이전 문서에서 HTML이 웹 페이지의 뼈대를 만들고, 브라우저가 이를 읽어 화면에 그려낸다는 사실을 알게 되었습니다. 그렇다면 우리가 직접 작성한 HTML 코드는 어떻게 브라우저 띄워볼 수 있을까요?

본 실습에서는 Visual Studio Code(VS Code)를 사용하여 첫 번째 HTML 파일을 직접 생성해 봅니다. 처음에는 코드를 수정할 때마다 매번 브라우저를 수동으로 새로고침해야 하는 전통적이고 번거로운 방식을 체험합니다. 그 후, 코드를 저장하기만 하면 즉시 브라우저 화면에 반영해 주는 마법 같은 확장 프로그램인 **Live Server**를 설치하고 활용하여, 현대 웹 개발자들이 필수적으로 사용하는 실시간 개발 환경을 구축해 봅니다.

### 준비물
* VS Code가 설치된 PC
* Google Chrome 브라우저 (권장)

### 이 모듈에서 배울 내용
* `.html` 확장자를 가진 웹 문서 파일 생성하기
* 작성한 HTML 문서를 브라우저에서 직접 열어 화면 확인하기
* `Live Server` 설치 및 실시간 렌더링 경험하기

## Task 1. HTML 파일 생성 및 기본 코드 작성

가장 먼저 웹 브라우저가 읽을 수 있는 문서인 HTML 파일을 만들어야 합니다. 웹 페이지 파일은 항상 `.html`이라는 확장자로 끝납니다.

1. VS Code를 열고 실습을 진행할 폴더를 하나 엽니다.
2. 새 파일을 생성하고, 파일 이름을 `index.html`로 지정하세요. (웹 서버는 보통 `index.html`을 해당 폴더의 메인 페이지로 인식합니다.)
3. `index.html`에 아래의 코드를 복사해서 붙여넣습니다.
   ```html
   <!DOCTYPE html>
   <html>
   <head>
       <meta charset="UTF-8">
       <title>나의 첫 웹 페이지</title>
   </head>
   <body>
       <h1>안녕하세요! 웹 개발의 세계에 오신 것을 환영합니다.</h1>
       <p>이것은 나의 첫 번째 HTML 문서입니다.</p>
   </body>
   </html>
   ```
4. `Ctrl + S` (Mac은 `Cmd + S`)를 눌러 파일을 **저장**합니다.

## Task 2. 브라우저에서 직접 열어보기

이제 우리가 만든 HTML 문서를 브라우저에게 읽혀(파싱하여) 화면에 그리도록 만들어 보겠습니다.

1. 파일 탐색기(윈도우) 또는 Finder(맥)를 열어 방금 만든 `index.html` 파일이 있는 폴더로 이동합니다.
2. `index.html` 파일을 더블 클릭하여 웹 브라우저로 엽니다.
3. 화면에 "안녕하세요! 웹 개발의 세계에 오신 것을 환영합니다."라는 아주 큰 글씨와 본문이 잘 나타나는지 확인합니다.
4. 이제 VS Code로 돌아와서 `<h1>` 태그 안의 텍스트를 다음과 같이 수정해 봅니다.
   ```html
   <h1>텍스트를 수정해 보았습니다! 화면이 바로 바뀔까요?</h1>
   ```
5. 파일을 **저장**한 뒤, 띄워두었던 브라우저 창을 확인해 봅니다. 화면이 변했나요? 변하지 않았을 것입니다. 브라우저의 <b>새로고침 버튼(또는 F5 키)</b>을 눌러야만 수정된 내용이 화면에 반영됩니다.

> **결과 확인:**
> 코드를 한 글자 바꿀 때마다 VS Code에서 저장하고, 브라우저 창으로 넘어가 새로고침을 누르는 과정을 반복해야 합니다. 웹 개발을 할 때는 하루에도 수백 번씩 코드를 수정하는데, 이 방식은 너무나도 비효율적입니다.

## Task 3. Live Server 설치 및 실시간 렌더링

VS Code의 **Live Server** 확장 프로그램은 이러한 불편함을 단번에 해결 해줍니다. 코드가 저장될 때마다 브라우저를 자동으로 새로고침해 줍니다.

1. VS Code의 왼쪽 아이콘 메뉴들 중, 4개의 네모 블록이 모여있는 모양의 **[확장(Extensions)]** 탭을 클릭합니다. (또는 `Ctrl+Shift+X` / `Cmd+Shift+X`)
2. 검색창에 `Live Server`를 검색합니다.
3. 여러 검색 결과 중 제작자가 **Ritwick Dey**인 보라색 아이콘의 `Live Server`를 찾아 **[설치(Install)]** 버튼을 누릅니다.
4. 설치가 완료되었다면, 아까 열어두었던 `index.html` 파일 코드 화면으로 돌아옵니다.
5. 오른쪽 아래 상태 표시줄을 보면 <b>[Go Live]</b>라는 버튼이 새로 생긴 것을 볼 수 있습니다. 이 버튼을 클릭합니다.
   *(만약 버튼이 보이지 않는다면, 코드 작성 화면 아무 곳이나 마우스 우클릭을 한 뒤 <b>'Open with Live Server'</b>를 선택하세요.)*
6. 기본 브라우저가 자동으로 열리면서 방금 만들었던 웹 페이지가 뜹니다.
7. VS Code에서 `<p>` 태그 안의 텍스트를 다음과 같이 수정해 봅니다.
   ```html
   <p>Live Server를 켜니 코드를 저장하자마자 화면이 바뀝니다!</p>
   ```
8. `Ctrl + S`를 눌러 **저장하는 즉시** 브라우저 화면을 쳐다보세요! 

> **예상 결과:**
> 개발자가 브라우저에서 새로고침(F5)을 누르지 않았는데도, 코드를 저장하는 순간 수정한 텍스트가 실시간으로 화면에 렌더링되는 것을 확인할 수 있습니다.
