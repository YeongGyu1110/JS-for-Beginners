# 기본 연산자

## 개요
프로그램은 결국 수많은 데이터를 이리저리 계산하고 가공하는 과정의 연속입니다. 자바스크립트에서는 수학 시간에서 배웠던 덧셈, 뺄셈뿐만 아니라, 프로그래밍만의 독특한 계산 기호들을 사용하여 데이터를 조작합니다.

본 문서에서는 데이터를 계산하고 가공하는 데 사용되는 <b>연산자(Operator)</b>의 기본 개념을 이해하고, 가장 기초가 되는 사칙연산, 학교 수학에서는 다루지 않는 나머지 연산자와 문자열 연결, 그리고 계산의 순서를 결정하는 우선순위에 대해 알아봅니다.

### 이 모듈에서 배울 내용
* 연산자와 피연산자의 개념
* 기본 사칙연산(`+`, `-`, `*`, `/`)과 거듭제곱(`**`) 연산자
* 나머지 연산자(`%`)
* 문자열 연결 연산자(`+`)
* 연산자 우선순위
* 할당 연산자(`=`)

---

## 1. 연산자와 피연산자

본격적으로 기호들을 알아보기 전에, 앞으로 자주 사용하게 될 두 가지 용어를 짚고 넘어가겠습니다.

* **연산자 (Operator):** 덧셈(`+`), 뺄셈(`-`)처럼 특정한 작업을 수행하도록 지시하는 **기호**입니다.
* **피연산자 (Operand):** 연산자가 작업을 수행할 때 대상이 되는 <b>데이터(값)</b>입니다.

예를 들어, `5 + 10`이라는 코드가 있다면 여기서 `+`는 연산자이고, 양옆의 `5`와 `10`은 피연산자가 됩니다.

---

## 2. 사칙연산과 거듭제곱 연산자

자바스크립트의 기본적인 수학 연산은 우리가 알고 있는 일반적인 수학과 거의 똑같이 동작합니다. 다만 곱하기와 나누기의 기호가 키보드에 있는 기호 모양에 맞춰져 있습니다.

* **더하기:** `+`
* **빼기:** `-`
* **곱하기:** `*` (별표, 애스터리스크)
* **나누기:** `/` (슬래시)

```javascript
console.log(10 + 5); // 출력: 15
console.log(10 - 5); // 출력: 5
console.log(10 * 5); // 출력: 50
console.log(10 / 5); // 출력: 2
```

여기에 추가로, 같은 수를 여러 번 곱하는 <b>거듭제곱(Exponentiation)</b>을 수행할 때는 `**` 기호를 연속으로 사용합니다.

```javascript
// 2를 3번 곱함 (2의 3승)
console.log(2 ** 3); // 출력: 8
```

---

## 3. 나머지 연산자 (%)

학교 수학에서는 소수점을 배우고 나면 잘 쓰지 않지만, 프로그래밍에서는 아주 강력하고 자주 쓰이는 연산자가 바로 <b>나머지 연산자(`%`)</b>입니다. 

기호가 `%`라고 해서 퍼센트(백분율)를 구하는 것이 **절대 아닙니다.** 왼쪽의 숫자를 오른쪽 숫자로 나누었을 때 남는 <b>'나머지 값'</b>만 반환합니다.

```javascript
// 10을 3으로 나누면 몫은 3이고 나머지는 1이 됩니다.
console.log(10 % 3); // 출력: 1

// 10을 5로 나누면 딱 떨어지므로 나머지는 0이 됩니다.
console.log(10 % 5); // 출력: 0
```

> [!TIP]
> **나머지 연산자는 언제 쓸까요?**
> 실무에서 나머지 연산자는 <b>짝수와 홀수를 판별</b>할 때 가장 많이 사용됩니다.
> 어떤 숫자를 `2`로 나누었을 때 나머지가 `0`이면 무조건 짝수이고, `1`이면 홀수라는 수학적 규칙을 이용하는 것입니다.
> ```javascript
> let myNumber = 7;
> console.log(myNumber % 2); // 출력: 1 (따라서 홀수임을 알 수 있음!)
> ```

## 4. 문자열 연결 연산자 (+)

`+` 기호는 양쪽에 숫자가 있을 때는 덧셈을 하지만, **피연산자 중 하나라도 문자열(String)이 있다면** 더하기가 아니라 두 글자를 하나로 이어 붙이는 <b>문자열 연결 연산자</b>로 동작합니다.

```javascript
let greeting = "Hello" + " " + "World";
console.log(greeting); // 출력: "Hello World"

// 숫자와 문자를 더하면 숫자가 자동으로 문자로 변환되어 이어 붙습니다.
let ageText = "내 나이는 " + 20 + "살 입니다.";
console.log(ageText);  // 출력: "내 나이는 20살 입니다."

// 주의: 문자열로 된 숫자끼리 더하면 덧셈 연산이 되지 않습니다.
console.log("10" + "20"); // 출력: "1020" (30이 아님!)
```

## 5. 연산자 우선순위

하나의 문장 안에 여러 개의 연산자가 섞여 있다면 컴퓨터는 어떤 것부터 계산할까요? 학교 수학에서 덧셈보다 곱셈을 먼저 계산하는 것처럼, 자바스크립트의 연산자들 사이에도 <b>우선순위(Precedence)</b>가 존재합니다.

| 우선순위 | 연산자 | 설명 |
| :---: | :--- | :--- |
| **1 (가장 높음)** | `()` | 괄호 |
| **2** | `**` | 거듭제곱 |
| **3** | `*`, `/`, `%` | 곱하기, 나누기, 나머지 |
| **4** | `+`, `-` | 더하기, 빼기 (수학 연산 또는 문자열 연결) |
| **5 (가장 낮음)** | `=` | 할당 (변수에 값 넣기) |

```javascript
// 곱하기가 먼저 계산되고 덧셈이 나중에 계산됩니다. (5 * 2 = 10 -> 10 + 10 = 20)
console.log(10 + 5 * 2); // 출력: 20
```

> [!NOTE]
> 우선순위 표를 달달 외울 필요는 없습니다. 수학에서와 마찬가지로 <b>괄호 `()`</b>를 사용하면 컴퓨터는 괄호 안의 식을 무조건 제일 먼저 계산합니다. 따라서 코드를 작성할 때 헷갈리거나 확실히 먼저 계산해야 하는 부분이 있다면 괄호로 묶어주는 것이 가독성도 좋고 안전한 방법입니다.
> ```javascript
> // 괄호를 사용하여 덧셈을 먼저 계산하도록 강제합니다.
> console.log((10 + 5) * 2); // 출력: 30
> ```

---

## 6. 할당 연산자 (Assignment Operator)

변수 챕터에서 배웠듯이 `=` 기호는 "같다"는 뜻이 아니라, <b>오른쪽의 계산 결과를 왼쪽의 변수에 집어넣는(할당하는) 연산자</b>입니다. 연산자 우선순위가 가장 낮기 때문에, 오른쪽의 모든 수식 계산이 끝난 뒤에 가장 마지막으로 실행됩니다.

```javascript
let score = 10;
score = score + 5; // 현재 score(10)에 5를 더한 값(15)을 다시 score 변수에 넣음
console.log(score); // 출력: 15
```
