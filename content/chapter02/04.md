# 자료형 변환

## 개요
프로그램을 만들다 보면 사용자가 입력한 숫자 데이터가 문자열(String)로 인식되거나, 반대로 숫자를 문자열로 연결해야 하는 상황이 빈번하게 발생합니다. 이때 데이터의 종류를 우리가 원하는 대로 바꾸는 작업을 <b>형변환(Type Conversion)</b>이라고 부릅니다.

본 문서에서는 자바스크립트의 내장 함수인 `String()`, `Number()`, `Boolean()`을 사용하여 원시 자료형의 타입을 명시적으로 변환하는 방법을 학습합니다.

### 이 모듈에서 배울 내용
* `String()`을 활용하여 데이터를 문자열로 변환
* `Number()`를 활용하여 데이터를 숫자로 변환하고 `NaN`의 의미 이해
* `Boolean()`을 활용한 논리형 변환과 `Falsy` 값의 종류 인지

---

## 1. 문자로 변환하기: String()

문자열로 바꾸고 싶을 때는 `String()` 함수를 사용합니다. 괄호 안에 변환할 데이터를 넣으면 결과값이 따옴표로 감싸진 문자열 형태로 반환됩니다.

주로 숫자나 논리값을 텍스트와 함께 화면에 출력해야 할 때 사용합니다.

```javascript
let num = 100;
console.log(typeof num);    // 출력: "number"

// 숫자를 문자열로 변환
let strNum = String(num);
console.log(typeof strNum); // 출력: "string"
console.log(strNum);        // 출력: "100" (겉보기엔 같지만 문자열입니다)

// 논리값을 문자열로 변환
let boolToStr = String(true);
console.log(boolToStr);     // 출력: "true"
```

---

## 2. 숫자로 변환하기: Number()

문자열로 저장된 숫자를 실제 수학 연산이 가능한 숫자로 바꾸고 싶을 때는 `Number()` 함수를 사용합니다. 

예를 들어, 사용자에게 나이를 입력받으면 기본적으로 문자열 형태로 저장됩니다. 이를 그대로 더하기 연산에 사용하면 글자가 이어 붙어버리기 때문에 반드시 숫자로 변환해야 합니다.

```javascript
let strPrice = "5000";

// 문자열 그대로 더하면 글자가 이어붙음
console.log(strPrice + 1000); // 출력: "50001000"

// 숫자로 변환한 뒤 더하면 정상적으로 연산됨
let realPrice = Number(strPrice);
console.log(realPrice + 1000); // 출력: 6000
```

### 숫자가 아닌 문자를 변환하려고 하면?
만약 `"Hello"`나 `"100원"`처럼 순수한 숫자가 아닌 글자를 `Number()`로 변환하려고 하면 어떻게 될까요? 컴퓨터는 이를 숫자로 바꿀 수 없다고 판단하고 <b>`NaN`</b>이라는 특수한 값을 반환합니다.

`NaN`은 <b>Not a Number(숫자가 아님)</b>의 약자로, 수학 연산이 실패했음을 알려주는 자바스크립트의 특별한 숫자형 데이터입니다.

```javascript
let wrongNumber = Number("안녕하세요");

console.log(wrongNumber);        // 출력: NaN
console.log(typeof wrongNumber); // 출력: "number" (NaN 자체는 숫자형에 속합니다)
```

## 3. 참 또는 거짓으로 변환하기: Boolean()

데이터를 논리형(`true` 또는 `false`)으로 변환할 때는 `Boolean()` 함수를 사용합니다. 
자바스크립트에서는 데이터를 논리형으로 변환할 때, <b>'값이 비어있거나 부정적인 의미를 가지는 데이터'</b>는 모두 `false`로 변환하고, <b>'그 외의 내용물이 있는 모든 데이터'</b>는 `true`로 변환합니다.

### 무조건 false가 되는 값들 (Falsy)
자바스크립트에서 `Boolean()`을 씌웠을 때 `false`로 변환되는 값은 딱 5가지로 정해져 있습니다. 이를 <b>Falsy(거짓 같은 값)</b>라고 부르며, 이 5가지만 외워두면 아주 유용합니다.

1. 숫자 `0`
2. 빈 문자열 `""` (띄어쓰기조차 없는 상태)
3. `null`
4. `undefined`
5. `NaN`

```javascript
// Falsy 값들의 변환
console.log(Boolean(0));         // 출력: false
console.log(Boolean(""));        // 출력: false
console.log(Boolean(null));      // 출력: false
console.log(Boolean(undefined)); // 출력: false
console.log(Boolean(NaN));       // 출력: false
```

### 무조건 true가 되는 값들 (Truthy)
위의 5가지 Falsy 값을 제외한 <b>세상의 모든 데이터는 `Boolean()`으로 변환하면 `true`</b>가 됩니다. 문자열 안에 공백이 있거나, 음수이거나, 심지어 문자 `"false"`조차도 내용물이 있는 문자열이므로 `true`가 됩니다.

```javascript
// Truthy 값들의 변환
console.log(Boolean(1));         // 출력: true
console.log(Boolean(-100));      // 출력: true (음수도 true)
console.log(Boolean("Hello"));   // 출력: true
console.log(Boolean(" "));       // 출력: true (띄어쓰기 공백이 있으므로 true)
console.log(Boolean("false"));   // 출력: true (글자 "false"가 들어있는 것이므로 true)
```

> [!TIP]
> 실무에서는 어떤 변수에 값이 정상적으로 들어있는지(비어있지 않은지) 확인할 때, 이 `Truthy`와 `Falsy`의 개념을 아주 적극적으로 활용합니다.
