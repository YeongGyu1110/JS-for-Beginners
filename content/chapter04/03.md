# 반복문 (while, for)

## 개요
만약 화면에 "안녕하세요"라는 문구를 100번 출력해야 한다고 가정해 봅시다. `console.log("안녕하세요")`를 100번 복사해서 붙여넣을 수도 있겠지만, 이는 코드를 지저분하게 만들고 수정하기도 매우 어렵게 합니다. 

본 문서에서는 동일한 작업을 원하는 만큼 자동으로 반복하게 해주는 <b>반복문(Loop)</b>에 대해 다룹니다. 조건만 맞으면 계속해서 코드를 실행하는 `while`문부터 시작하여, 반복 횟수가 정해져 있을 때 사용하기 좋은 `for`문의 세밀한 구조, 그리고 반복의 흐름을 자유자재로 제어하는 `break`, `continue`, `레이블(Label)` 기능까지 아주 상세하게 파헤쳐 봅니다.

### 이 모듈에서 배울 내용
* 조건이 참인 동안 코드를 계속 실행하는 `while`문의 구조
* `for`문의 4가지 구성 요소 (begin, condition, step, body)와 실행 순서
* 카운터 변수의 인라인 선언과 이터레이션(Iteration)의 개념
* `for`문의 구성 요소를 생략하는 방법과 무한 루프
* 반복문의 흐름을 즉시 끊어버리는 `break`와 한 턴을 건너뛰는 `continue`
* 중첩 반복문에서 바깥쪽 반복문까지 한 번에 제어하는 레이블(Label)

---

## 1. while 반복문

`while`문은 `if`문과 비슷하게 생겼지만, **조건이 참(`true`)인 동안에는 중괄호 `{}` 안의 코드를 끝없이 반복해서 실행**한다는 차이가 있습니다.

* `while (조건식)` : 소괄호 안의 조건식이 참이면 코드 블록을 실행하고, 실행이 끝나면 **다시 위로 올라와 조건을 검사**합니다. 조건이 거짓이 될 때까지 이 과정을 반복합니다.

```javascript
let count = 0;

// count가 3보다 작을 동안만 반복합니다.
while (count < 3) {
    console.log(`현재 카운트: ${count}`);
    count++; // 매 반복마다 count를 1씩 증가시킵니다.
}
// 출력 결과:
// 현재 카운트: 0
// 현재 카운트: 1
// 현재 카운트: 2
```

이때 중괄호 `{}` 안에서 실행되는 코드 블록을 <b>본문(body)</b>이라고 부르며, 반복문이 본문을 한 번 실행하는 것을 <b>이터레이션(Iteration, 반복, 순회)</b>이라고 부릅니다. 위의 코드는 총 3번의 이터레이션을 거친 것입니다.

> [!IMPORTANT]
> `while`문을 사용할 때는 반드시 본문(`body`) 안에서 <b>조건식을 거짓으로 만들 수 있는 조작(위 코드의 `count++`)</b>을 해주어야 합니다. 만약 이를 빼먹으면 조건이 영원히 참이 되어 프로그램이 멈추지 않는 <b>무한 루프(Infinite Loop)</b>에 빠지게 됩니다.

> [!NOTE]
> **본문이 한 줄이라면 중괄호`{..}`를 생략할 수 있습니다.**\
> `if`문과 마찬가지로 구문이 단 한 줄이라면 중괄호를 생략할 수 있습니다.
> ```javascript
> let i = 3;
> while (i) alert(i--);
> ```

## 2. do...while 반복문

`while`문은 반복문에 진입하기 전에 조건을 먼저 검사합니다. 따라서 처음부터 조건이 거짓(`false`)이라면 본문 코드가 단 한 번도 실행되지 않고 그대로 건너뛰어집니다.

하지만 상황에 따라 <b>조건의 참/거짓 여부와 상관없이 본문 코드를 최소한 '무조건 한 번'은 실행</b>해야 할 때가 있습니다. 이때 사용하는 것이 `do...while` 반복문입니다.

* `do` 블록 안의 본문 코드를 먼저 한 번 실행합니다.
* 코드가 끝난 뒤 밑에 있는 `while (조건식)`을 검사하여, 참이면 다시 위로 올라가 `do` 블록을 실행하고 거짓이면 반복문을 종료합니다.

```javascript
let count = 10;

// 이미 count가 3보다 크기 때문에 조건(count < 3)은 거짓입니다.
// 하지만 do 블록이 조건을 검사하기 전에 먼저 실행되므로, 콘솔에 딱 한 번은 무조건 출력됩니다.
do {
    console.log(`현재 카운트: ${count}`);
    count++;
} while (count < 3);

// 출력 결과:
// 현재 카운트: 10
```

> [!TIP]
> **언제 사용할까요?**\
> `do...while`문은 실무에서 자주 쓰이는 문법은 아니지만, 사용자에게 **무언가를 최소 한 번은 입력받은 뒤, 그 값이 조건에 맞을 때까지 계속해서 다시 입력하라고 요구하는 상황**에서 아주 깔끔하게 사용될 수 있습니다.
> ```javascript
> let password;
> 
> do {
>     // 일단 팝업창을 띄워 비밀번호를 한 번은 물어봅니다.
>     password = prompt("비밀번호를 설정하세요 (최소 4자리 이상 입력):", "");
>     
> } while (password.length < 4); // 입력한 비밀번호가 4자리 미만이면 다시 do 블록으로 돌아가 팝업창을 띄웁니다.
> ```

## 3. for 반복문의 구조와 작동 원리

`while`문은 구조가 단순하지만 카운터를 세기 위한 변수 선언, 조건 검사, 값 증가 코드가 여기저기 흩어져 있어 실수를 유발하기 쉽습니다. 이를 한 곳에 모아 보기 좋게 만든 것이 <b>`for`문</b>입니다.

`for`문은 크게 4가지 요소로 구성됩니다.

```javascript
// for (begin; condition; step) { body }
for (let i = 0; i < 3; i++) {
    console.log(i);
}
```

1. **시작(begin):** `let i = 0` 
   * 반복문에 진입할 때 **단 한 번만** 실행됩니다. 주로 카운터를 셀 <b>카운터 변수</b>를 선언하고 초기화합니다.
2. **조건(condition):** `i < 3`
   * 매 이터레이션이 시작되기 전에 검사합니다. 이 조건이 거짓이 되면 반복문을 즉시 멈추고 빠져나갑니다.
3. **본문(body):** `console.log(i)`
   * 조건이 참일 때 실행되는 실제 코드입니다.
4. **단계(step):** `i++`
   * 본문 코드가 모두 실행된 직후에 실행됩니다. 주로 카운터 변수를 증가시키거나 감소시키는 역할을 합니다.

### 실행 순서 요약
`for`문은 항상 다음의 순서로 톱니바퀴처럼 돌아갑니다.
* **최초 1회:** `begin` 실행 → `condition` 검사 → 참이면 `body` 실행 → `step` 실행
* **이후 반복:** `condition` 검사 → 참이면 `body` 실행 → `step` 실행 → 반복...

> [!NOTE]
> **인라인 변수 선언**\
> `for`문의 소괄호 안에서 `let i = 0`처럼 변수를 선언하는 것을 **인라인 변수 선언**이라고 부릅니다. 이렇게 선언된 카운터 변수 `i`는 <b>오직 `for`문의 중괄호 `{}` 안에서만 존재</b>하며, 반복문이 끝나면 메모리에서 깔끔하게 사라집니다. (for문 바깥에서 `console.log(i)`를 호출하면 에러가 발생합니다.)

## 4. for문의 구성 요소 생략

`for`문의 소괄호 안에 들어가는 `begin`, `condition`, `step`은 모두 선택 사항입니다. 상황에 따라 일부를 생략할 수 있지만, <b>구분자인 세미콜론(`;`)은 반드시 두 개를 남겨두어야 합니다.</b>

```javascript
let i = 0; // 이미 바깥에 카운터 변수가 있다면 begin을 생략할 수 있습니다.

for (; i < 3; i++) {
    console.log(i);
}
```

```javascript
let j = 0;

for (; j < 3;) { // step마저 생략할 수 있습니다. (이 경우 while문과 완전히 동일해집니다)
    console.log(j);
    j++; // 본문 안에서 카운터를 증가시킵니다.
}
```

만약 모든 구성 요소를 생략한다면 <b>무한 루프</b>가 만들어집니다.
```javascript
// 세미콜론 2개만 남겨두면 조건이 항상 참(true)인 것으로 간주합니다.
for (;;) { 
    // 영원히 실행되는 본문
}
```

## 5. 반복문의 흐름 제어: break와 continue

반복문은 기본적으로 조건이 거짓이 될 때까지 끝까지 달립니다. 하지만 특정 상황에서 반복문을 강제로 멈추거나, 이번 턴만 건너뛰고 싶을 때 사용하는 특별한 지시어가 있습니다.

### 루프 탈출: break
조건과 상관없이 <b>반복문 전체를 즉시 부수고(break) 빠져나옵니다.</b> 무한 루프를 사용할 때 특정 조건을 만족하면 탈출구를 만들어주기 위해 자주 사용됩니다.

```javascript
let sum = 0;

while (true) { // 무한 루프
    let value = prompt("숫자를 입력하세요. (0을 입력하면 종료)");
    
    // 사용자가 0을 입력하면 반복문을 완전히 박살내고 탈출합니다!
    if (value == 0) { 
        break; 
    }
    
    sum += Number(value);
}
console.log(`총합: ${sum}`);
```

### 이번 턴만 건너뛰기: continue
반복문 전체를 멈추는 것이 아니라, <b>현재 진행 중인 이터레이션(본문 코드)만 즉시 멈추고 다음 턴(step)으로 넘어갑니다.</b> 특정 조건의 데이터만 필터링해서 처리하고 싶을 때 유용합니다.

```javascript
// 1부터 5까지 출력하되, 짝수는 건너뛰고 홀수만 출력하는 코드
for (let i = 1; i <= 5; i++) {
    
    if (i % 2 === 0) { 
        continue; // i가 짝수면 아래 코드를 무시하고 곧바로 i++ 로 넘어갑니다!
    }
    
    console.log(i); // 1, 3, 5만 출력됨
}
```

## 6. 중첩 반복문과 레이블 (Label)

반복문 안에 또 다른 반복문을 넣을 수 있습니다. 이를 <b>중첩 반복문(Nested Loop)</b>이라고 합니다. (예: 구구단 출력, 2차원 좌표 탐색 등)

그런데 만약 안쪽에 있는 반복문에서 특정 조건을 만족했을 때, <b>안쪽 반복문뿐만 아니라 바깥쪽 반복문까지 한 번에 부수고 나가고 싶다면</b> 어떻게 해야 할까요? 그냥 `break`를 쓰면 자신이 속한 가장 안쪽의 반복문 하나만 빠져나가게 됩니다.

이때 <b>레이블(Label)</b>이라는 이름표 기능을 사용합니다. 반복문 앞에 `이름:` 형태로 레이블을 붙여두고, `break 이름;`을 호출하면 그 이름표가 붙은 반복문 전체를 빠져나갑니다.

```javascript
// 바깥쪽 for문에 'outerLoop'라는 이름표(레이블)를 붙입니다.
outerLoop: for (let i = 1; i <= 3; i++) {

    for (let j = 1; j <= 3; j++) {
        let input = prompt(`좌표 (${i}, ${j})의 값을 입력하세요. (취소 누르면 전체 종료)`);

        // 사용자가 취소(null)를 누르면 안쪽 for문만 멈추는 게 아니라 바깥쪽 for문까지 통째로 종료합니다!
        if (input === null) {
            break outerLoop; 
        }
        
        console.log(`입력된 값: ${input}`);
    }
}

console.log("반복문이 완전히 종료되었습니다.");
```

> [!TIP]
> 레이블은 `continue`에도 사용할 수 있습니다. (`continue outerLoop;`) 하지만 무분별한 레이블의 사용은 코드가 어디로 튈지 예측하기 힘들게 만들어(스파게티 코드) 가독성을 크게 떨어뜨립니다. 중첩 반복문을 한 번에 빠져나와야 하는 <b>특수한 상황에서만 제한적으로 사용</b>하는 것을 권장합니다.
