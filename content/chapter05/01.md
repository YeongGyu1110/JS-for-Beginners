# 함수 기본

## 개요
`console.log()`, `String()`, `Number()` 이 명령어들의 공통점은 모두 이름 뒤에 <b>소괄호 `()`</b>가 붙는다는 것입니다. 이것들이 바로 자바스크립트가 기본적으로 제공하는 <b>함수(Function)</b>들입니다.

함수는 프로그래밍의 꽃이자, 초보자가 가장 먼저 마주하는 거대한 벽이기도 합니다. 함수를 단순히 '코드를 묶어두는 주머니' 정도로 얕게 이해하면 나중에 데이터가 오가는 흐름을 놓치기 십상입니다. 

본 문서(전반부)에서는 우리가 직접 이런 함수를 만들어보는 **함수 선언**과 실행 방법, 함수가 어떤 행동을 하는지 직관적으로 나타내는 **이름 짓기 규칙**, 그리고 함수 내부와 외부의 데이터가 철저하게 분리되는 **지역 변수와 외부 변수**의 개념에 대해 깊이 있게 파헤쳐 봅니다.

### 이 모듈에서 배울 내용
* 함수를 직접 정의하는 선언(Declaration)과 실행하는 호출(Call)의 분리
* 동사(Verb) 형태를 사용하는 함수의 이름 짓기 관례
* 함수 내부에서만 살아 숨 쉬는 지역 변수(Local Variable)
* 함수 바깥의 데이터를 가져다 쓰는 외부 변수(Outer Variable)의 접근 규칙

---

## 1. 함수의 선언과 호출

함수는 쉽게 말해 <b>"특정한 작업을 수행하도록 미리 짜인 코드들의 묶음에 이름을 붙여놓은 것"</b>입니다. 한번 잘 만들어두면 필요할 때마다 이름만 불러서 재사용할 수 있습니다.

### 함수 선언 (Declaration)
새로운 함수를 만들 때는 `function`이라는 키워드를 사용합니다. 그 뒤에 함수의 **이름**, 그리고 <b>소괄호 `()`</b>와 <b>중괄호 `{}`</b>가 순서대로 따라옵니다.

```javascript
// 'showGreeting'이라는 이름의 함수를 선언(정의)합니다.
function showGreeting() {
    // 중괄호 {} 내부는 함수가 호출되었을 때 실행될 '본문(Body)'입니다.
    console.log("안녕하세요!");
    console.log("자바스크립트의 세계에 오신 것을 환영합니다.");
}
```
위 코드를 작성하고 실행해 보면 콘솔에는 **아무것도 출력되지 않습니다.** 
함수를 '선언'하는 것은 비유하자면 자판기 안에 음료수를 채워 넣고 버튼을 설계한 것일 뿐, 아직 **버튼을 누르지는 않았기 때문**입니다.

### 함수 호출 (Call / Invocation)
자판기의 버튼을 눌러 안에 있는 코드를 실제로 작동시키는 것을 <b>호출(Call)</b>이라고 합니다. 함수 이름 뒤에 소괄호 `()`를 붙여주면 컴퓨터가 함수 본문으로 점프하여 코드를 실행합니다.

```javascript
// 위에서 선언한 함수를 호출(실행)합니다.
showGreeting(); // 안녕하세요! \n 자바스크립트의 세계에 오신 것을 환영합니다.

// 함수는 원하는 만큼 몇 번이든 재사용할 수 있습니다.
showGreeting();
showGreeting(); 
```

## 2. 함수 이름 짓기 규칙

변수의 이름을 지을 때 명사(예: `userName`, `price`)를 주로 사용했다면, 함수는 <b>'어떤 동작을 수행하는 코드의 모음'</b>이므로 **반드시 동사(Verb) 형태**로 시작하도록 이름을 지어야 합니다. 

이름만 봐도 이 함수가 무슨 일을 하는지, 어떤 값을 뱉어낼지 완벽하게 예측할 수 있어야 좋은 코드입니다. 자바스크립트에서는 변수와 마찬가지로 <b>카멜 케이스(camelCase)</b>를 사용합니다.

* `show...` : 무언가를 보여줄 때 (예: `showMessage`)
* `get...` : 어떤 값을 계산하거나 가져와서 반환할 때 (예: `getAge`, `getUserData`)
* `calc...` : 수학적인 계산을 수행할 때 (예: `calcTotalPrice`)
* `create...` : 새로운 데이터나 문서를 생성할 때 (예: `createAccount`)
* `check...` : 특정 조건이 맞는지 확인하고 논리값(true/false)을 뱉어낼 때 (예: `checkPermission`)

```javascript
// 나쁜 예: 무엇을 하는지 알 수 없는 명사형 이름
function loginData() { ... }

// 좋은 예: 동작이 명확한 동사형 이름
function checkLoginData() { ... }
```

## 3. 지역 변수와 외부 변수

함수가 초보자에게 어려운 가장 큰 이유 중 하나는, 함수를 선언하는 순간 **중괄호 `{}`를 경계로 눈에 보이지 않는 거대한 '유리벽'이 세워지기 때문**입니다. 

### 지역 변수 (Local Variable)
함수 내부(중괄호 안)에서 `let`이나 `const`로 선언한 변수를 **지역 변수**라고 부릅니다. 이 변수는 <b>오직 함수 안에서만 살아 숨 쉬며, 함수가 끝나는 순간 메모리에서 완전히 증발</b>합니다.

```javascript
function showMessage() {
    // message는 showMessage 함수 내부의 '지역 변수'입니다.
    let message = "안녕하세요, 저는 함수 안에서 태어났습니다.";
    console.log(message); // 함수 안에서는 정상적으로 접근 가능
}

showMessage();

// 유리벽 바깥(함수 외부)에서는 함수 안의 지역 변수를 절대 들여다볼 수 없습니다!
console.log(message); // ReferenceError: message is not defined (에러 발생)
```

### 외부 변수 (Outer Variable)
반대로, 함수 바깥에서 선언된 변수를 **외부 변수**(또는 전역 변수)라고 부릅니다. 
함수의 유리벽은 <b>'안에서는 밖이 보이지만, 밖에서는 안이 보이지 않는 특수 유리'</b>와 같습니다. 따라서 함수 내부에서는 자신보다 바깥에 있는 변수를 자유롭게 가져다 읽고 수정할 수 있습니다.

```javascript
let userName = "Hero"; // 외부 변수

function showWelcome() {
    // 함수 안에서는 바깥에 있는 userName을 볼 수 있고 수정도 가능합니다.
    userName = "Super " + userName; 
    
    // 함수 안에서 새로운 지역 변수도 만들 수 있습니다.
    let welcomeText = "환영합니다, " + userName;
    console.log(welcomeText);
}

showWelcome(); // "환영합니다, Super Hero" 출력

// 외부 변수인 userName은 함수에 의해 값이 변경된 채로 유지됩니다.
console.log(userName); // "Super Hero" 출력
```

> [!IMPORTANT]
> **변수 이름이 똑같다면? (Shadowing)**\
> 만약 외부 변수와 똑같은 이름으로 함수 내부에서 지역 변수를 선언하면 어떻게 될까요?
> 함수는 자신과 가장 가까운(자기 내부에 있는) 지역 변수를 우선적으로 사용합니다. 이때 바깥에 있던 외부 변수는 가려지게 되는데, 이를 <b>변수 쉐도잉(Shadowing)</b>이라고 부릅니다.
> ```javascript
> let text = "바깥쪽 변수";
> 
> function printText() {
>     let text = "안쪽 변수"; // 외부 변수와 이름이 똑같은 지역 변수 선언
>     console.log(text); // "안쪽 변수" 출력 (외부 변수는 무시됨)
> }
> 
> printText();
> console.log(text); // "바깥쪽 변수" 출력 (외부 변수의 값은 전혀 영향을 받지 않음)
> ```
