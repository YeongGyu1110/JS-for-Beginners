# CSS 여백과 테두리 상세 가이드 (Margin, Border, Padding)

## 개요
이전 모듈에서 우리는 웹 페이지의 모든 요소가 네모난 박스로 이루어져 있다는 박스 모델의 기본 개념을 배웠습니다. 그렇다면 이 박스들을 화면에 보기 좋게 배치하고 서로 간섭하지 않도록 간격을 띄우려면 어떻게 해야 할까요?

본 문서에서는 박스의 형태와 위치를 결정짓는 핵심 속성인 <b>패딩(Padding), 테두리(Border), 마진(Margin)</b>에 대해 더욱 깊이 있게 다룹니다. 실무에서 이 속성들을 얼마나 자유자재로 다루느냐에 따라 웹사이트의 디테일과 완성도가 결정됩니다. 각 속성의 다양한 작성법(축약형)과 테두리를 둥글게 깎는 방법, 그리고 CSS 초보자들을 당황하게 만드는 '마진 병합(Margin Collapsing) 현상'까지 상세히 파헤쳐 봅니다.

### 기본 요건
이 실습은 사용자가 다음에 익숙하다는 가정하에 진행됩니다.
* CSS 박스 모델의 기본 구조
* 블록 요소와 인라인 요소의 성질

### 이 모듈에서 배울 내용
* 상하좌우 여백을 한 줄로 작성하는 축약형 문법의 완벽한 이해
* 클릭 영역을 넓혀주고 배경색을 연장하는 안쪽 여백 `padding`
* 선의 디테일을 살리는 `border`와 모서리를 둥글게 만드는 `border-radius`
* 박스 간의 거리를 띄우는 바깥쪽 여백 `margin`
* 상하 마진이 겹칠 때 발생하는 '마진 병합(Collapsing)' 현상의 원리와 규칙

---

## 1. 방향과 축약형 문법 (공통 규칙)

`padding`과 `margin`은 상단(top), 우측(right), 하단(bottom), 좌측(left)의 네 방향에 여백을 줄 수 있습니다. 각 방향을 따로 지정할 수도 있지만, 코드의 길이를 줄이기 위해 <b>공백으로 값을 띄어 쓰는 축약형(Shorthand)</b>을 주로 사용합니다.

값의 개수에 따라 적용되는 위치가 달라지므로 이 규칙을 반드시 암기해야 합니다. (이 규칙은 `padding`과 `margin`에 동일하게 적용됩니다.)

* **값 1개:** 상하좌우 모두 동일하게 적용
* **값 2개:** `[상하]` `[좌우]` 순서로 짝지어 적용
* **값 3개:** `[상단]` `[좌우]` `[하단]` 순서로 적용 (위아래 여백이 다를 때 유용)
* **값 4개:** 12시부터 **시계 방향** (`상` `우` `하` `좌`) 순서로 적용

```css
/* 1. 상하좌우 각각 지정할 때 */
.box1 {
    padding-top: 10px;
    padding-right: 20px;
    padding-bottom: 30px;
    padding-left: 40px;
}

/* 2. 축약형으로 작성할 때 */
.box2 {
    margin: 20px;             /* 상하좌우 모두 20px */
    margin: 10px 30px;        /* 위/아래 10px, 좌/우 30px */
    margin: 10px 20px 30px;   /* 위 10px, 좌/우 20px, 아래 30px */
    margin: 10px 20px 30px 0; /* 위 10px, 우 20px, 아래 30px, 좌 0px */
}
```

## 2. 안쪽 여백: Padding

패딩은 **테두리 선(Border)과 실제 내용물(Content) 사이의 간격**을 의미합니다. 

단순히 내용물이 벽에 붙지 않게 숨통을 틔워주는 역할을 넘어, 실무에서는 **요소의 클릭 가능한 영역(Target Area)을 넓히는 데** 매우 중요하게 쓰입니다. 버튼 태그(`<button>`)나 링크 태그(`<a>`)에 패딩을 넉넉히 주면, 사용자가 정확히 글자를 클릭하지 않아도 버튼 주변을 누르면 클릭이 되도록 만들 수 있습니다.

또한, 패딩 영역에는 **요소의 배경색(background-color)이나 배경 이미지가 그대로 연장되어 적용**됩니다.

```css
.btn-submit {
    background-color: blue;
    color: white;
    
    /* 글자 주변으로 상하 12px, 좌우 24px의 넉넉한 공간을 만들어 
       클릭하기 좋은 큼직한 버튼을 완성합니다. 배경색인 파란색도 꽉 차게 칠해집니다. */
    padding: 12px 24px;
}
```

## 3. 테두리: Border와 Border-Radius

### 1. 테두리 선 긋기
`border`는 패딩과 마진 사이에서 박스의 경계를 짓는 선입니다. 앞서 배운 대로 두께, 스타일, 색상을 띄어쓰기로 축약하여 작성합니다.

```css
.alert-box {
    /* 2px 두께의 빨간색 실선 */
    border: 2px solid red; 
    
    /* 위쪽 테두리만 다른 스타일로 덮어쓸 수도 있습니다. */
    border-top: 5px dotted orange;
}
```
*(스타일 종류: `solid`(실선), `dashed`(절취선/긴 점선), `dotted`(둥근 점선), `double`(이중선), `none`(선 없음) 등)*

### 2. 모서리 둥글게 깎기: `border-radius`
현대 웹 디자인에서는 뾰족하고 날카로운 사각형보다 모서리가 부드럽게 둥근 형태를 선호합니다. 이때 사용하는 속성이 바로 `border-radius`입니다. 

입력한 수치(반지름)만큼 네 모서리가 둥글게 깎입니다. 패딩이나 마진처럼 각 모서리별로 다르게 값을 줄 수도 있습니다.

```css
.card {
    /* 4개의 모서리를 모두 8px만큼 둥글게 만듭니다. */
    border-radius: 8px;
}

.profile-img {
    /* 가로세로 크기가 똑같은 정사각형 요소에 radius를 50% 주면 완벽한 원형(동그라미)이 됩니다! */
    width: 100px;
    height: 100px;
    border-radius: 50%; 
}
```

## 4. 바깥쪽 여백: Margin

마진은 **테두리(Border) 바깥쪽의 투명한 여백**을 의미합니다. 내 박스와 주변의 다른 박스들을 밀어내어 거리를 띄울 때 사용합니다. 패딩과 달리 마진 영역에는 배경색이 칠해지지 않습니다.

블록(Block) 요소의 좌우 마진을 자동으로 균등 분배하여 화면 중앙에 배치하는 `margin: 0 auto;` 기법은 웹 레이아웃에서 가장 빈번하게 사용되는 공식 중 하나입니다.

---

## 5. 중요 개념: 마진 병합 (Margin Collapsing)

웹 퍼블리싱을 하다 보면, 내가 설정한 마진 값대로 요소들이 띄워지지 않아 당황하는 순간이 반드시 찾아옵니다. 이는 CSS의 독특한 규칙인 **'마진 병합(상쇄) 현상'** 때문입니다.

마진 병합이란, **블록 요소들의 위아래(상/하) 마진이 서로 만났을 때, 두 마진이 더해지는 것이 아니라 더 큰 마진 값 하나로 합쳐져 버리는 현상**을 말합니다. 
*(주의: 좌우 마진에서는 이 현상이 절대 발생하지 않으며, 오직 수직(위아래) 방향에서만 일어납니다.)*

### 병합 사례: 형제 요소 간의 병합
위에 있는 박스의 `margin-bottom`과 아래에 있는 박스의 `margin-top`이 닿았을 때 발생합니다.

```html
<div class="box1">위쪽 박스</div>
<div class="box2">아래쪽 박스</div>
```
```css
.box1 {
    margin-bottom: 30px; /* 아래로 30px 밀어내기 */
}
.box2 {
    margin-top: 50px;    /* 위로 50px 밀어내기 */
}
/* 결과: 두 박스 사이의 간격은 80px이 아니라, 더 큰 값인 50px이 됩니다. */
```

### 왜 이런 규칙이 생겼을까요?
문단(`<p>`)이나 제목(`<h1>`) 같은 텍스트 요소들을 세로로 나열할 때, 불필요하게 여백이 과도하게 겹쳐서 간격이 너무 듬성듬성해지는 것을 막기 위해 브라우저가 똑똑하게 여백을 조율해 주는 기능으로 고안되었습니다.

> [!NOTE]
> **마진 병합을 피하거나 해결하는 방법**\
> 레이아웃을 짤 때 이 현상이 방해가 된다면, 다음 방법들로 병합을 막을 수 있습니다.
> 1. 마진 대신 박스 내부에 <b>`padding`</b>을 주어 공간을 확보합니다.
> 2. 요소의 속성을 플렉스박스(`display: flex;`)나 인라인-블록(`display: inline-block;`)으로 변경하면 마진 병합이 일어나지 않습니다.
> 3. 부모와 자식 간에 마진이 병합되어 부모까지 통째로 밀려 내려가는 경우에는 부모 요소에 아주 얇은 `border`나 `padding`을 1px이라도 주어 벽을 만들어주면 병합이 차단됩니다.
