# CSS 선택자와 캐스케이딩 원리

## 개요
앞선 파트에서는 CSS의 개념과 문법, 그리고 웹 문서에 적용하는 3가지 방법에 대해 알아보았습니다. 이제는 CSS 코드를 작성할 때 "어떤 요소를 꾸밀 것인지" 정확하게 짚어내는 방법과, 여러 스타일이 충돌했을 때 브라우저가 어떤 규칙으로 최종 디자인을 결정하는지 이해해야 합니다.

본 문서에서는 실무에서 가장 많이 쓰이는 4가지 기본 선택자를 알아보고, CSS의 핵심 동작 원리인 '캐스케이딩(Cascading)'의 3가지 우선순위 기준을 다룹니다.

### 기본 요건
이 모듈은 사용자가 다음에 익숙하다는 가정하에 진행됩니다.
* HTML 문서의 기본 구조
* 기본 HTML 태그

### 이 모듈에서 배울 내용
* 대상을 지정하는 4가지 기본 선택자 (전체, 태그, 클래스, 아이디)
* 스타일의 충돌을 해결하는 캐스케이딩(Cascading)의 개념
* 캐스케이딩의 3대 기준 (명시도, 상속, 코드 순서)

---

## 1. CSS 기본 선택자 (Basic Selectors)

선택자(Selector)는 디자인을 적용할 HTML 요소를 조준하는 조준경과 같습니다. HTML 문서 내의 수많은 태그 중 내가 원하는 요소만 정확히 골라내기 위해 CSS는 다양한 종류의 선택자를 제공합니다. 그중 가장 기본적이면서 실무에서 자주 쓰이는 4가지 기본 선택자를 알아봅니다.

### 1. 전체 선택자 (Universal Selector) : `*`
키보드의 별표 기호(`*`)를 사용하여 **웹 페이지 내부의 모든 요소**를 한꺼번에 선택합니다. 브라우저가 기본적으로 가지고 있는 여백을 초기화(Reset)하는 용도로 주로 사용합니다.

```css
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}
```

### 2. 태그 선택자 (Type Selector) : `태그이름`
HTML 태그의 이름을 그대로 적어, **해당 태그를 가진 모든 요소를 일괄 선택**합니다. 

```css
/* 페이지 안의 모든 p 태그의 글자 크기를 16픽셀로 설정 */
p {
    font-size: 16px;
}
```

### 3. 클래스 선택자 (Class Selector) : `.클래스이름`
HTML 태그에 부여된 `class` 속성값을 기준으로 요소를 선택합니다. 클래스 이름 앞에는 <b>반드시 마침표(`.`)</b>를 붙여야 브라우저가 클래스 선택자로 인식합니다. 

웹 페이지 안에서 **여러 개의 요소에 중복하여 동일한 스타일을 적용**하고 싶을 때 가장 널리 사용됩니다.

```html
<!-- HTML -->
<p class="highlight">이 문단은 강조됩니다.</p>
<span class="highlight">이 글자도 똑같이 강조됩니다.</span>
```
```css
/* CSS */
.highlight {
    background-color: yellow;
    font-weight: bold;
}
```

### 4. 아이디 선택자 (ID Selector) : `#아이디이름`
HTML 태그에 부여된 `id` 속성값을 기준으로 요소를 선택합니다. 아이디 이름 앞에는 <b>반드시 우물 정 기호(`#`)</b>를 붙여야 합니다. 

`id`는 웹 문서 내에서 **오직 단 하나만 존재하는 고유한 식별자**여야 합니다. 따라서 특정 하나의 요소에만 아주 특별한 디자인을 입히고 싶을 때 제한적으로 사용합니다.

```html
<!-- HTML -->
<nav id="main-header">웹사이트의 메인 상단 영역입니다.</nav>
```
```css
/* CSS */
#main-header {
    background-color: #333;
    color: white;
    height: 80px;
}
```

## 2. 캐스케이딩(Cascading)

CSS의 첫 글자인 <b>Cascading(캐스케이딩)</b>은 '위에서 아래로 흐르는 폭포수'라는 뜻을 가지고 있습니다. 

하나의 HTML 요소에 여러 개의 스타일이 복합적으로 적용되거나 서로 충돌할 때, **어떤 스타일을 최종적으로 화면에 보여줄지 결정하는 우선순위 규칙**을 캐스케이딩이라고 부릅니다. 브라우저가 이 충돌을 해결하기 위해 따르는 3가지 핵심 기준이 있습니다.

---

### 기준 1: 스타일 우선순위 (명시도, Specificity)
선택자의 종류에 따라 점수(가중치)가 다르게 매겨지며, 더 구체적으로 대상을 지정하는 선택자일수록 우선순위가 높습니다. 점수가 높은 스타일이 낮은 스타일을 덮어씁니다.

| 선택자 종류 | 예시 | 점수 (명시도 무게) | 우선순위 |
| :--- | :--- | :--- | :--- |
| **`!important` 선언** | `color: red !important;` | 측정 불가 (가장 강력) | 1순위 |
| **인라인 스타일** | `<p style="color: blue;">` | 1000점 | 2순위 |
| **아이디 선택자** | `#title { ... }` | 100점 | 3순위 |
| **클래스 선택자** | `.highlight { ... }` | 10점 | 4순위 |
| **태그 선택자** | `p { ... }` | 1점 | 5순위 |
| **전체 선택자** | `* { ... }` | 0점 | 6순위 |

```css
/* 태그 선택자 (1점) */
p { color: blue; }

/* 클래스 선택자 (10점) */
.text-red { color: red; }

/* 결과적으로 아래 클래스 속성을 가진 p 태그는 10점짜리인 'red'가 최종 반영됩니다. */
```

> [!WARNING]
> **`!important` 사용 주의**\
> 속성 값 뒤에 `!important`를 붙이면 우선순위 점수 체계를 완전히 무시하고 무조건 1순위로 렌더링됩니다. 이는 추후 스타일을 수정하거나 디버깅할 때 다른 스타일이 적용되지 않는 원인이 될 수 있으므로, 실무에서는 꼭 필요한 상황이 아니라면 사용을 자제하는 것이 바람직합니다.

---

### 기준 2: 스타일 상속 (Inheritance)
HTML 요소들은 부모와 자식 관계(포함 관계)를 맺는다고 배웠습니다. CSS의 특정 속성들은 **부모 요소에 스타일을 지정하면 자식 요소들에게도 그 스타일이 자연스럽게 물려내려 가는데**, 이를 상속이라고 합니다.

* **상속되는 속성들 (주로 글자/텍스트 관련):** `font-family`, `font-size`, `color`, `text-align` 등
* **상속되지 않는 속성들 (주로 레이아웃/박스 관련):** `margin`, `padding`, `border`, `width`, `height` 등

```html
<!-- HTML -->
<main style="color: green;">
    <!-- 부모인 div에 녹색 글자를 지정했습니다. -->
    <p>자식인 p 태그도 자동으로 녹색 글자로 렌더링됩니다. (스타일 상속)</p>
</main>
```

---

### 기준 3: 코드 순서에 의한 우선순위 (Source Order)
우선순위 점수(명시도)가 완전히 동일한 스타일이 충돌하는 경우, **CSS 파일 내에서 가장 마지막(아래쪽)에 작성된 코드**가 최종적으로 살아남아 화면에 그려집니다. 브라우저가 위에서 아래로 코드를 읽어 내려가면서 덮어쓰기 때문입니다.

```css
p {
    color: red;
}

/* 아래쪽에 작성된 스타일이 동일한 점수(태그 선택자 1점)이므로 위 스타일을 덮어씁니다. */
p {
    color: blue; /* 최종 반영 */
}
```
