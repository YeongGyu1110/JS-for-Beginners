# Display와 Float (CSS 레이아웃의 기초 1부) 

## 개요
기본적으로 HTML 문서의 요소들은 위에서 아래로, 좌측에서 우측으로 자연스럽게 흘러가며 배치됩니다. 하지만 우리가 매일 접속하는 웹사이트들을 보면, 왼쪽에 메뉴바가 있고 오른쪽에 본문이 나란히 있거나, 여러 개의 상품 사진이 격자(Grid) 형태로 깔끔하게 정렬되어 있습니다. 

단순히 위아래로 쌓이는 요소들을 화면의 원하는 곳에 자유롭게 배치하여 다채로운 구조를 만드는 과정을 **레이아웃(Layout) 설계**라고 합니다. 본 문서는 분량이 방대하여 두 부분으로 나누어 제공됩니다.

**1부**에서는 요소의 기본적인 태생(블록/인라인)을 결정짓는 `display` 속성과, 요소를 화면 구석으로 띄워 나란히 배치하는 전통적인 레이아웃 기법인 `float`와 `clear`에 대해 먼저 학습합니다. 

### 기본 요건
이 실습은 사용자가 다음에 익숙하다는 가정하에 진행됩니다.
* 기본 HTML 태그
* 웹 문서의 기본 렌더링 흐름 (Document Flow): HTML 코드가 작성된 순서대로 화면 위에서부터 아래로 차곡차곡 블록이 쌓이는 기본적인 브라우저의 화면 출력 방식에 대한 이해.

### 이 모듈에서 배울 내용
* 요소의 배치 성질을 완전히 뒤바꾸는 `display` (`block`, `inline`, `inline-block`, `none`)
* 텍스트와 이미지를 어우러지게 하거나 요소를 가로로 배치하는 `float`
* float의 흐름을 끊고 레이아웃 붕괴를 막아주는 `clear`

---

## 1. 요소의 태생을 바꾸는 마법: `display`

HTML의 모든 태그는 태어날 때부터 고유한 화면 배치 성질(블록 또는 인라인)을 가지고 있습니다. CSS의 **`display`** 속성은 이 태생적인 성질을 개발자 마음대로 바꿔버릴 수 있는 가장 기본적이고 강력한 레이아웃 속성입니다.

### 1. `display: block`
* **특징:** 화면의 **가로 너비(100%)를 혼자서 전부 차지**합니다. 마치 테트리스의 긴 막대 블록처럼, 요소의 양옆에 다른 요소가 올 수 없고 항상 새로운 줄(줄바꿈)에서 시작합니다.
* **크기 제어:** `width`, `height`, `margin`, `padding` 값을 모두 자유롭게 지정할 수 있습니다.
* **대표 태그:** `<div>`, `<p>`, `<h1>`\~`<h6>`, `<ul>`, `<li>`

### 2. `display: inline`
* **특징:** 줄바꿈 없이 **자신의 내용물(글자) 크기만큼만 공간을 차지**하며, 다른 인라인 요소들과 한 줄에 나란히 배치됩니다. 문장 속의 단어와 같습니다.
* **크기 제어:** `width`와 `height`를 지정해도 **절대 적용되지 않습니다.** 상하 마진(`margin-top`, `margin-bottom`)도 적용되지 않습니다. 오직 좌우 여백만 조절 가능합니다.
* **대표 태그:** `<span>`, `<a>`, `<strong>`

### 3. `display: inline-block`
* **특징:** 블록과 인라인의 **장점만 결합한 하이브리드** 형태입니다. 
* 요소들은 인라인처럼 **한 줄에 나란히 배치**되지만, 내부적으로는 블록처럼 **`width`, `height`, 상하 `margin`을 모두 가질 수 있습니다.** 가로로 나열되는 버튼들이나 카드 레이아웃을 만들 때 매우 유용합니다.
* **대표 태그:** `<button>`, `<img>`, `<input>`

### 4. `display: none`
* **특징:** 해당 요소를 **화면에서 완전히 지워버립니다.** 
* 시각적으로 안 보일 뿐만 아니라, 요소가 차지하던 공간(박스) 자체를 싹 없애버려 뒤에 오던 요소들이 그 자리를 채우게 됩니다. 자바스크립트와 연동하여 메뉴를 열고 닫거나(Toggle) 모달 창을 띄울 때 필수적으로 사용됩니다.

```css
/* 기본적으로 인라인 요소인 a 태그를 블록으로 바꿔 큼직한 버튼처럼 만듭니다. */
.nav-link a {
    display: block;
    width: 100%;
    padding: 15px;
    background-color: blue;
}

/* 요소를 화면에서 숨깁니다. */
.hidden-box {
    display: none;
}
```

## 2. 요소를 둥둥 띄우기: `float`

`float`은 영어로 '뜨다, 부유하다'라는 뜻입니다. 원래는 신문 기사처럼 **이미지 주변을 텍스트가 자연스럽게 감싸고 흐르도록(Text-wrapping) 만들기 위해** 탄생한 속성입니다. 

하지만 Flexbox나 Grid 같은 최신 기술이 등장하기 전 과거 10여 년 동안은, 블록 요소들을 가로로 나란히 배치하여 2단, 3단 컬럼(Column) 레이아웃을 만드는 핵심 기술로 사용되었습니다.

* **`float: left`:** 요소를 화면의 **왼쪽**으로 띄워서 배치합니다.
* **`float: right`:** 요소를 화면의 **오른쪽**으로 띄워서 배치합니다.
* **`float: none` (기본값):** 띄우지 않습니다.

```html
<img src="apple.jpg" class="apple-img">
<p>이 사과는 매우 맛있습니다. 텍스트가 사과 이미지 옆으로 자연스럽게 흘러갑니다...</p>
```
```css
/* 이미지를 왼쪽으로 둥둥 띄우면, 뒤에 오는 p 태그의 글자들이 
   이미지의 오른쪽 빈 공간으로 딸려 올라와 감싸게 됩니다. */
.apple-img {
    float: left;
    margin-right: 15px;
}
```

## 3. 흐름을 끊고 제자리 찾기: `clear`

`float` 속성을 사용하여 요소를 띄우면 치명적인 부작용이 발생합니다. 띄워진 요소는 공중으로 붕 떠버리기 때문에, **그 부모 요소나 뒤따라오는 형제 요소들이 띄워진 요소를 인식하지 못하고 레이아웃이 겹치거나 찌그러지는 현상**이 발생합니다.

이러한 부작용을 해결하고 "더 이상 float의 영향을 받지 않겠다(흐름을 끊겠다)"라고 선언하는 속성이 바로 <b>`clear`</b>입니다. 

* **`clear: left`:** `float: left`의 영향을 끊어냅니다.
* **`clear: right`:** `float: right`의 영향을 끊어냅니다.
* **`clear: both`:** 양쪽 모두의 영향을 끊어냅니다. (가장 많이 사용됨)

```html
<div class="box-left">왼쪽 박스</div>
<div class="box-right">오른쪽 박스</div>
<div class="footer">바닥글 (이 요소는 가로로 배치되면 안 됩니다!)</div>
```
```css
.box-left {
    float: left;
    width: 50%;
}
.box-right {
    float: left;
    width: 50%;
}

/* clear를 해주지 않으면 footer가 왼쪽/오른쪽 박스 밑으로 겹쳐서 기어들어갑니다.
   clear: both를 선언하면 float의 흐름을 끊고 정상적으로 다음 줄로 내려갑니다. */
.footer {
    clear: both; 
    background-color: gray;
}
```

> [!TIP]
> **Clearfix (클리어픽스) 핵**
> 자식 요소들이 모두 `float` 처리되면 부모 요소의 높이가 `0`으로 쪼그라드는 문제가 발생합니다. 이를 해결하기 위해 부모 요소의 가상 클래스(`::after`)에 `clear: both`를 부여하는 '클리어픽스' 기법이 실무에서 관행처럼 사용되었습니다. (다만, 최근에는 `display: flex`를 주로 사용하여 레이아웃을 짜므로 `float`의 사용 빈도는 크게 줄어들었습니다.)
