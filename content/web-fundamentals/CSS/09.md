# 반응형 웹과 미디어 쿼리

## 개요
과거의 웹사이트는 컴퓨터 모니터의 넓은 화면만을 고려하여 고정된 크기로 제작되었습니다. 하지만 스마트폰, 태블릿, 노트북, 4K 모니터 등 사용자가 웹 페이지에 접속하는 기기의 화면 크기가 매우 다양해지면서 기존의 고정 레이아웃은 모바일 기기에서 글씨가 너무 작아 보이거나 화면 밖으로 잘려 나가는 문제를 일으켰습니다.

본 문서에서는 기기의 화면 크기에 따라 웹 페이지의 레이아웃과 디자인이 유연하게 변하는 <b>반응형 웹 디자인(Responsive Web Design, RWD)</b>의 개념을 학습합니다. 또한 이를 구현하는 핵심 CSS 기술인 <b>미디어 쿼리(`@media`)</b>의 기본 문법을 익히고, 실무에서 어떤 기준으로 화면 크기를 나누고 스타일을 적용하는지 살펴봅니다.

### 기본 요건
이 실습은 사용자가 다음에 익숙하다는 가정하에 진행됩니다.
* HTML 문서의 기본 구조 (`<head>` 영역과 `<meta>` 태그의 역할)
* 요소의 너비(`width`) 제어 및 퍼센트(`%`), `calc()` 함수 등을 활용한 CSS 크기 계산
* 코드 작성 순서에 따라 스타일이 덮어씌워지는 CSS의 캐스케이딩(Cascading) 원리
* 플렉스 박스(`display: flex`)를 활용한 요소의 가로 배치 및 줄바꿈(`flex-wrap`) 개념

### 이 모듈에서 배울 내용
* 반응형 웹 디자인의 개념과 장점
* 모바일 브라우저의 정상적인 렌더링을 돕는 `viewport` 메타 태그
* 화면 조건에 따라 다른 스타일을 적용하는 미디어 쿼리(`@media`)의 기본 문법
* 화면 크기가 변하는 지점인 브레이크포인트의 이해
* 모바일 퍼스트와 데스크톱 퍼스트 전략의 차이점

---

## 1. 반응형 웹 디자인

반응형 웹 디자인은 **단 하나의 HTML 문서와 CSS 코드**로 접속하는 기기의 해상도에 맞춰 웹사이트의 레이아웃이 자동으로 최적화되어 보여지도록 설계하는 웹 디자인 기법입니다.

* **고정형 웹 vs 반응형 웹:** 고정형 웹은 스마트폰으로 접속해도 데스크톱 화면을 축소해서 보여주기 때문에 확대,축소가 빈번해야 하지만, 반응형 웹은 기기 폭에 맞춰 텍스트와 이미지 크기가 자동으로 조절되고 레이아웃 형태가 변화합니다.
* **장점:** PC용 사이트와 모바일용 사이트를 따로 개발하고 유지보수할 필요가 없어 효율적이며, SEO 측면에서도 동일한 URL를 가지므로 유리합니다.

---

## 2. 반응형 웹의 필수 조건: Viewport

아무리 CSS로 반응형 코드를 짜도, HTML 문서의 `<head>` 영역 안에 아래의 **뷰포트(`viewport`) 메타 태그**가 빠져 있으면 스마트폰에서 페이지가 데스크톱 화면처럼 작게 축소되어 보입니다.

```html
<head>
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
</head>
```

* `width=device-width`: 웹 페이지의 가로 너비를 접속한 기기의 실제 화면 너비에 맞추어 렌더링하도록 지시합니다.
* `initial-scale=1.0`: 페이지가 처음 로딩될 때 기본 확대/축소 비율을 100%(1대1 비율)로 설정합니다.

## 3. 미디어 쿼리(`@media`)의 기본 문법

미디어 쿼리는 <b>"만약 화면의 너비가 특정 크기 이상이라면 이 스타일을 적용해라"</b>라는 조건문과 같은 역할을 하는 CSS3 기술입니다. 

```css
@media 미디어타입 and (조건문) {
    /* 조건이 참(True)일 때만 적용될 CSS 코드 */
}
```

* **미디어 타입:** 기기의 성격을 정합니다. 보통 일반 브라우저 화면을 의미하는 <b>`screen`</b>을 주로 사용하며, 인쇄 출력을 위한 `print` 등도 있습니다. (생략 가능)
* **조건문:** 화면의 가로 너비를 기준으로 스타일이 바뀔 조건을 지정합니다. 주로 `min-width`(최소 너비)와 `max-width`(최대 너비)를 씁니다.

```css
/* 기본 스타일 (모든 기기에 적용) */
.title {
    font-size: 18px;
}

/* 화면 너비가 768px '이상'일 때만 중복 적용되는 스타일 */
@media screen and (min-width: 768px) {
    .title {
        font-size: 28px; /* 태블릿 이상에서는 글자 크기가 커집니다. */
    }
}
```

## 4. 브레이크포인트(Breakpoint)와 반응형 전략

스타일이 변하는 기준이 되는 가로 해상도 지점을 <b>브레이크포인트(Breakpoint)</b>라고 부릅니다. 기기마다 화면 크기가 천차만별이므로 실무에서는 대략적인 범주를 3~4개 정도로 나누어 설정합니다.

* **모바일 기본 (0px ~ ):** 스마트폰 화면 (기본 스타일)
* **태블릿 (~ 768px 이상):** 태블릿 또는 작은 노트북
* **데스크톱 (~ 1024px 이상):** 일반 데스크톱 모니터

이러한 브레이크포인트를 토대로 코드를 작성할 때는 크게 두 가지 전략 방향을 선택할 수 있습니다.

### 1. 모바일 퍼스트 (Mobile-First) 전략 (실무 권장)
가장 작은 화면(모바일)의 디자인을 **기본 CSS**로 먼저 작성한 뒤, 화면이 점점 커질 때마다 **`min-width`(최소 너비 이상)** 조건을 사용하여 레이아웃을 확장해 나가는 방식입니다. 

불필요한 스타일 덮어쓰기를 줄여주고, 성능이 상대적으로 낮은 모바일 기기의 로딩 부담을 덜어주어 현대 웹 개발에서 기본적으로 권장되는 전략입니다.

```css
/* 1. 모바일 기본 스타일 (모양 잡기) */
.container {
    width: 100%;
}

/* 2. 태블릿 이상 (768px 이상) */
@media (min-width: 768px) {
    .container {
        width: 750px;
        margin: 0 auto;
    }
}

/* 3. 데스크톱 이상 (1024px 이상) */
@media (min-width: 1024px) {
    .container {
        width: 980px;
    }
}
```

### 2. 데스크톱 퍼스트 (Desktop-First) 전략
큰 모니터(데스크톱) 화면을 **기본 CSS**로 작성한 뒤, 화면이 좁아질 때마다 **`max-width`(최대 너비 이하)** 조건을 사용해 요소를 축소하거나 한 줄로 배치하는 방식입니다. 기존 데스크톱 전용 웹사이트를 모바일 대응으로 개편할 때 주로 쓰입니다.

## 5. 반응형 웹 실무 적용 예시: 그리드 변환

가장 빈번하게 사용되는 반응형 패턴 중 하나는 카드가 나열되는 열의 개수를 조절하는 것입니다. 
스마트폰에서는 1열(세로)로 보여주다가, 화면이 넓어지면 2열, 4열로 자연스럽게 늘어나는 예제입니다.

```html
<!-- HTML -->
<div class="card-list">
    <div class="card">카드 1</div>
    <div class="card">카드 2</div>
    <div class="card">카드 3</div>
    <div class="card">카드 4</div>
</div>
```

```css
/* CSS (모바일 퍼스트 전략) */

/* 1. 모바일 화면: 한 줄에 하나씩 100% 채움 (1열 배치) */
.card-list {
    display: flex;
    flex-wrap: wrap; /* 요소가 넘치면 다음 줄로 바꿈 */
    gap: 16px;       /* 카드 간의 간격 */
}

.card {
    width: 100%;     /* 모바일에서는 너비 100% */
    background-color: #eee;
    padding: 20px;
}

/* 2. 태블릿 이상 (768px 이상): 2열 배치 */
@media (min-width: 768px) {
    .card {
        /* 전체 너비에서 간격을 제외하고 절반씩 차지하도록 계산 */
        width: calc(50% - 8px);
    }
}

/* 3. 데스크톱 이상 (1024px 이상): 4열 배치 */
@media (min-width: 1024px) {
    .card {
        /* 한 줄에 4개씩 배치 */
        width: calc(25% - 12px);
    }
}
```

> [!IMPORTANT]
> **미디어 쿼리 작성 시 코드 순서의 중요성**\
> 모바일 퍼스트(`min-width`) 전략으로 코드를 작성할 때는 **반드시 작은 해상도부터 큰 해상도 순서로 위에서 아래로 작성**해야 합니다. 
> 
> CSS의 캐스케이딩 원리에 의해 동일한 요소에 대해 1024px 이상의 조건이 먼저 작성되고 768px 이상의 조건이 아래에 작성되면, 1024px 모니터에서도 아래쪽의 768px 코드가 최종적으로 덮어씌워지는 부작용이 발생합니다.
