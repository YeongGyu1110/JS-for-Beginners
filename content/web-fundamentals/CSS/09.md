# CSS 배경 스타일링 1부: 이미지와 제어 속성

## 개요
웹 페이지를 디자인할 때 요소의 배경은 단순히 단색을 칠하는 것을 넘어, 화려한 이미지나 다채로운 색상 전환 효과를 넣어 사용자에게 강렬한 시각적 인상을 심어주는 아주 중요한 영역입니다. 

본 문서는 분량이 방대하여 두 부분으로 나누어 제공됩니다.
**1부**에서는 단색 배경을 넘어 원하는 이미지를 배경으로 삽입하고, 이미지가 바둑판처럼 반복되는 것을 제어하며, 박스 모델을 기준으로 배경이 어디서부터 시작될지 결정하는 다양한 배경 제어 속성들을 상세히 학습합니다.

### 이 모듈에서 배울 내용
* 배경에 이미지를 불러오는 `background-image`
* 배경 이미지의 반복 패턴을 제어하는 `background-repeat`
* 요소 크기에 맞춰 이미지를 늘리거나 맞추는 `background-size`
* 배경 이미지의 위치를 정밀하게 조정하는 `background-position`
* 배경이 시작되는 기준점과 잘리는 영역을 결정하는 `background-origin`과 `background-clip`

---

## 1. 배경 색상과 배경 이미지 삽입

### 1. 배경 색상: `background-color`
요소의 배경에 단일 색상을 채웁니다. 색상 이름, HEX 코드(`#ffffff`), RGB/RGBA 등을 사용할 수 있습니다. `rgba`를 사용하면 배경의 투명도(Alpha)를 조절할 수 있습니다.

### 2. 배경 이미지: `background-image`
요소의 배경으로 이미지 파일을 불러와 삽입합니다. CSS에서는 파일의 경로를 지정할 때 **`url()`** 함수를 사용합니다.

```css
.hero-section {
    background-color: #f4f4f4; /* 이미지가 로딩되지 않았을 때를 대비한 예비 색상 */
    background-image: url('./images/main-banner.jpg');
}
```

> [!NOTE]
> `<img>` 태그와 `background-image`는 어떻게 다를까요?
> * `<img>` 태그는 이미지 자체가 문서의 **핵심 콘텐츠**일 때 사용합니다. (예: 뉴스 기사의 보도 사진, 상품 이미지) 검색 엔진이 이를 수집합니다.
> * `background-image`는 문서의 정보와는 무관하게 **순수하게 장식 목적**일 때 사용합니다. 텍스트 뒤에 깔리는 패턴이나 꾸밈용 이미지가 이에 해당합니다.

---

## 2. 이미지의 반복 제어: `background-repeat`

CSS에서 배경 이미지를 불러오면, 브라우저는 기본적으로 요소의 공간이 이미지보다 클 경우 **빈 공간을 채우기 위해 이미지를 바둑판 모양으로 무한 반복(Tiling)**하여 렌더링합니다. 이 속성을 제어하여 반복을 막거나 특정 방향으로만 반복시킬 수 있습니다.

* `repeat` (기본값): 가로와 세로 방향 모두 이미지를 반복합니다.
* `no-repeat`: 이미지를 단 한 번만 띄우고 **절대 반복하지 않습니다.** (실무에서 가장 많이 사용)
* `repeat-x`: 가로(X축) 방향으로만 반복합니다.
* `repeat-y`: 세로(Y축) 방향으로만 반복합니다.

```css
.banner {
    background-image: url('./images/logo.png');
    background-repeat: no-repeat; /* 로고 하나만 띄우고 반복을 멈춥니다. */
}
```

## 3. 배경 이미지의 크기 조절: `background-size`

요소의 크기와 불러온 이미지의 원본 크기가 다를 때, 이미지를 어떻게 화면에 맞출지 결정하는 아주 강력한 속성입니다. 반응형 웹 디자인에서 필수적으로 쓰입니다.

* **`auto` (기본값):** 이미지의 원본 크기 그대로 표시합니다.
* **`cover`:** 이미지가 찌그러지지 않는 선에서(비율 유지), **요소의 전체 화면(배경)을 빈틈없이 꽉 채우도록** 이미지를 확대하거나 축소합니다. 이 과정에서 이미지의 일부(가장자리)가 잘려 나갈 수 있습니다.
* **`contain`:** 이미지가 찌그러지지 않고 **잘려 나가는 부분 없이 온전히 다 보이도록** 크기를 맞춥니다. 대신 요소의 비율과 이미지의 비율이 다르면 상하 또는 좌우에 빈 공간(여백)이 생깁니다.
* **사용자 지정 크기:** `100px 50px`(가로 세로 픽셀 지정) 또는 `100% 100%`(부모 크기에 꽉 맞게 강제 변형 - 비율이 깨질 수 있음)

```css
.full-screen-bg {
    background-image: url('./background.jpg');
    background-repeat: no-repeat;
    background-size: cover; /* 화면을 빈틈없이 꽉 채우는 현대 웹사이트의 기본 공식 */
}
```

## 4. 배경 이미지의 위치 이동: `background-position`

`background-repeat: no-repeat`로 이미지를 한 번만 띄웠거나, `background-size: cover`로 이미지가 잘렸을 때, **이미지의 어느 부분을 중심으로 띄울 것인지** 기준점을 이동하는 속성입니다.

* **키워드 사용:** `top`, `bottom`, `left`, `right`, `center`를 조합하여 사용합니다. (예: `center center` -> 정중앙)
* **퍼센트(%)나 픽셀(px) 사용:** 왼쪽 위 모서리(0,0)를 기준으로 가로와 세로 이동 거리를 지정합니다.

```css
.profile-header {
    background-image: url('./photo.jpg');
    background-size: cover;
    /* 이미지의 상단은 위쪽 끝에 맞추고, 가로는 정중앙을 기준으로 띄웁니다. */
    background-position: center top; 
}
```

## 5. 배경의 기준점과 자르기: origin & clip

박스 모델 모듈에서 배운 패딩(Padding)과 테두리(Border) 영역을 기억하시나요? 배경 이미지나 색상을 박스의 어느 영역부터 시작하고 자를지 정밀하게 통제하는 속성입니다.

### 1. 시작점 결정: `background-origin`
배경 이미지가 박스 모델의 어느 영역을 0,0(좌측 상단) 기준점으로 삼아 그려지기 시작할지 정합니다.
* `padding-box` (기본값): 패딩 영역의 안쪽 모서리부터 시작합니다.
* `border-box`: 테두리 선의 바깥쪽 모서리부터 시작합니다. (테두리 밑으로 그림이 깔립니다)
* `content-box`: 패딩을 제외한 순수 콘텐츠 영역부터 시작합니다.

### 2. 배경 자르기: `background-clip`
색상이나 이미지를 박스의 어느 영역까지만 보여주고 그 바깥쪽은 잘라낼지 정합니다.
* `border-box` (기본값): 테두리 영역까지 배경을 채웁니다.
* `padding-box`: 테두리 영역에는 배경을 표시하지 않고, 패딩 영역까지만 보여줍니다.
* `content-box`: 콘텐츠 영역에만 배경을 칠하고, 패딩과 테두리 영역은 투명하게 비워둡니다.

```css
.box {
    border: 5px dashed rgba(0, 0, 0, 0.5); /* 반투명한 점선 테두리 */
    padding: 20px;
    background-color: lightcoral;
    
    /* 배경색이 패딩까지만 칠해지고, 테두리(점선) 영역은 배경색 없이 투명하게 잘려 나갑니다. */
    background-clip: padding-box; 
}
```
