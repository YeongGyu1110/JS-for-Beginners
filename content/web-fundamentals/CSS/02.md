# 글꼴과 텍스트 스타일

## 개요
웹 페이지에서 사용자가 가장 많이 소비하는 핵심 콘텐츠는 다름 아닌 '텍스트'입니다. 아무리 유용한 정보를 담고 있는 웹사이트라 하더라도, 글꼴이 지나치게 투박하거나 줄 간격이 좁아 가독성이 떨어진다면 사용자는 금방 페이지를 이탈하게 됩니다. 

따라서 웹 문서의 성격에 맞게 서체를 지정하고 읽기 편하게 글자를 정돈하는 타이포그래피(Typography) 작업은 매우 중요합니다. 본 문서에서는 글꼴의 종류와 크기, 두께를 제어하는 스타일 속성부터 문단을 정렬하고 행간과 자간을 조절하여 전체적인 가독성을 끌어올리는 다양한 텍스트 전용 속성들을 살펴봅니다.

### 기본 요건
이 실습은 사용자가 다음에 익숙하다는 가정하에 진행됩니다.
* HTML 텍스트 관련 태그
* 하이퍼링크 태그(`<a>`)
* CSS 기본 문법 및 선택자

### 이 모듈에서 배울 내용
* 서체를 지정하고 대비책(Fallback)을 설정하는 `font-family`
* 다양한 단위(`px`, `em`, `rem`)를 활용한 글자 크기 조절 (`font-size`)
* 글자의 굵기와 기울임을 결정하는 `font-weight`, `font-style`
* 텍스트의 정렬과 줄 간격을 맞추는 `text-align`, `line-height`
* 밑줄을 제어하고 글자 간격을 조정하는 `text-decoration`, `letter-spacing`

## 1. 글꼴 지정하기: `font-family`

`font-family` 속성은 텍스트에 적용할 서체(글꼴)를 지정할 때 사용합니다. 

웹 브라우저는 기본적으로 **사용자의 컴퓨터에 실제로 설치되어 있는 글꼴**만을 화면에 그려줄 수 있습니다. 만약 개발자가 웹사이트 디자인을 위해 특정 폰트를 지정했더라도, 방문자의 컴퓨터에 그 폰트가 없다면 브라우저는 제멋대로 기본 시스템 서체(예: 굴림, 돋움 등)로 글씨를 보여주게 됩니다.

이러한 문제를 예방하기 위해 `font-family`를 선언할 때는 쉼표(`,`)를 사용하여 <b>여러 개의 예비 글꼴(Fallback Fonts)</b>을 순서대로 적어두는 것이 일반적입니다.

```css
body {
    font-family: "Malgun Gothic", "맑은 고딕", AppleSDGothicNeo, sans-serif;
}
```

### 작동 원리
1. 브라우저는 가장 먼저 작성된 `"Malgun Gothic"`이 사용자의 컴퓨터에 설치되어 있는지 확인하고, 있다면 적용합니다.
2. 없다면 두 번째 지정된 `"맑은 고딕"`을 적용합니다.
3. 이마저도 없다면 세 번째 `AppleSDGothicNeo`를 적용합니다.
4. 모든 예비 글꼴이 없을 때를 대비하여, 맨 마지막에는 어떤 컴퓨터에나 반드시 존재하는 <b>범용 글꼴 분류(Generic Family)</b>를 적어두어 최소한의 디자인 일관성을 유지합니다.

> [!NOTE]
> **범용 글꼴 분류의 대표 종류**
> * `sans-serif`: 삐침이 없는 고딕 계열의 서체 (예: 맑은 고딕, 돋움, Helvetica) -> 본문에 주로 사용
> * `serif`: 글자 끝에 삐침이 있는 명조 계열의 서체 (예: 바탕체, Times New Roman) -> 인쇄물이나 격식 있는 타이틀에 주로 사용
> * `monospace`: 글자들의 가로 폭이 모두 일정한 고정폭 서체 (예: Consolas, Courier) -> 코드 블록이나 수치 표기에 주로 사용

> [!TIP]
> **글꼴 이름에 공백이 있는 경우**\
> 맑은 고딕("Malgun Gothic")처럼 글꼴 이름 중간에 공백(띄어쓰기)이 포함된 경우에는 브라우저가 하나의 글꼴 이름으로 정확히 인식할 수 있도록 반드시 따옴표(`" "` 또는 `' '`)로 이름을 감싸주어야 합니다. 공백이 없는 영문 서체는 따옴표를 생략해도 작동합니다.

## 2. 글자 크기와 스타일: `font-size`, `font-weight`, `font-style`

### 1. 글자 크기 지정: `font-size`
글자의 크기를 조절하는 속성입니다. 사용할 수 있는 단위는 절대 단위와 상대 단위로 나뉩니다.

* **`px` (Pixel, 절대 단위):** 모니터의 화면 화소 단위를 기준으로 글자 크기를 고정합니다. 브라우저 설정이나 부모 요소의 크기에 영향을 받지 않고 직관적으로 크기를 제어할 수 있지만, 사용자가 브라우저 설정에서 기본 글자 크기를 키우더라도 크기가 변하지 않아 웹 접근성 측면에서는 다소 아쉬움이 남습니다.
* **`rem` (Root EM, 상대 단위):** 웹 문서의 **최상위 요소(보통 `<html>` 태그)의 기본 글자 크기**를 기준으로 몇 배수인지 결정하는 상대 단위입니다. 대부분 브라우저의 기본 글자 크기는 `16px`이므로, `1rem = 16px`, `1.5rem = 24px`가 됩니다. 반응형 웹 디자인을 설계할 때 가장 권장되는 단위입니다.
* **`em` (상대 단위):** 최상위가 아닌 **자신이 속한 바로 위 부모 요소의 글자 크기**를 기준으로 배수를 결정합니다. 중첩된 구조에서 글자 크기가 누적되어 계산되기 때문에 관리가 까다로울 수 있습니다.

```css
h1 {
    font-size: 2.5rem; /* 최상위 기본 글자 크기의 2.5배 */
}
p {
    font-size: 16px; /* 16픽셀로 고정 */
}
```

### 2. 글자 두께 지정: `font-weight`
글씨의 굵기를 조절하는 속성입니다.

* **키워드 값:** `normal`(일반 굵기), `bold`(굵게)
* **숫자 값:** `100`부터 `900`까지 100 단위의 숫자로 더 세밀하게 조정할 수 있습니다. (예: `400`은 일반 굵기, `700`은 대략 bold에 해당합니다.) 숫자가 클수록 글씨가 굵어집니다.

```css
.bold-text {
    font-weight: 700;
}
```
*(단, 숫자로 정교하게 제어하려면 해당 서체 파일 자체가 각 굵기별 세부 파일들을 포함하고 있어야 정상적으로 출력됩니다.)*

### 3. 글자 스타일 지정: `font-style`
글자를 기울임꼴(이탤릭체)로 변경할 때 주로 사용합니다.

```css
/* 텍스트를 오른쪽으로 비스듬히 기울입니다. */
.italic-text {
    font-style: italic;
}
```
`bold`를 사용해 대상을 볼드체로 변경할 수도 있습니다.

## 3. 문단 및 텍스트 정렬: `text-align`, `line-height`

### 1. 텍스트 정렬: `text-align`
문단 내부에서 텍스트의 가로 방향 정렬 방식을 결정합니다.

* `left` (기본값): 왼쪽 정렬
* `right`: 오른쪽 정렬
* `center`: 가운데 정렬
* `justify`: 양쪽 정렬 (글자 사이 간격을 조절하여 가로 끝 줄을 가지런히 맞춥니다.)

```css
.center-title {
    text-align: center;
}
```
*(주의: `text-align` 속성은 블록 상자 안의 텍스트나 인라인 요소에만 영향을 줍니다. 독립적인 블록 상자 자체를 페이지 가운데로 배치하는 원리와는 다릅니다.)*

### 2. 줄 간격(행간) 조절: `line-height`
글자의 윗줄과 아랫줄 사이의 수직 간격을 설정하는 속성입니다. 가독성을 확보하는 데 매우 중요한 역할을 합니다.

* **단위 없는 숫자 (추천):** 현재 지정된 글자 크기의 배수로 간격을 결정합니다. 예를 들어 글자 크기가 `16px`일 때 `line-height: 1.5;`로 지정하면 줄 간격은 24px(`16 * 1.5`)이 됩니다. 글자 크기가 바뀌어도 유연하게 대응하므로 가장 권장되는 작성법입니다.
* **단위 지정 (`px`, `rem` 등):** 간격을 특정 수치로 고정합니다.

```css
p {
    font-size: 1rem;
    line-height: 1.6; /* 글자 크기의 1.6배만큼 줄 간격을 확보하여 가독성을 높입니다. */
}
```

## 4. 기타 유용한 텍스트 꾸밈 속성

### 1. 텍스트 장식선 설정: `text-decoration`
글자에 밑줄을 긋거나 취소선을 긋는 등의 시각적인 효과를 줍니다.

* `underline`: 텍스트 밑에 선을 긋습니다.
* `line-through`: 텍스트 중간에 관통하는 취소선을 긋습니다.
* `none`: 적용되어 있던 선을 모두 제거합니다.

```css
/* 하이퍼링크(a) 태그가 기본으로 가진 파란색 밑줄을 강제로 지울 때 매우 자주 쓰입니다. */
a {
    text-decoration: none;
}
```

### 2. 자간(글자 간격) 조절: `letter-spacing`
글자와 글자 사이의 가로 여백을 미세하게 조절합니다. 폰트의 특성에 따라 기본 자간이 지나치게 멀거나 가깝게 보일 때 이 속성으로 레이아웃 균형을 맞춥니다. 음수 값도 지정할 수 있습니다.

```css
h1 {
    /* 글자 사이를 아주 미세하게 좁혀서 제목을 더 단단해 보이게 만듭니다. */
    letter-spacing: -0.05em;
}
```
