# CSS 고급 선택자 (Advanced Selectors)

## 개요
이전 모듈에서 우리는 특정 요소를 꾸미기 위해 태그 이름, 클래스(`.`), 아이디(`#`)를 활용하는 '기본 선택자'를 배웠습니다. 하지만 웹 페이지의 HTML 복잡해지면, 스타일을 적용할 때마다 수십 개의 태그에 일일이 클래스 이름을 붙여주는 것은 대단히 번거롭고 비효율적인 작업이 됩니다.

본 문서에서는 HTML 문서의 <b>구조적인 관계(부모, 자식, 형제)</b>를 이용하거나, **특정 속성값**, 혹은 **사용자의 마우스 움직임 같은 특정 상태**를 감지하여 요소를 정밀하게 타격(Targeting)하는 **고급 선택자**들에 대해 학습합니다. 이 선택자들을 자유자재로 다루게 되면 HTML 코드를 훨씬 깔끔하게 유지하면서도 원하는 디자인을 마음껏 입힐 수 있습니다.

### 이 모듈에서 배울 내용
* 요소 간의 계층 관계를 이용하는 연결 선택자 (` `, `>`, `+`, `~`)
* HTML 태그의 특정 속성값을 추적하는 속성 선택자 (`[attr]`)
* 요소의 특정 상태나 순서를 감지하는 가상 클래스 (`:hover`, `:nth-child`)
* HTML에 존재하지 않는 가상의 요소를 만들어내는 가상 요소 (`::before`, `::after`)

## 1. 연결 선택자 (Combinators)

연결 선택자는 HTML 요소들이 맺고 있는 부모, 자식, 형제 관계를 기호로 연결하여 대상을 좁혀나가는 방식입니다.

### 1. 하위(자손) 선택자 : `공백(Space)`
특정 요소의 **내부에 있는 모든 해당 요소**를 선택합니다. 직계 자식뿐만 아니라 손자, 증손자 요소까지 전부 찾아냅니다.
```css
/* section 태그 안쪽에 있는 '모든' p 태그를 선택합니다. */
section p {
    color: blue;
}
```

### 2. 자식 선택자 : `>`
특정 요소의 **바로 아래에 있는 직계 자식**만 선택합니다. 그보다 더 깊숙한 곳에 있는 태그는 무시합니다.
```css
/* ul 태그의 직계 자식인 li 태그만 선택합니다. */
ul > li {
    border: 1px solid black;
}
```

### 3. 인접 형제 선택자 : `+`
같은 부모를 가진 형제 요소 중, **나와 바로 딱 붙어서 뒤에 나오는 첫 번째 동생 요소** 단 하나만 선택합니다.
```css
/* h1 태그 '바로 뒤'에 나오는 첫 번째 p 태그만 선택합니다. */
h1 + p {
    font-weight: bold;
}
```

### 4. 일반 형제 선택자 : `~`
같은 부모를 가진 형제 요소 중, **내 뒤에 나오는 모든 동생 요소**들을 선택합니다.
```css
/* h2 태그 뒤에 등장하는 모든 p 태그들을 선택합니다. */
h2 ~ p {
    color: gray;
}
```

## 2. 속성 선택자 (Attribute Selectors)

HTML 태그가 가진 특정 속성이나 속성값을 기준으로 요소를 선택합니다. 특히 `<input>` 태그나 `<a>` 태그를 다룰 때 클래스 이름 없이도 요소를 구분할 수 있어 아주 유용합니다. 대괄호 `[ ]`를 사용합니다.

* **`[속성이름]`**: 특정 속성을 가지고 있기만 하면 선택합니다.
* **`[속성이름="값"]`**: 속성값이 정확히 일치하는 요소를 선택합니다.

```css
/* target 속성을 가진 모든 링크 선택 */
a[target] {
    text-decoration: underline;
}

/* type이 text인 입력창만 골라서 선택 */
input[type="text"] {
    border: 2px solid blue;
}
```

> [!TIP]
> **문자열 필터링 속성 선택자**
> * `[href^="https"]`: "https"로 **시작하는** 요소 선택 (`^=` 기호)
> * `[href$=".pdf"]`: ".pdf"로 **끝나는** 요소 선택 (`$=` 기호) (PDF 파일 링크 솎아내기)
> * `[class*="btn"]`: 클래스명에 "btn"이 **포함된** 요소 선택 (`*=` 기호)

## 3. 가상 클래스 (Pseudo-classes)

HTML 요소의 이름표가 아니라, <b>요소가 처한 '특정 상태'나 '순서'</b>를 가상으로 인식하여 선택합니다. 선택자 뒤에 콜론(`:`) 한 개를 붙여 사용합니다.

### 1. 사용자 행동(상태) 관련 가상 클래스
* `:hover`: 사용자가 마우스 커서를 요소 위에 올려놓았을 때 (실무에서 버튼이나 링크에 무조건 사용됨)
* `:active`: 마우스로 요소를 클릭(누르고 있는)하는 순간
* `:focus`: 입력창(`<input>`) 등을 클릭하여 커서가 깜빡이며 포커스가 맞춰졌을 때

```css
/* 버튼에 마우스를 올렸을 때 배경색이 바뀝니다. */
.submit-btn:hover {
    background-color: darkblue;
}

/* 텍스트 입력창을 클릭하여 글을 쓸 준비가 되면 테두리가 빨개집니다. */
input[type="text"]:focus {
    outline: 2px solid red;
}
```

### 2. 순서 가상 클래스
형제 요소들 사이에서 몇 번째에 위치하는지에 따라 요소를 선택합니다.
* `:first-child`: 형제 요소 중 첫 번째 요소
* `:last-child`: 형제 요소 중 마지막 요소
* `:nth-child(n)`: 형제 요소 중 **n번째** 요소. 숫자뿐만 아니라 수식을 넣을 수도 있습니다. (예: `2n`은 짝수, `2n+1`은 홀수)

```css
/* 목록의 제일 첫 번째 항목만 글씨를 빨간색으로 */
li:first-child {
    color: red;
}

/* 표의 짝수 번째 가로행(tr)마다 배경색을 칠함 (얼룩말 패턴 표 만들기!) */
tr:nth-child(even) {
    background-color: #f2f2f2;
}
```

## 4. 가상 요소 (Pseudo-elements)

가상 요소는 HTML 코드에는 존재하지 않지만, <b>CSS를 이용해 화면상에 가짜 요소를 창조해 내거나 텍스트의 일부분만 특별히 선택</b>할 때 사용합니다. CSS3부터는 가상 클래스(`:`)와 구분하기 위해 콜론 두 개(`::`)를 사용하는 것이 표준입니다.

### 1. 새로운 콘텐츠를 창조하는 `::before`와 `::after`
선택한 요소의 내용물 바로 앞(`before`)이나 바로 뒤(`after`)에 새로운 가상의 요소를 찔러 넣습니다. 
이 속성을 사용할 때는 **반드시 `content` 속성을 함께 써주어야 작동**합니다. 아이콘을 텍스트 옆에 붙이거나, 레이아웃의 장식 선을 만들 때 매우 유용합니다.

```css
/* 'best-item' 클래스가 붙은 요소의 텍스트 맨 앞에 별 이모지를 삽입합니다. */
.best-item::before {
    content: "⭐ "; /* 삽입할 가상의 텍스트나 기호 */
    color: gold;
}

/* 링크 요소 뒤에 작은 화살표를 덧붙입니다. */
.external-link::after {
    content: " ↗";
    font-size: 0.8em;
}
```

### 2. 텍스트의 일부를 꾸미는 가상 요소
* `::first-line`: 문단(`<p>`)의 내용 중 브라우저 화면에 보여지는 **첫 번째 줄**만 선택합니다.
* `::first-letter`: 문단의 **가장 첫 번째 글자**만 선택합니다. 뉴스 기사나 잡지에서 첫 글자를 아주 크게 키우는 타이포그래피 기법에 주로 쓰입니다.

```css
p::first-letter {
    font-size: 3em;      /* 첫 글자만 엄청나게 크게 */
    font-weight: bold;
    float: left;         /* 텍스트가 첫 글자를 감싸도록 float 처리 */
    margin-right: 10px;
}
```
