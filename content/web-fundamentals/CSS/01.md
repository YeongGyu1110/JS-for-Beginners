# CSS의 기초와 스타일 적용 방법

## 개요
이전 모듈까지 우리는 HTML을 사용해 웹 페이지의 구조를 설계하고 텍스트, 이미지, 링크, 폼 등 다양한 요소를 배치하는 방법을 배웠습니다. 하지만 HTML만으로 구성된 웹 페이지는 90년대 초반의 투박한 문서처럼 보입니다. 여기에 색상을 입히고, 정렬을 맞추고, 아름다운 서체를 적용하여 현대적인 웹 페이지로 탈바꿈시켜 주는 기술이 바로 **CSS**입니다.

본 문서에서는 웹 디자인의 핵심 기술인 CSS의 기본적인 개념을 이해하고, 단일 '스타일'과 이를 모아둔 '스타일 시트'가 어떻게 다른지 알아봅니다. 또한 웹 페이지에 CSS를 적용하는 대표적인 3가지 방법의 장단점을 살펴보고, CSS 코드를 작성할 때 반드시 알아야 하는 문법의 기초를 다룹니다.

### 이 모듈에서 배울 내용
* CSS(Cascading Style Sheets)의 개념과 역할
* 스타일(Style)과 스타일 시트(Style Sheet)의 구분
* CSS를 웹 문서에 적용하는 3가지 방법 (인라인, 내부, 외부)
* CSS 규칙(Rule)을 구성하는 선택자, 속성, 값의 기본 구조

## 1. CSS란 무엇인가?

CSS는 **C**ascading **S**tyle **S**heets의 약자로, HTML 문서의 시각적인 표현(디자인과 레이아웃)을 정의하는 스타일 시트 언어입니다.

HTML이 건물의 뼈대를 세우고 방을 나누는 '철골 공사'라면, CSS는 벽지를 바르고, 가구를 배치하고, 예쁜 조명을 다는 '인테리어 공사'에 비유할 수 있습니다. HTML이 정보의 구조를 담당하고, CSS는 그 정보가 사용자에게 어떻게 보일지(시각적 표현)를 전송받아 제어합니다.

이렇게 웹 디자인과 구조를 분리하면 다음과 같은 실무적인 이점이 있습니다.
* **디자인의 일관성 유지:** 웹사이트 전체의 글자 색상이나 배경을 한 번에 제어할 수 있습니다.
* **유지보수의 편리함:** 웹 페이지의 구조(HTML)를 건드리지 않고 디자인(CSS)만 수정하여 사이트의 전반적인 분위기를 손쉽게 바꿀 수 있습니다.

### 스타일(Style)과 스타일 시트(Style Sheet)
* **스타일(Style):** 글자 크기, 글자 색상, 배경색, 여백 등 웹 페이지 요소에 지정하는 개별적인 시각적 속성을 의미합니다.
* **스타일 시트(Style Sheet):** 이러한 스타일 규칙들을 체계적으로 모아둔 문서나 코드의 집합을 말합니다. 여러 HTML 문서가 하나의 스타일 시트를 공유하여 동일한 디자인 테마를 갖도록 유도할 수 있습니다.

## 2. CSS의 기본 문법 구조

CSS는 HTML처럼 꺾쇠 괄호(`< >`)를 사용하지 않고, 고유의 문법 규칙을 따릅니다. CSS 코드는 기본적으로 **"무엇을(대상), 어떻게(속성과 값)"** 꾸밀지 결정하는 구조로 작성됩니다.

```css
선택자 {
    속성: 값;
    속성: 값;
}
```

이 구조를 구성하는 세 가지 핵심 요소는 다음과 같습니다.

* **선택자 (Selector):** 스타일을 적용할 대상을 지정합니다. "어떤 HTML 요소를 꾸밀 것인가"를 결정하는 부분입니다. (예: `h1`, `p`, `div` 등)
* **속성 (Property):** 선택한 대상에서 바꾸고 싶은 구체적인 항목(스타일 변수)입니다. 콜론(`:`) 앞에 위치합니다. (예: `color`, `font-size`, `background-color`)
* **값 (Value):** 해당 속성에 부여할 실제 스타일 결과입니다. 속성명 뒤에 작성하며, 한 줄의 스타일 설정이 끝나면 반드시 세미콜론(`;`)을 붙여 구분을 지어주어야 합니다. (예: `blue`, `20px`, `red`)

```css
/* 예시: 모든 h1 태그의 글자 색상을 파란색으로 바꾸고 글자 크기를 24픽셀로 설정 */
h1 {
    color: blue;
    font-size: 24px;
}
```

> [!NOTE]
> **CSS 주석 작성법**\
> CSS 코드 내에서 브라우저가 실행하지 않고 개발자만 볼 수 있는 메모를 남길 때는 `/* 주석 내용 */` 형태로 작성합니다. HTML의 주석 기호(`<!-- -->`)와 혼동하지 않도록 유의하세요.

## 3. 웹 페이지에 스타일을 적용하는 3가지 방법

작성한 CSS 코드를 HTML 문서와 결합하여 화면에 반영하는 방법은 크게 세 가지가 있습니다. 상황과 규모에 따라 알맞은 방식을 선택하여 사용합니다.

### 방법 1. 인라인 스타일 (Inline Style)
HTML 태그 내부에 `style` 속성을 직접 사용하여 해당 요소에만 스타일을 바로 적용하는 방식입니다.

```html
<h1 style="color: red; font-size: 20px;">인라인 스타일 예시</h1>
<p>이 문단에는 스타일이 적용되지 않습니다.</p>
```
* **장점:** 별도의 설정 없이 특정 태그 하나에 신속하게 스타일을 임시 적용할 수 있습니다.
* **단점:** 디자인과 구조가 완전히 뒤섞여 코드가 지저분해지고, 동일한 스타일을 여러 태그에 반복 적용해야 할 때 수정이 극히 번거로워집니다. 현업에서는 특별한 경우가 아니면 사용을 피하는 것을 권장합니다.

### 방법 2. 내부 스타일 시트 (Internal Style Sheet)
HTML 문서 내부의 `<head>` 태그 영역 안에 `<style>` 태그를 열고, 그 안에 CSS 코드를 모아 작성하는 방식입니다.

```html
<head>
    <meta charset="UTF-8">
    <title>내부 스타일 시트 예시</title>
    <style>
        /* 이 문서 안의 모든 p 태그에 일괄 적용됩니다. */
        p {
            color: green;
            line-height: 1.6;
        }
    </style>
</head>
<body>
    <p>첫 번째 문단입니다.</p>
    <p>두 번째 문단도 녹색으로 표현됩니다.</p>
</body>
```
* **장점:** HTML 문서 하나 안에서 스타일을 일괄 제어할 수 있으며, 구조와 스타일이 한 파일에 있어 비교적 규모가 작은 단일 페이지 웹사이트를 만들 때 유용합니다.
* **단점:** 웹사이트의 페이지 수가 늘어나면(예: 수십 개의 HTML 파일), 파일마다 일일이 스타일 코드를 복사해서 붙여넣어야 하므로 전반적인 관리의 비효율성이 발생합니다.

### 방법 3. 외부 스타일 시트 (External Style Sheet)
CSS 코드를 HTML 파일과 분리하여 확장자가 `.css`인 별도의 독립 파일로 저장하고, HTML의 `<head>` 영역 안에서 `<link>` 태그를 사용해 불러오는 방식입니다. **현대 웹 개발에서 표준으로 사용하는 가장 정석적인 방법**입니다.

우선, `style.css`라는 파일을 하나 생성하고 아래와 같이 CSS 코드만 작성합니다. (HTML 태그를 적지 않습니다.)

```css
/* style.css 파일 내용 */
body {
    background-color: #f4f4f4;
}
h1 {
    color: darkblue;
}
```

이후 스타일을 적용할 HTML 문서의 `<head>` 구역에서 다음과 같이 연결합니다.

```html
<head>
    <meta charset="UTF-8">
    <title>외부 스타일 시트 예시</title>
    <!-- link 태그를 사용해 css 파일을 외부에서 불러옵니다. -->
    <link rel="stylesheet" href="./style.css">
</head>
<body>
    <h1>외부 파일로 스타일을 입혔습니다.</h1>
</body>
```

* **장점:** HTML은 구조에만 집중하고, CSS는 스타일에만 집중할 수 있어 코드 관리가 대단히 깔끔해집니다. 수백 개의 HTML 페이지가 있더라도 외부 CSS 파일 하나만 수정하면 사이트 전체의 디자인을 단번에 바꿀 수 있습니다.
* **단점:** 연결할 파일의 경로(`href`)를 잘못 지정하면 스타일이 전혀 로드되지 않으므로 상대 경로 지정에 주의해야 합니다.

> [!IMPORTANT]
> **`<link>` 태그의 필수 속성**\
> 외부 스타일 시트를 연결할 때는 빈 태그인 `<link>`를 사용하며, 다음 속성이 올바르게 작성되었는지 확인해야 합니다.
> * `rel`: 관계(Relation)를 의미하며, 불러올 파일이 스타일 시트임을 브라우저에 알려주기 위해 반드시 `rel="stylesheet"`로 고정 기입합니다.
> * `href`: 연결할 외부 CSS 파일의 경로를 상대 경로 혹은 절대 경로로 올바르게 적어줍니다.

## 4. CSS 기본 선택자 (Basic Selectors)

선택자(Selector)는 디자인을 적용할 HTML 요소를 조준하는 조준경과 같습니다. HTML 문서 내의 수많은 태그 중 내가 원하는 요소만 정확히 골라내기 위해 CSS는 다양한 종류의 선택자를 제공합니다. 그중 가장 기본적이면서 실무에서 자주 쓰이는 4가지 기본 선택자를 알아봅니다.

### 1. 전체 선택자 (Universal Selector) : `*`
키보드의 별표 기호(`*`)를 사용하여 **웹 페이지 내부의 모든 요소**를 한꺼번에 선택합니다. 브라우저가 기본적으로 가지고 있는 여백을 초기화(Reset)하는 용도로 주로 사용합니다.

```css
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}
```

### 2. 태그 선택자 (Type Selector) : `태그이름`
HTML 태그의 이름을 그대로 적어, **해당 태그를 가진 모든 요소를 일괄 선택**합니다. 

```css
/* 페이지 안의 모든 p 태그의 글자 크기를 16픽셀로 설정 */
p {
    font-size: 16px;
}
```

### 3. 클래스 선택자 (Class Selector) : `.클래스이름`
HTML 태그에 부여된 `class` 속성값을 기준으로 요소를 선택합니다. 클래스 이름 앞에는 <b>반드시 마침표(`.`)</b>를 붙여야 브라우저가 클래스 선택자로 인식합니다. 

웹 페이지 안에서 **여러 개의 요소에 중복하여 동일한 스타일을 적용**하고 싶을 때 가장 널리 사용됩니다.

```html
<!-- HTML -->
<p class="highlight">이 문단은 강조됩니다.</p>
<span class="highlight">이 글자도 똑같이 강조됩니다.</span>
```
```css
/* CSS */
.highlight {
    background-color: yellow;
    font-weight: bold;
}
```

### 4. 아이디 선택자 (ID Selector) : `#아이디이름`
HTML 태그에 부여된 `id` 속성값을 기준으로 요소를 선택합니다. 아이디 이름 앞에는 <b>반드시 우물 정 기호(`#`)</b>를 붙여야 합니다. 

이전 하이퍼링크 모듈에서 배운 것처럼, `id`는 웹 문서 내에서 **오직 단 하나만 존재하는 고유한 식별자**여야 합니다. 따라서 특정 하나의 요소에만 아주 특별한 디자인을 입히고 싶을 때 제한적으로 사용합니다.

```html
<!-- HTML -->
<div id="main-header">웹사이트의 메인 상단 영역입니다.</div>
```
```css
/* CSS */
#main-header {
    background-color: #333;
    color: white;
    height: 80px;
}
```

## 5. 캐스케이딩(Cascading)

CSS의 첫 글자인 <b>Cascading(캐스케이딩)</b>은 '위에서 아래로 흐르는 폭포수'라는 뜻을 가지고 있습니다. 

하나의 HTML 요소에 여러 개의 스타일이 복합적으로 적용되거나 서로 충돌할 때, **어떤 스타일을 최종적으로 화면에 보여줄지 결정하는 우선순위 규칙**을 캐스케이딩이라고 부릅니다. 브라우저가 이 충돌을 해결하기 위해 따르는 3가지 핵심 기준이 있습니다.

---

### 기준 1: 스타일 우선순위 (명시도, Specificity)
선택자의 종류에 따라 점수(가중치)가 다르게 매겨지며, 더 구체적으로 대상을 지정하는 선택자일수록 우선순위가 높습니다. 점수가 높은 스타일이 낮은 스타일을 덮어씁니다.

| 선택자 종류 | 예시 | 점수 (명시도 무게) | 우선순위 |
| :--- | :--- | :--- | :--- |
| **`!important` 선언** | `color: red !important;` | 측정 불가 (가장 강력) | 1순위 |
| **인라인 스타일** | `<p style="color: blue;">` | 1000점 | 2순위 |
| **아이디 선택자** | `#title { ... }` | 100점 | 3순위 |
| **클래스 선택자** | `.highlight { ... }` | 10점 | 4순위 |
| **태그 선택자** | `p { ... }` | 1점 | 5순위 |
| **전체 선택자** | `* { ... }` | 0점 | 6순위 |

```css
/* 태그 선택자 (1점) */
p { color: blue; }

/* 클래스 선택자 (10점) */
.text-red { color: red; }

/* 결과적으로 아래 클래스 속성을 가진 p 태그는 10점짜리인 'red'가 최종 반영됩니다. */
```

> [!WARNING]
> **`!important` 사용 주의**\
> 속성 값 뒤에 `!important`를 붙이면 우선순위 점수 체계를 완전히 무시하고 무조건 1순위로 렌더링됩니다. 이는 추후 스타일을 수정하거나 디버깅할 때 다른 스타일이 적용되지 않는 원인이 될 수 있으므로, 실무에서는 꼭 필요한 상황이 아니라면 사용을 자제하는 것이 바람직합니다.

---

### 기준 2: 스타일 상속 (Inheritance)
HTML 요소들은 부모와 자식 관계(포함 관계)를 맺는다고 배웠습니다. CSS의 특정 속성들은 **부모 요소에 스타일을 지정하면 자식 요소들에게도 그 스타일이 자연스럽게 물려내려 가는데**, 이를 상속이라고 합니다.

* **상속되는 속성들 (주로 글자/텍스트 관련):** `font-family`, `font-size`, `color`, `text-align` 등
* **상속되지 않는 속성들 (주로 레이아웃/박스 관련):** `margin`, `padding`, `border`, `width`, `height` 등

```html
<!-- HTML -->
<div style="color: green;">
    <!-- 부모인 div에 녹색 글자를 지정했습니다. -->
    <p>자식인 p 태그도 자동으로 녹색 글자로 렌더링됩니다. (스타일 상속)</p>
</div>
```

### 기준 3: 코드 순서에 의한 우선순위 (Source Order)
우선순위 점수(명시도)가 완전히 동일한 스타일이 충돌하는 경우, **CSS 파일 내에서 가장 마지막(아래쪽)에 작성된 코드**가 최종적으로 살아남아 화면에 그려집니다. 브라우저가 위에서 아래로 코드를 읽어 내려가면서 덮어쓰기 때문입니다.

```css
p {
    color: red;
}

/* 아래쪽에 작성된 스타일이 동일한 점수(태그 선택자 1점)이므로 위 스타일을 덮어씁니다. */
p {
    color: blue; /* 최종 반영 */
}
```

## 요약

CSS를 처음 다룰 때는 단순히 디자인 속성을 외우는 것보다 스타일이 올바르게 전달되고 제어되는 원리를 파악하는 것이 중요합니다.
* 구조(HTML)와 표현(CSS)을 분리하여 관리하는 **외부 스타일 시트** 작성이 권장됩니다.
* 스타일을 입힐 대상을 정밀하게 고르기 위해 **태그, 클래스(`.`), 아이디(`#`) 선택자**를 조합하여 사용합니다.
* 여러 스타일이 얽히고설킬 때는 <b>선택자의 가중치(명시도)</b>와 **코드 작성 순서**에 따라 최종 디자인이 확정되는 캐스케이딩의 규칙을 따르게 됩니다.
