# 목록 스타일링 (List Style)

## 개요
HTML에서 목록을 정의하는 `<ul>`과 `<ol>` 태그는 기본적으로 각 항목 앞에 까만 점(Bullet)이나 순서대로 올라가는 숫자(Number)를 자동으로 붙여주어 정보를 구조화합니다. 하지만 디자이너가 요청한 예쁜 불릿 기호를 적용하거나, 혹은 목록 태그를 활용해 웹사이트 상단의 가로형 메뉴바(Navigation Bar)를 만들고 싶을 때는 이 기본 스타일들이 오히려 방해가 되기도 합니다.

본 문서에서는 목록 기호의 형태와 위치를 제어하는 스타일 속성을 알아보고, 최종적으로 기본 불릿을 말끔하게 지워낸 뒤 목록 태그를 실무 레이아웃(메뉴바 등)에 어떠한 방식으로 응용하는지 학습합니다.

### 기본 요건
이 실습은 사용자가 다음에 익숙하다는 가정하에 진행됩니다.

 - CSS 텍스트 스타일링 기초
 - HTML 목록 태그 구조: `<ul>`, `<ol>`, `<li>` 태그의 계층적인 부모-자식 마크업 작성법

### 이 모듈에서 배울 내용
* 목록 기호의 모양을 바꾸는 `list-style-type`
* 이미지 파일로 목록 기호를 대신하는 `list-style-image`
* 목록 기호의 위치를 여백 안팎으로 조정하는 `list-style-position`
* 스타일 속성들을 한 번에 적는 단축 속성 `list-style`
* 기본 불릿을 제거하고 목록 태그를 가로형 메뉴바 레이아웃으로 변환하는 실무 응용법

---

## 1. 목록 기호 모양 제어: `list-style-type`

`list-style-type` 속성은 목록 항목(`<li>`) 앞에 붙는 불릿이나 번호의 종류를 지정합니다. `<ul>`(순서 없음)과 `<ol>` (순서 있음) 모두 이 속성을 통해 기호의 형태를 자유롭게 바꿀 수 있습니다.

### 순서 없는 목록(`<ul>`)에 자주 쓰이는 값
* `disc` (기본값): 까만 채워진 원
* `circle`: 속이 빈 원
* `square`: 채워진 사각형
* `none`: **목록 기호를 완전히 없앱니다.** (가장 자주 사용)

### 순서 있는 목록(`<ol>`)에 자주 쓰이는 값
* `decimal` (기본값): 아라비아 숫자 (1, 2, 3...)
* `lower-alpha` / `upper-alpha`: 영문 소문자/대문자 (a, b, c... / A, B, C...)
* `lower-roman` / `upper-roman`: 로마 숫자 소문자/대문자 (i, ii, iii... / I, II, III...)

```css
/* 목록의 기본 불릿을 사각형 모양으로 바꿉니다. */
ul {
    list-style-type: square;
}

/* 순서 목록의 기호를 로마 숫자 대문자로 바꿉니다. */
ol {
    list-style-type: upper-roman;
}
```

---

## 2. 불릿 이미지와 배치 위치: `list-style-image`, `list-style-position`

### 1. 이미지 불릿 지정: `list-style-image`
기본 도형 대신 직접 디자인한 아이콘이나 이미지 파일을 목록 기호로 사용하고 싶을 때 사용합니다.

```css
ul {
    /* url() 경로 안에 이미지 파일의 경로를 적어줍니다. */
    list-style-image: url('./images/check-icon.png');
}
```
*(다만 이미지의 크기가 너무 크면 목록 텍스트의 정렬과 어긋나 보일 수 있으므로, 최근 실무에서는 이 속성 대신 뒤에서 배울 배경 이미지 속성(`background-image`)이나 아이콘 폰트를 이용하는 방식을 더 선호합니다.)*

### 2. 기호의 위치 지정: `list-style-position`
목록 기호(점이나 숫자)를 텍스트 상자의 안쪽 공간에 배치할지, 아니면 바깥쪽 공간으로 내어 쓸지 결정합니다.

* `outside` (기본값): 기호가 텍스트 상자 영역 바깥에 위치합니다. 항목이 줄바꿈되어 다음 줄로 넘어갈 때, 기호 아래쪽 공간이 깨끗하게 비어 정돈된 느낌을 줍니다.
* `inside`: 기호가 텍스트 상자 안쪽으로 들어옵니다. 문장이 길어져 줄바꿈이 일어날 때, 기호의 수직 라인 아래로 텍스트가 밀고 들어오게 됩니다.

```css
li {
    list-style-position: inside;
}
```

---

## 3. 한 줄로 축약하기: `list-style`

위에서 설명한 `type`, `position`, `image` 속성들을 일일이 길게 적을 필요 없이, <b>`list-style`</b>이라는 하나의 단축 속성을 통해 공백으로 구분하여 한 줄로 간단하게 통합해서 적을 수 있습니다.

```css
/* 기호 모양은 사각형으로 하고, 상자 안쪽에 위치시킵니다. */
ul {
    list-style: square inside;
}

/* 목록 기호를 깔끔하게 없앨 때도 이 단축 속성이 요긴하게 쓰입니다. */
li {
    list-style: none;
}
```

## 4. 실무 응용: 기본 스타일 초기화와 내비게이션 바 제작

현대 웹 퍼블리싱 및 프론트엔드 실무에서 `<ul>`과 `<li>` 태그는 단순히 리스트 데이터를 나열하는 용도 외에도, **내비게이션 메뉴바나 카드 레이아웃의 구조를 잡는 뼈대**로 활발히 사용됩니다. 

이를 위해 기본 목록 스타일을 지워버리는 '초기화(Reset)' 코드와 가로형 메뉴바를 구성하는 간단한 예제를 소개합니다.

### 1단계: 목록의 기본 스타일 지우기 (초기화)
브라우저는 기본적으로 목록 태그 주위에 약간의 마진(외부 여백)과 패딩(내부 여백), 그리고 불릿 기호를 기본 장착하고 있습니다. 레이아웃 배치를 방해하는 이 기본 요소들을 깔끔하게 비워내는 기본 코드입니다.

```css
ul.nav-menu {
    list-style: none; /* 불릿 제거 */
    margin: 0;        /* 브라우저 기본 외부 여백 제거 */
    padding: 0;       /* 브라우저 기본 내부 여백 제거 */
}
```

### 2단계: 가로형 메뉴바 구조 및 스타일 구현
기본 스타일이 해제된 목록의 항목(`<li>`)들을 가로 방향으로 정렬하여 웹사이트 상단 메뉴바의 원리를 구현하는 예시입니다.

```html
<!-- HTML -->
<nav>
    <ul class="nav-menu">
        <li><a href="#">홈</a></li>
        <li><a href="#">회사 소개</a></li>
        <li><a href="#">서비스</a></li>
        <li><a href="#">고객 지원</a></li>
    </ul>
</nav>
```

```css
/* CSS */

/* 1. 목록 초기화 */
.nav-menu {
    list-style: none;
    margin: 0;
    padding: 0;
    background-color: #222; /* 어두운 배경색 설정 */
    display: flex;          /* 자식 요소들을 가로 정렬하기 위해 플렉스 박스 적용 */
}

/* 2. 각 메뉴 항목들 스타일링 */
.nav-menu li {
    /* 필요한 경우 li 내부에 여백을 줄 수 있습니다. */
}

/* 3. 메뉴 링크(a) 스타일링 */
.nav-menu a {
    display: block;         /* 클릭 영역을 넓히기 위해 블록 요소로 변경 */
    color: white;           /* 글자색을 하얗게 */
    text-decoration: none;  /* 기본 밑줄 제거 */
    padding: 15px 20px;     /* 상하좌우 안쪽 여백 설정 */
}

/* 마우스를 올렸을 때 배경색 변환 효과 */
.nav-menu a:hover {
    background-color: #444;
}
```

> [!IMPORTANT]
> **왜 메뉴바를 굳이 `<ul>`과 `<li>`로 만드나요?**\
> 단순 글자 링크인 `<a>` 태그들만 주르륵 나열해도 눈으로 보기에 똑같은 메뉴바를 완성할 수 있습니다. 하지만 시각장애인용 화면 낭독기나 검색 엔진의 로봇은 이 메뉴들이 '서로 연관된 하나의 메뉴 묶음(그룹)'이라는 사실을 인지하기 어렵습니다. 
> 
> `<ul>`(목록) 안에 `<li>`(항목)들로 메뉴를 감싸 구성하면, 컴퓨터가 상호 연관된 항목들의 집합임을 구조적으로 명확히 해석할 수 있어 **웹 접근성과 의미론적 마크업(Semantic Markup)** 관점에서 매우 훌륭한 작성법이 됩니다.
