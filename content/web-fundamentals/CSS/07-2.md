# CSS 레이아웃의 기초 2부: Position과 좌표 제어

## 개요
앞서 1부에서 살펴본 `display`와 `float`이 문서의 자연스러운 흐름 속에서 요소들을 밀고 당기며 배치하는 방법이었다면, 이번에 배울 기술은 **요소를 콕 집어서 내가 원하는 정확한 화면 좌표에 강제로 꽂아 넣는 방법**입니다.

본 문서(2부)에서는 요소를 화면의 특정 위치에 고정하거나, 다른 요소 위에 겹치게 만드는 등 자유도 높은 배치를 가능하게 하는 **`position`** 속성에 대해 학습합니다. 더불어, 위치를 지정할 때 사용하는 방향 속성(`top`, `bottom`, `left`, `right`)과 요소들이 겹쳤을 때 위아래 순서를 정해주는 `z-index`의 개념까지 완벽하게 파헤쳐 봅니다.

### 기본 요건
이 실습은 사용자가 다음에 익숙하다는 가정하에 진행됩니다.
* HTML 부모-자식 및 조상 요소 계층 구조
* 웹 문서의 일반적인 렌더링 흐름 (Normal Flow): HTML 요소들이 기본적으로 화면을 차지하며 위에서 아래로 쌓이는 방식에 대한 인지

### 이 모듈에서 배울 내용
* 요소의 배치 기준점을 정하는 `position` (static, relative, absolute, fixed, sticky)
* 기준점으로부터 요소를 이동시키는 좌표 속성 (`top`, `bottom`, `left`, `right`)
* `absolute`를 사용할 때 부모 요소에 `relative`를 주어야 하는 이유
* 요소가 겹쳤을 때 z축(깊이) 순서를 제어하는 `z-index`

---

## 1. 좌표를 움직이는 방향 속성 (top, right, bottom, left)

CSS에서 요소의 위치를 이동시킬 때는 상, 하, 좌, 우 네 가지 방향 속성을 사용합니다. 
* `top`: 기준점의 위쪽(Top)에서부터 얼만큼 떨어질 것인가?
* `bottom`: 기준점의 아래쪽(Bottom)에서부터 얼만큼 떨어질 것인가?
* `left`: 기준점의 왼쪽(Left)에서부터 얼만큼 떨어질 것인가?
* `right`: 기준점의 오른쪽(Right)에서부터 얼만큼 떨어질 것인가?

**가장 중요한 대전제:** 이 방향 속성들은 요소의 `position` 속성이 기본값(`static`)일 때는 **아무리 숫자를 입력해도 절대 작동하지 않습니다.** 반드시 `position` 속성을 다른 값으로 변경해주어야만 비로소 요소가 움직이기 시작합니다.

---

## 2. 배치 기준점 정하기: `position`

`position` 속성은 요소를 이동시킬 때 <b>"무엇을 기준으로 움직일 것인가?"</b>를 결정하는 핵심 속성입니다.

### 1. 정적 배치 (`static` - 기본값)
모든 HTML 요소가 태어날 때부터 가지는 기본 상태입니다. HTML에 작성된 순서대로 위에서 아래로 차곡차곡 쌓입니다. 앞서 말했듯 `top`, `left` 등의 좌표 속성을 무시합니다.

### 2. 상대 배치 (`relative`)
* **기준점:** 요소가 원래 있어야 할 <b>자신의 기본 위치(`static`이었을 때의 위치)</b>가 기준이 됩니다.
* **특징:** 요소를 이동시켜도, 원래 있던 자리(빈 공간)는 다른 요소들이 침범하지 못하도록 그대로 보존됩니다. 줄을 서 있던 사람이 잠깐 옆으로 한 발짝 비켜섰지만, 그 자리는 여전히 자신의 자리로 맡아둔 것과 같습니다.

```css
.box {
    position: relative; /* 원래 자신의 위치를 기준으로 삼습니다. */
    top: 20px;          /* 위에서부터 아래로 20px 밀어냅니다. (아래로 이동) */
    left: 50px;         /* 왼쪽에서부터 오른쪽으로 50px 밀어냅니다. (우측으로 이동) */
}
```

### 3. 절대 배치 (`absolute`)
* **기준점:** 자신의 부모 요소(조상 요소 포함) 중, **`position`이 `static`이 아닌 요소**를 찾아 그곳을 0,0 기준점으로 삼습니다.
* **특징:** 원래 자신이 차지하던 공간을 완전히 포기하고 공중으로 붕 떠버립니다. 문서의 자연스러운 흐름에서 완전히 빠져나오기 때문에, 뒤에 있던 요소들이 빈자리를 채우러 위로 올라옵니다. 

> [!IMPORTANT]
> **실무 레이아웃의 핵심 공식: 부모는 relative, 자식은 absolute**\
> `absolute` 요소는 기준점이 될 부모를 찾기 위해 HTML 구조를 거슬러 올라갑니다. 만약 부모 중에 `relative`나 `absolute`가 하나도 없다면, <b>웹 브라우저의 전체 화면(Body)</b>을 기준으로 엉뚱한 곳으로 날아가 버립니다. 
> 
> 따라서 특정 박스(부모) 안에서 요소(자식)를 자유롭게 배치하고 싶다면, **반드시 부모 요소에 `position: relative;`를 쥐여주어 기준점(울타리)을 만들어 주어야 합니다.**

```html
<!-- HTML 구조 -->
<div class="parent-box">
    <div class="child-box">절대 배치 요소</div>
</div>
```
```css
/* CSS */
.parent-box {
    position: relative; /* 자식이 바깥으로 도망가지 못하게 가두는 기준점 역할 */
    width: 300px;
    height: 300px;
    background-color: lightgray;
}

.child-box {
    position: absolute; /* 공중으로 띄웁니다 */
    top: 10px;          /* 부모 상단 모서리에서 10px 아래로 */
    right: 10px;        /* 부모 우측 모서리에서 10px 왼쪽으로 (우측 상단에 찰싹 붙음) */
}
```

### 4. 고정 배치 (`fixed`)
* **기준점:** 무조건 <b>웹 브라우저 창(Viewport)</b>의 화면 모서리를 기준으로 삼습니다.
* **특징:** 마우스 스크롤을 아무리 위아래로 내려도, 지정된 화면의 좌표에 딱지처럼 영원히 고정되어 움직이지 않습니다. 쇼핑몰의 '맨 위로 가기 버튼'이나 화면 상단에 고정된 '내비게이션 바(메뉴)'를 만들 때 사용합니다.

```css
.go-top-btn {
    position: fixed;
    bottom: 20px; /* 브라우저 창 맨 아래에서 20px 띄움 */
    right: 20px;  /* 브라우저 창 맨 오른쪽에서 20px 띄움 */
}
```

### 5. 끈적이 배치 (`sticky`)
* **특징:** 평소에는 `relative`처럼 문서의 흐름을 따라 자연스럽게 스크롤되어 올라가다가, **요소가 화면의 특정 위치(예: 화면 맨 위)에 닿는 순간 `fixed`처럼 그 자리에 찰싹 달라붙습니다.**
* 긴 표를 읽을 때 제목 줄(`<th>`)이 시야에서 사라지지 않게 화면 상단에 붙여두거나, 블로그의 사이드바 광고를 고정할 때 매우 유용합니다.

```css
.table-header {
    position: sticky;
    top: 0; /* 스크롤을 내리다가 화면 맨 위(0)에 닿으면 그곳에 달라붙습니다. */
}
```

## 3. 겹침 순서 제어하기: `z-index`

`position`을 사용해 요소들을 (`static`이 아닌 값으로) 공중으로 띄우다 보면, 필연적으로 요소들끼리 겹치는 상황이 발생합니다. 기본적으로는 HTML 코드 상에서 **나중에 작성된(아래쪽에 있는) 요소가 더 위에 덮어씌워지게 됩니다.**

이러한 Z축(깊이)의 순서를 내 마음대로 바꾸고 싶을 때 사용하는 속성이 <b>`z-index`</b>입니다.

* 숫자가 클수록 화면의 앞으로(사용자와 가깝게) 튀어나옵니다.
* 숫자가 작을수록(음수 포함) 뒤로 숨습니다.
* **주의:** `z-index` 역시 `position`이 `static`이 아닌 요소(relative, absolute, fixed 등)에만 효과가 있습니다.

```css
.background-image {
    position: absolute;
    z-index: 1; /* 제일 뒤에 깔립니다. */
}

.text-content {
    position: relative;
    z-index: 10; /* 배경 이미지 위로 올라옵니다. */
}

.modal-popup {
    position: fixed;
    z-index: 9999; /* 화면의 모든 요소들을 덮고 최상단에 뜹니다. */
}
```

## 요약
CSS 레이아웃을 정복하기 위해서는 요소의 크기와 여백(Box Model)을 다루는 것을 넘어, `display`로 블록과 인라인 성질을 통제하고, `position` 삼총사(`relative`, `absolute`, `fixed`)를 자유자재로 다루어 요소를 원하는 좌표 공간에 띄우는 감각을 익히는 것이 무엇보다 중요합니다.
