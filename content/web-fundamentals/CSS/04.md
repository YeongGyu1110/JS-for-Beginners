# 표 스타일링 (Table Style)

## 개요
HTML에서 테이블 태그들(`<table>`, `<tr>`, `<td>` 등)을 사용해 표를 만들고 웹 브라우저로 직접 확인해 보면 테두리가 없거나 혹은 셀과 셀 사이가 어색하게 벌어진 모습을 마주하게 됩니다. CSS를 전혀 적용하지 않은 기본 상태의 표는 데이터를 한눈에 정돈해 보여주기 힘듭니다.

본 문서에서는 표의 테두리를 깔끔하게 정리하는 핵심 속성을 알아보고, 셀 여백과 정렬을 조절하는 기초적인 원칙을 학습합니다. 더 나아가 대용량의 표 데이터를 읽을 때 눈의 피로를 덜어주는 얼룩말 무늬(Zebra Striping) 효과와 마우스 오버 반응 등 가독성을 한층 더 높여주는 표 스타일링 기법들을 다룹니다.

### 기본 요건
이 실습은 사용자가 다음에 익숙하다는 가정하에 진행됩니다.
* HTML 표 기본 태그

### 이 모듈에서 배울 내용
* 이중 테두리를 하나로 단정하게 합쳐주는 `border-collapse`
* 셀에 여유 공간을 주어 숨통을 틔워주는 패딩(`padding`)과 크기 설정
* 가로정렬(`text-align`)과 세로정렬(`vertical-align`)의 조화
* 짝수/홀수 행을 구분하여 색상을 입히는 가독성 향상 기법
* 마우스 커서가 올라간 행을 강조하는 호버(`:hover`) 스타일

---

## 1. 테두리 합치기: `border-collapse`

HTML 표에 테두리(`border`) 속성을 입히면 기본적으로 각 셀마다 테두리가 따로 생성되어, 셀과 셀 사이가 벌어지고 테두리가 겹쳐서 투박한 이중 선으로 나타나게 됩니다.

이때 **`border-collapse`** 속성을 사용하여 표의 테두리를 어떻게 처리할지 선언할 수 있습니다.

* `separate` (기본값): 각 셀의 테두리를 분리하여 표시합니다. 이 때문에 이중 테두리처럼 보이게 됩니다.
* `collapse`: **인접한 셀끼리 테두리를 겹쳐서 단일 선으로 표현합니다.** 표 디자인 시 압도적으로 많이 쓰이는 설정입니다.

```css
table {
    border-collapse: collapse; /* 이중 테두리를 하나로 합쳐서 깔끔하게 만듭니다. */
    width: 100%;               /* 표의 가로 너비를 부모 요소에 꽉 차게 설정 */
}

th, td {
    border: 1px solid #ccc;    /* 모든 셀에 얇은 회색 테두리 적용 */
}
```

## 2. 셀 여백과 크기 제어: `padding`, `width`

표 내의 글자들이 테두리에 빽빽하게 붙어있으면 데이터를 읽기 무척 힘들어집니다. 이를 해결하려면 셀 영역(`<th>`, `<td>`) 안쪽에 숨을 쉴 수 있는 여백을 마련해 주어야 합니다.

### 셀 패딩 (`padding`)
셀 안에 들어있는 텍스트와 테두리 선 사이의 거리를 설정합니다. 상하좌우 적당한 여백을 부여하는 것만으로도 표의 완성도가 크게 개선됩니다.

```css
th, td {
    padding: 12px 15px; /* 상하 12픽셀, 좌우 15픽셀의 안쪽 여백 적용 */
}
```

### 표와 열의 너비 (`width`)
표 전체의 가로 크기뿐만 아니라, 특정 열(Column)의 너비도 CSS로 균등하거나 비균등하게 조절해 줄 수 있습니다.

```css
/* 첫 번째 제목 칸(th)에 이 클래스를 주어 해당 열 전체의 가로 폭을 제한합니다. */
.col-small {
    width: 10%;
}
.col-medium {
    width: 30%;
}
```

## 3. 정렬 방식 제어: `text-align`, `vertical-align`

셀 내부의 내용물을 보기 좋게 수평 및 수직 방향으로 정렬하는 방법입니다.

### 1. 수평 정렬 (`text-align`)
일반적으로 표의 제목 열(`<th>`)은 가운데 정렬, 본문 열(`<td>`)은 왼쪽 정렬을 기본값으로 사용합니다. 
* 숫자로 된 데이터는 우측 정렬(`right`), 짧은 코드나 상태 값 등은 가운데 정렬(`center`)을 해 주면 표가 더 일목요연해 보입니다.

```css
.number-cell {
    text-align: right; /* 숫자 데이터 우측 정렬 */
}
```

### 2. 수직 정렬 (`vertical-align`)
셀의 높이가 글자 높이보다 여유 있게 클 때, 텍스트가 셀 안에서 위쪽에 붙을지 아래쪽에 붙을지 결정합니다.

* `top`: 위쪽 정렬
* `middle` (기본값): 수직선상 가운데 정렬
* `bottom`: 아래쪽 정렬

```css
td {
    vertical-align: middle; /* 데이터를 셀 세로 중앙에 고정 */
}
```

## 4. 디자인 응용: 가독성 높은 표 만들기

수많은 가로행(`<tr>`)을 품고 있는 큰 표의 경우, 줄이 조금만 밀려도 윗줄의 값을 아랫줄의 값으로 오해하는 일이 발생하기 쉽습니다. 가독성을 한층 더 올리기 위한 유용한 기법 두 가지를 공유합니다.

### 1. 얼룩말 무늬 디자인 (Zebra Striping)
행들의 배경색을 교차로 다르게 지정하는 디자인 방식입니다. CSS의 가상 클래스 중 하나인 <b>`:nth-child()`</b>를 활용하면 홀수(odd) 또는 짝수(even) 행만 자동으로 골라내어 배경색을 연하게 칠해 줄 수 있습니다.

```css
/* 짝수 번째 가로행(tr)에만 아주 연한 회색 배경색을 입힙니다. */
tbody tr:nth-child(even) {
    background-color: #f9f9f9;
}
```

### 2. 행 마우스 호버 효과 (Row Hover Effect)
사용자의 마우스 커서가 머물러 있는 행의 배경색을 다르게 표현하여, 현재 내가 표의 어느 위치를 읽고 있는지 직관적으로 파악할 수 있도록 돕는 기법입니다.

```css
/* 마우스 커서가 올라간 행의 배경색을 살짝 어둡게 만들어 집중도를 높입니다. */
tbody tr:hover {
    background-color: #f1f1f1;
}
```

## 종합 실습 코드 예시

위에서 다룬 내용들을 모두 조화롭게 합친 신뢰도 높은 표 스타일의 예제 코드입니다.

```html
<!-- HTML -->
<table class="styled-table">
    <thead>
        <tr>
            <th>번호</th>
            <th>도서명</th>
            <th>저자</th>
            <th class="text-right">가격</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>1</td>
            <td>쉽게 배우는 HTML</td>
            <td>홍길동</td>
            <td class="text-right">15,000원</td>
        </tr>
        <tr>
            <td>2</td>
            <td>CSS 가독성 디자인 가이드</td>
            <td>이순신</td>
            <td class="text-right">18,000원</td>
        </tr>
        <tr>
            <td>3</td>
            <td>반응형 웹 사이트 구축 실습</td>
            <td>강감찬</td>
            <td class="text-right">22,000원</td>
        </tr>
    </tbody>
</table>
```

```css
/* CSS */

/* 1. 표 기본 구조 설정 */
.styled-table {
    border-collapse: collapse;
    width: 100%;
    margin: 20px 0;
    font-size: 0.95rem;
    font-family: sans-serif;
}

/* 2. 표 제목 영역 스타일링 */
.styled-table thead tr {
    background-color: #009879;
    color: #ffffff;
    text-align: left;
}

/* 3. 모든 셀의 여백 및 테두리 설정 */
.styled-table th,
.styled-table td {
    padding: 12px 15px;
    border-bottom: 1px solid #dddddd;
}

/* 4. 얼룩말 줄무늬 적용 */
.styled-table tbody tr:nth-child(even) {
    background-color: #f3f3f3;
}

/* 5. 마우스 호버 효과 적용 */
.styled-table tbody tr:hover {
    background-color: #eaeaea;
}

/* 6. 특정 정렬용 보조 클래스 */
.text-right {
    text-align: right;
}
```
