# CSS 박스 모델 (Box Model)과 크기 제어

## 개요
웹 브라우저의 눈에 비친 HTML 요소들은 사실 둥글거나 불규칙한 모양이 아니라, <b>모두 투명한 직사각형 형태의 '박스'</b>로 이루어져 있습니다. 웹 페이지의 레이아웃을 짠다는 것은 결국 이 네모난 박스들의 크기를 정하고, 박스 간의 간격을 조절하며, 원하는 위치에 박스를 차곡차곡 배치하는 과정입니다.

본 문서에서는 CSS 레이아웃의 가장 근본적인 개념인 <b>박스 모델(Box Model)</b>에 대해 학습합니다. 박스를 구성하는 4가지 영역(콘텐츠, 패딩, 테두리, 마진)의 역할을 이해하고, 박스의 실제 크기가 계산되는 원리를 바꿔주는 마법 같은 속성인 `box-sizing`에 대해 다룹니다. 마지막으로 밋밋한 평면 박스에 입체감을 불어넣는 그림자 효과까지 상세히 알아봅니다.

### 기본 요건
이 실습은 사용자가 다음에 익숙하다는 가정하에 진행됩니다.

 - 블록 요소와 인라인 요소의 성질
 - HTML 부모-자식 포함 관계

### 이 모듈에서 배울 내용
* 모든 HTML 요소를 구성하는 박스 모델의 4가지 영역 이해
* 내용물의 가로세로 크기를 지정하는 `width`와 `height`
* 테두리를 기준으로 안팎의 간격을 벌리는 `padding`과 `margin`
* 선의 두께, 스타일, 색상을 지정하는 `border`
* 박스의 크기 계산 방식을 직관적으로 바꿔주는 `box-sizing`
* 박스에 시각적인 깊이감을 더하는 `box-shadow`

## 1. 박스 모델의 구조 이해하기

CSS 박스 모델은 현실 세계의 <v>'액자'</b>와 매우 비슷합니다. 모든 박스는 안쪽에서부터 바깥쪽으로 다음 4가지 층(Layer)으로 겹겹이 구성되어 있습니다.

1. **Margin (마진 / 바깥쪽 여백):** 벽에 걸린 내 액자와 옆 액자 사이의 '거리'에 해당합니다. 다른 박스(요소)와의 바깥쪽 간격입니다.
2. **Border (보더 / 테두리):** 그림을 감싸고 있는 실제 '액자 틀(나무 프레임)'입니다. 박스의 테두리 선을 의미합니다.
3. **Padding (패딩 / 안쪽 여백):** 그림과 액자 틀 사이의 '하얀 여백(매트)'에 해당합니다. 콘텐츠와 테두리 사이의 간격입니다.
4. **Content (콘텐츠):** 액자 속의 실제 '그림'에 해당합니다. 텍스트나 이미지 등 실질적인 내용물이 위치하는 가장 안쪽 영역입니다.

## 2. 콘텐츠의 크기 지정: `width`, `height`

박스 안의 실제 내용물(Content)이 차지할 가로 너비와 세로 높이를 지정하는 속성입니다.

* `width`: 가로 너비
* `height`: 세로 높이

단위로는 픽셀(`px`)로 고정된 크기를 주거나, 부모 요소의 크기에 비례하여 변하는 퍼센트(`%`) 등의 상대 단위를 사용할 수 있습니다.

```css
.box {
    width: 300px;  /* 가로 크기를 300픽셀로 고정 */
    height: 150px; /* 세로 크기를 150픽셀로 고정 */
    background-color: lightblue; /* 콘텐츠와 패딩 영역까지 배경색이 칠해집니다. */
}
```
*(참고: `<span>`, `<a>` 같은 인라인(Inline) 요소는 글자 크기만큼만 공간을 차지하므로 `width`와 `height`를 지정해도 적용되지 않습니다. 반드시 블록(Block) 요소나 인라인-블록 요소에만 적용됩니다.)*

## 3. 여백 제어하기: `padding`과 `margin`

### 안쪽 여백: `padding`
테두리 선 안쪽으로 콘텐츠가 숨을 쉴 수 있는 여유 공간을 만듭니다. 패딩 영역은 요소의 **배경색(Background-color)이 그대로 연장되어 적용**됩니다.

### 바깥쪽 여백: `margin`
테두리 선 바깥쪽으로 다른 요소들을 밀어내어 간격을 벌립니다. 마진 영역은 **항상 투명**하며, 배경색이 칠해지지 않습니다.

### 여백을 축약해서 작성하는 방법 (시계 방향)
`padding`과 `margin`은 상하좌우(Top, Right, Bottom, Left) 방향을 각각 따로 지정할 수도 있고, 한 줄에 축약해서 쓸 수도 있습니다. 값의 개수에 따라 적용되는 위치가 다릅니다.

```css
.box {
    /* 1. 상하좌우 개별 지정 */
    padding-top: 20px;
    margin-left: 10px;

    /* 2. 값 1개: [상하좌우] 모두 똑같이 적용 */
    padding: 20px; 

    /* 3. 값 2개: [상, 하] [좌, 우] 짝지어 적용 */
    margin: 10px 20px; /* 위아래 10px, 좌우 20px */

    /* 4. 값 4개: 12시부터 [시계방향] (위, 오른쪽, 아래, 왼쪽) 순서로 적용 */
    padding: 10px 15px 20px 25px;
}
```

> [!TIP]
> **블록 요소를 가로 중앙에 배치하는 마법의 주문: `margin: 0 auto;`**\
> `width`가 지정된 블록 요소에 좌우 마진을 `auto`로 설정하면, 브라우저가 남은 바깥쪽 공간을 좌우로 똑같이 반분하여 자동으로 박스를 화면 정중앙에 배치해 줍니다. 
> ```css
> .container {
>     width: 800px;
>     margin: 0 auto; /* 위아래 마진은 0, 좌우 마진은 자동으로 균등 분할 */
> }
> ```

## 4. 테두리 그리기: `border`

박스의 외곽선을 그리는 속성입니다. 선의 두께, 선의 종류(실선, 점선 등), 선의 색상 등 3가지 값을 지정해야 화면에 나타납니다.

* **두께 (`border-width`):** `px` 단위로 지정합니다.
* **종류 (`border-style`):** `solid`(실선), `dashed`(절취선 같은 점선), `dotted`(둥근 점선) 등이 있습니다.
* **색상 (`border-color`):** 색상 이름이나 핵사 코드(`#000000`)를 지정합니다.

일반적으로 이 세 가지를 공백으로 띄워 한 번에 작성하는 축약형을 압도적으로 많이 사용합니다.

```css
.card {
    /* 두께 2px, 실선(solid), 검은색 테두리 적용 */
    border: 2px solid black;
    
    /* 특정 방향에만 선을 그을 수도 있습니다. */
    border-bottom: 1px dashed red;
}
```

## 5. 박스 크기 계산의 마법: `box-sizing`

웹 디자인을 처음 시작할 때 가장 많이 겪는 혼란은 **"내가 300px이라고 지정한 박스가 화면에서 300px보다 훨씬 크게 나타나는 현상"**입니다. 

그 이유는 CSS의 기본 박스 크기 계산법(`box-sizing: content-box`) 때문입니다. 기본적으로 내가 지정한 `width`는 오직 '콘텐츠'만의 크기입니다. 패딩과 테두리를 추가하면 박스는 풍선처럼 바깥으로 부풀어 오릅니다.

* **기본 계산법:** `width 300px` + `padding 좌우 20px` + `border 좌우 1px` = **실제 화면상의 너비는 342px**

이 계산법은 레이아웃을 정확하게 짜기 매우 힘들게 만듭니다. 이를 직관적으로 해결해 주는 속성이 바로 **`box-sizing: border-box`**입니다.

### `box-sizing: border-box`
이 속성을 적용하면 내가 지정한 `width`와 `height` 안에 **패딩과 테두리의 크기까지 전부 포함**되어 계산됩니다. 패딩을 아무리 늘려도 박스 자체가 커지지 않고, 내부의 콘텐츠 크기가 줄어들면서 전체 박스의 덩치를 완벽하게 유지합니다.

```css
/* 현대 웹 개발에서는 묻지도 따지지도 않고 모든 요소에 border-box를 선언하고 시작하는 것이 국룰(표준 관행)입니다. */
* {
    box-sizing: border-box;
}

.box {
    width: 300px;
    padding: 20px;
    border: 1px solid black;
    /* border-box가 적용되었으므로, 패딩과 테두리를 더해도 화면상에 차지하는 실제 가로 크기는 딱 300px을 유지합니다. */
}
```

## 6. 입체감 부여하기: `box-shadow`

`box-shadow` 속성은 평면적인 2D 박스에 그림자를 추가하여 화면에서 붕 떠 있는 듯한 입체감(Depth)과 고급스러움을 더해줍니다. 카드형 레이아웃이나 팝업창, 버튼 등에 아주 널리 쓰입니다.

그림자 효과를 만들려면 X축 이동, Y축 이동, 흐림 정도, 색상 등 여러 개의 값을 순서대로 적어주어야 합니다.

1. **X축 오프셋(가로 위치):** 양수는 오른쪽, 음수는 왼쪽으로 그림자가 이동합니다.
2. **Y축 오프셋(세로 위치):** 양수는 아래쪽, 음수는 위쪽으로 그림자가 이동합니다.
3. **흐림 반경(Blur Radius):** 그림자의 끝을 얼마나 흐릿하게 번지게 할지 정합니다. 값이 클수록 흐릿하고 부드러워집니다.
4. **확산 반경(Spread Radius - 생략 가능):** 그림자의 전체 크기를 확장하거나 축소합니다.
5. **색상:** 그림자의 색상과 투명도(`rgba`)를 지정합니다.

```css
.card {
    background-color: white;
    border-radius: 8px; /* 박스 모서리를 둥글게 깎아줍니다. */
    
    /* 가로 0px, 세로 4px 이동, 흐림 반경 8px, 반투명한 검은색(투명도 10%) 그림자 */
    box-shadow: 0px 4px 8px rgba(0, 0, 0, 0.1);
}

.card:hover {
    /* 마우스를 올렸을 때 그림자가 아래로 더 길어지고 번지면서 
       마치 카드가 화면 위로 살짝 떠오르는 듯한 효과를 줍니다. */
    box-shadow: 0px 8px 16px rgba(0, 0, 0, 0.2);
}
```

> [!NOTE]
> 그림자의 색상을 단순히 완전한 검은색(`black`)이나 회색(`gray`)으로 주면 다소 촌스럽고 탁해 보일 수 있습니다. 실무에서는 그림자가 자연스럽게 배경과 섞이도록 **`rgba` 함수를 사용하여 투명도를 5% ~ 20% 정도로 낮춘 아주 연한 검은색**을 주로 활용합니다.
