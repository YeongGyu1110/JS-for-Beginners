# 플렉스 박스 레이아웃 (Flexbox Layout)

## 개요
과거 웹 개발자들은 화면에 박스들을 가로로 나란히 배치하거나 수직으로 중앙 정렬하기 위해 `float`이나 `position`, `inline-block` 같은 속성들을 억지로 끼워 맞추며 온갖 편법(Hack)을 동원해야 했습니다. 

이러한 레이아웃 설계의 고통을 영원히 끝내기 위해 등장한 CSS3의 혁명적인 기술이 바로 <b>플렉스 박스(Flexible Box, Flexbox)</b>입니다. 플렉스 박스는 이름 그대로 요소들을 고무줄처럼 유연하게 늘리거나 줄이면서, 가로 또는 세로 1차원 방향으로 손쉽게 배치하고 정렬할 수 있도록 설계된 현대 웹 레이아웃의 핵심 표준입니다.

본 문서에서는 플렉스 박스의 작동 원리인 '부모'와 '자식'의 관계를 이해하고, 축을 결정하는 방법과 요소들 사이의 간격 및 정렬을 제어하는 속성들을 학습합니다.

### 기본 요건
이 실습은 사용자가 다음에 익숙하다는 가정하에 진행됩니다.
* HTML 요소의 부모-자식 관계 및 계층 구조에 대한 이해
* 블록 요소의 특징과 CSS 박스 모델의 크기(`width`, `height`), 여백 제어 방법
* 요소의 화면 배치 성질을 결정짓는 `display` 속성(block, inline 등)의 기본 개념

### 이 모듈에서 배울 내용
* 플렉스 박스의 기본 구조: 컨테이너와 아이템
* 레이아웃의 방향을 결정하는 주축(Main Axis)과 교차축(Cross Axis)의 개념
* 가로세로 배치 방향을 바꾸는 `flex-direction`
* 주축을 기준으로 아이템을 정렬하는 `justify-content`
* 교차축을 기준으로 아이템을 정렬하는 `align-items`
* 아이템의 줄바꿈을 제어하는 `flex-wrap`

---

## 1. 기본 개념: 컨테이너와 아이템

플렉스 박스를 사용할 때 가장 먼저 기억해야 할 절대 규칙은 <b>"정렬하려는 요소들의 '부모 요소'에게 플렉스 선언을 해야 한다"</b>는 것입니다.

* **Flex Container, 플렉스 컨테이너:** 플렉스 박스의 전체 영역을 감싸는 부모 요소입니다. 여기에 `display: flex;`를 선언하면 플렉스 마법이 시작됩니다.
* **Flex Item, 플렉스 컨테이너:** 컨테이너 안에서 실제로 정렬되는 자식 요소들입니다. 

```html
<!-- HTML 구조 -->
<div class="container"> <!-- 부모 (Container) -->
    <div class="item">1</div> <!-- 자식 (Item) -->
    <div class="item">2</div> <!-- 자식 (Item) -->
    <div class="item">3</div> <!-- 자식 (Item) -->
</div>
```

```css
.container {
    /* 부모 요소에 플렉스를 선언하는 순간, 자식 요소들은 자동으로 가로로 나란히 배치됩니다. */
    display: flex;
}
```

---

## 2. 두 가지 축: 주축(Main Axis)과 교차축(Cross Axis)

부모에게 `display: flex;`를 주었다면, 그다음으로 결정해야 할 것은 **배치 방향**입니다. 플렉스 박스는 항상 두 개의 축을 기준으로 움직입니다.

* **주축 (Main Axis):** 아이템들이 배치되는 메인 방향입니다.
* **교차축 (Cross Axis):** 주축과 90도로 수직을 이루는 방향입니다.

### 방향 결정하기: `flex-direction`
부모 요소에 `flex-direction` 속성을 사용하여 주축의 방향을 가로로 할지, 세로로 할지 결정합니다.

* **`row` (기본값):** 주축이 <b>가로(왼쪽에서 오른쪽)</b>가 됩니다.
* **`column`:** 주축이 <b>세로(위에서 아래)</b>가 됩니다.
* `row-reverse` / `column-reverse`: 각각 가로/세로 방향을 역순(반대)으로 배치합니다.

```css
.container {
    display: flex;
    flex-direction: column; /* 자식 요소들을 위에서 아래로 세로 배치합니다. */
}
```

---

## 3. 아이템 정렬하기

플렉스 박스의 진정한 위력은 정렬 속성에서 나옵니다. 아이템들을 주축(Main) 방향으로 정렬할지, 교차축(Cross) 방향으로 정렬할지에 따라 사용하는 속성 이름이 다릅니다.

### 1. 주축 방향 정렬: `justify-content`
주축을 따라 아이템들을 어떻게 배치하고 남은 여백을 어떻게 분배할지 결정합니다. (기본값 `row` 상태에서는 **가로 정렬**을 의미합니다.)

* `flex-start` (기본값): 아이템들을 시작점(왼쪽)으로 몰아서 정렬합니다.
* `flex-end`: 아이템들을 끝점(오른쪽)으로 몰아서 정렬합니다.
* **`center`**: 아이템들을 가운데로 모아서 정렬합니다.
* **`space-between`**: 첫 아이템은 양 끝에 붙이고, 나머지 아이템들 사이의 **간격을 균등하게** 벌립니다.
* `space-around`: 각 아이템의 양옆 둘레에 동일한 간격을 줍니다.

```css
.navbar {
    display: flex;
    /* 양 끝에 로고와 메뉴를 배치하고 가운데를 비웁니다! */
    justify-content: space-between; 
}
```

### 2. 교차축 방향 정렬: `align-items`
교차축을 따라 아이템들을 어떻게 배치할지 결정합니다. (기본값 `row` 상태에서는 **수직 정렬**을 의미합니다.)

* `stretch` (기본값): 아이템들이 교차축 방향(세로)으로 부모의 높이만큼 꽉 차게 쭈욱 늘어납니다.
* `flex-start`: 위쪽(시작점)에 맞춰 정렬합니다.
* `flex-end`: 아래쪽(끝점)에 맞춰 정렬합니다.
* **`center`**: 아이템들을 수직선상 **정중앙**에 맞춥니다.

---

## 4. 줄바꿈 제어하기: `flex-wrap`

플렉스 박스는 기본적으로 자식 요소들의 크기가 아무리 커도 **절대 줄바꿈을 하지 않고** 억지로 한 줄에 욱여넣으려는 성질(`nowrap`)을 가지고 있습니다. 이 성질을 풀어주어 요소가 넘치면 다음 줄로 자연스럽게 내려가도록 만드는 속성입니다.

* `nowrap` (기본값): 줄바꿈을 하지 않습니다.
* **`wrap`:** 부모의 너비를 넘어가면 <b>다음 줄로 줄바꿈(Wrapping)</b>을 합니다.

```css
.gallery-container {
    display: flex;
    flex-wrap: wrap; /* 화면이 좁아지면 카드들이 알아서 밑으로 떨어집니다. */
}
```

> [!NOTE]
> **간격 띄우기: `gap` 속성**\
> 과거에는 아이템 사이를 띄우기 위해 `margin`을 복잡하게 계산해야 했지만, 이제는 부모 요소에 **`gap: 20px;`** 처럼 한 줄만 적어주면 아이템들 사이에만 정확하고 깔끔하게 20px의 여백이 생성됩니다.

---

## 5. 유연성 속성: `flex`

지금까지 배운 속성은 모두 부모에게 주는 것이었습니다. 반면 자식 요소들에게 직접 부여하여 <b>"남은 여백을 누가 얼마나 더 차지할 것인가?"</b>를 비율로 결정하는 `flex` 속성도 있습니다.

```css
.item-1 {
    flex: 1; /* 남은 공간의 1의 비율만큼 늘어나 차지함 */
}
.item-2 {
    flex: 2; /* 남은 공간을 item-1보다 2배 더 많이 차지함 */
}
```
*(검색창 UI에서 검색어 입력칸은 길게 늘어나고(`flex: 1`), 돋보기 버튼은 고정된 크기를 가질 때 자주 응용됩니다.)*

## 6. 완벽한 중앙 정렬

CSS를 다룰 때 수많은 개발자들을 괴롭혔던 <b>"박스를 부모 요소의 가로세로 완벽한 정중앙에 배치하기"</b>는 플렉스 박스의 등장으로 단 3줄의 코드로 종결되었습니다. 이 코드는 반드시 통째로 외워두는 것을 권장합니다.

```html
<div class="box-wrapper">
    <div class="center-box">완벽한 중앙에 있습니다.</div>
</div>
```

```css
.box-wrapper {
    width: 100%;
    height: 100vh; /* 브라우저 화면 전체 높이 설정 */
    
    /* 완벽한 중앙 정렬을 위한 마법의 3줄 */
    display: flex;
    justify-content: center; /* 주축(가로) 중앙 정렬 */
    align-items: center;     /* 교차축(세로) 중앙 정렬 */
}

.center-box {
    background-color: coral;
    padding: 30px;
}
```
