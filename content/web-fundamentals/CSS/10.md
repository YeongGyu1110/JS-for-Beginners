# CSS 배경 스타일링 2부: 그레이디언트와 단축 속성

## 개요
앞서 1부에서는 외부 이미지 파일을 불러와 배경으로 삽입하고 그 크기와 위치를 통제하는 방법을 배웠습니다. 하지만 매번 이미지 파일을 만들고 불러오는 것은 웹사이트의 로딩 속도를 저하시킬 수 있습니다. 

본 문서(2부)에서는 이미지 파일 없이도 CSS 코드만으로 여러 가지 색상이 자연스럽게 스며드는 화려한 **그레이디언트(Gradient)** 효과를 만드는 방법을 학습합니다. 더불어 1, 2부에서 배운 수많은 배경 속성들을 단 한 줄의 코드로 깔끔하게 정리하는 **단축 속성(Shorthand)** 작성법을 알아봅니다.

### 이 모듈에서 배울 내용
* `linear-gradient`를 활용하여 직선 방향으로 자연스럽게 색상이 스며드는 선형 그레이디언트 만들기
* `radial-gradient`와 `conic-gradient`를 활용한 원형 및 원뿔형 그레이디언트 효과
* 하나의 요소에 여러 개의 배경 이미지와 그레이디언트를 겹쳐서 쌓아 올리는 다중 배경 기법
* 다양한 배경 제어 속성들을 단 한 줄로 깔끔하게 축약하는 `background` 단축 속성 작성법과 슬래시(`/`) 규칙

---

## 1. 선형 그레이디언트: `linear-gradient()`

그레이디언트는 엄밀히 말해 단순한 '색상(color)'이 아니라, 브라우저가 코드를 읽고 실시간으로 그려내는 '이미지(image)'로 취급됩니다. 따라서 `background-color`가 아닌 **`background-image`** 속성에 값을 대입해야 합니다.

`linear-gradient`는 색상이 직선 방향으로 순차적으로 변화하는 효과를 줍니다.

### 기본 작성법
괄호 안에 최소 2개 이상의 색상을 쉼표로 구분하여 적어줍니다. 기본적으로 **위에서 아래로(to bottom)** 색상이 변합니다.

```css
.box {
    /* 파란색에서 시작해 서서히 분홍색으로 변하며 내려옵니다. */
    background-image: linear-gradient(blue, pink);
}
```

### 방향 바꾸기
괄호 안의 가장 첫 번째 자리에 `to 방향` 키워드나 `각도(deg)`를 넣어 색상이 번져가는 방향을 조절할 수 있습니다.
* `to right`: 왼쪽에서 오른쪽으로
* `to bottom right`: 왼쪽 위에서 오른쪽 아래(대각선)로
* `45deg`: 45도 각도 방향으로

```css
/* 대각선 방향으로 3가지 색상이 섞이는 예시 */
.sunset-bg {
    background-image: linear-gradient(to bottom right, red, orange, yellow);
}
```

### 색상 비중(중단점, Color Stops) 조절하기
각 색상 뒤에 퍼센트(`%`)나 픽셀을 적어주면, 해당 색상이 정확히 어디까지 뚜렷하게 유지되고 어디서부터 다른 색으로 섞일지 경계(중단점)를 지정할 수 있습니다.

```css
/* 빨간색이 전체의 50% 지점까지 뚜렷하게 칠해지다가, 그 이후부터 파란색으로 변합니다. */
.half-bg {
    background-image: linear-gradient(to right, red 50%, blue);
}
```

## 2. 원형 그레이디언트: `radial-gradient()`

직선이 아니라, 중심점에서 시작하여 동심원이나 타원 모양으로 바깥을 향해 퍼져나가는 그레이디언트입니다. 빛이 퍼져나가는 후광 효과를 만들거나 버튼에 입체감을 줄 때 유용합니다.

```css
/* 정중앙에서 시작하여 안쪽은 노란색, 바깥쪽은 초록색으로 둥글게 퍼져나갑니다. */
.circle-bg {
    background-image: radial-gradient(circle, yellow, green);
}
```
*(기본 모양은 타원형(ellipse)이며, `circle` 키워드를 첫 번째에 적어주면 완벽한 원형으로 퍼집니다.)*

---

## 3. 원뿔형 그레이디언트: `conic-gradient()`

가장 최근에 추가된 그레이디언트 속성으로, 중심점을 기준으로 피자 조각을 자르듯 시계 방향(각도)으로 색상이 회전하며 변합니다. 데이터 시각화를 위한 파이 차트(원형 그래프)나 색상표(Color Wheel)를 만들 때 매우 유용합니다.

```css
/* 시계 방향으로 빨강 -> 녹색 -> 파랑 순으로 돌아가며 칠해집니다. */
.pie-chart {
    border-radius: 50%; /* 박스를 동그랗게 만듦 */
    background-image: conic-gradient(red, green, blue);
}
```

## 4. 배경 이미지 여러 개 겹치기 (다중 배경)

CSS3부터는 하나의 박스 요소에 배경 이미지를 2개 이상 겹쳐서 올릴 수 있습니다. `background-image` 속성에 쉼표(`,`)를 사용하여 여러 이미지를 나열하면 됩니다.

**주의할 점:** 코드를 작성할 때 **먼저 적은 이미지가 화면의 가장 앞(맨 위)에** 쌓이고, 나중에 적은 이미지가 뒤쪽(아래)에 깔리게 됩니다.

이 기능을 응용하면 멋진 풍경 사진(이미지) 위에, 반투명한 검은색 그레이디언트를 덮어씌워 텍스트를 훨씬 읽기 쉽게 만드는 디자인 기법(Overlay)을 HTML 추가 수정 없이 CSS만으로 구현할 수 있습니다.

```css
.hero-banner {
    /* 1번 레이어(위): 위에서 아래로 어두워지는 반투명 검은색 그레이디언트 
       2번 레이어(아래): 실제 배경 풍경 사진 */
    background-image: 
        linear-gradient(to bottom, rgba(0,0,0,0.1), rgba(0,0,0,0.8)),
        url('./landscape.jpg');
        
    background-size: cover; /* 두 이미지 모두에 적용됨 */
    color: white; /* 텍스트는 하얗게 */
}
```

## 5. 모든 배경 속성을 한 줄로! 단축 속성: `background`

지금까지 우리는 `color`, `image`, `repeat`, `size`, `position` 등 무수히 많은 배경 관련 속성들을 배웠습니다. 실무에서 이들을 일일이 줄을 바꿔가며 적는 것은 코드가 너무 길어지고 비효율적입니다.

이를 단 한 줄로 깔끔하게 정리하는 마법의 단축 속성(Shorthand)이 바로 **`background`**입니다.

### 단축 속성 작성 공식
대부분의 값들은 순서가 크게 중요하지 않으며, 띄어쓰기(공백)로 구분하여 나열하면 브라우저가 알아서 해석합니다. 

단, **`position`과 `size`를 함께 적을 때**는 브라우저가 숫자를 혼동하지 않도록 반드시 **`position / size` 순서로 슬래시(`/`)를 넣어 구분**해주어야 한다는 치명적인 규칙이 있습니다.

```css
/* 개별 속성으로 작성할 때 (너무 길다) */
.box {
    background-color: #f0f0f0;
    background-image: url('./pattern.png');
    background-repeat: no-repeat;
    background-position: center;
    background-size: cover;
}

/* 단축 속성으로 작성할 때 (깔끔하다) */
.box {
    /* 색상, 이미지, 반복유무, 위치 / 크기 */
    background: #f0f0f0 url('./pattern.png') no-repeat center / cover;
}
```

> [!TIP]
> **실무에서의 주의점**\
> `background` 단축 속성을 선언하면, 내가 미처 적지 않은 나머지 배경 속성들은 모조리 **기본값으로 덮어쓰기(초기화)** 되어버립니다. 따라서 기존에 적용되어 있던 배경 설정이 실수로 날아갈 수 있으니, 특정 배경 속성 딱 하나(예: 색상)만 바꾸고 싶을 때는 단축 속성보다는 `background-color`처럼 정확한 개별 속성을 지정하는 것이 더 안전한 코딩 습관입니다.
