# CSS의 기초와 스타일 적용 방법

## 개요
HTML을 사용해 웹 페이지의 구조를 설계하고 텍스트, 이미지, 링크, 폼 등 다양한 요소를 배치할 수 있습니다. 하지만 HTML만으로 구성된 웹 페이지는 90년대 초반의 투박한 문서처럼 보입니다. 여기에 색상을 입히고, 정렬을 맞추고, 아름다운 서체를 적용하여 현대적인 웹 페이지로 탈바꿈시켜 주는 기술이 바로 **CSS**입니다.

본 문서에서는 웹 디자인의 핵심 기술인 CSS의 기본적인 개념을 이해하고, 단일 '스타일'과 이를 모아둔 '스타일 시트'가 어떻게 다른지 알아봅니다. 또한 웹 페이지에 CSS를 적용하는 대표적인 3가지 방법의 장단점을 살펴보고, CSS 코드를 작성할 때 반드시 알아야 하는 문법의 기초를 다룹니다.

### 기본 요건
이 모듈은 사용자가 다음에 익숙하다는 가정하에 진행됩니다.
* HTML 문서의 기본 구조
* 기본 HTML 태그

### 이 모듈에서 배울 내용
* CSS(Cascading Style Sheets)의 개념과 역할
* 스타일(Style)과 스타일 시트(Style Sheet)의 구분
* CSS를 웹 문서에 적용하는 3가지 방법 (인라인, 내부, 외부)
* CSS 규칙(Rule)을 구성하는 선택자, 속성, 값의 기본 구조

## 1. CSS란 무엇인가?

CSS는 **C**ascading **S**tyle **S**heets의 약자로, HTML 문서의 시각적인 표현(디자인과 레이아웃)을 정의하는 스타일 시트 언어입니다.

HTML이 건물의 뼈대를 세우고 방을 나누는 '철골 공사'라면, CSS는 벽지를 바르고, 가구를 배치하고, 예쁜 조명을 다는 '인테리어 공사'에 비유할 수 있습니다. HTML이 정보의 구조를 담당하고, CSS는 그 정보가 사용자에게 어떻게 보일지(시각적 표현)를 전송받아 제어합니다.

이렇게 웹 디자인과 구조를 분리하면 다음과 같은 실무적인 이점이 있습니다.
* **디자인의 일관성 유지:** 웹사이트 전체의 글자 색상이나 배경을 한 번에 제어할 수 있습니다.
* **유지보수의 편리함:** 웹 페이지의 구조(HTML)를 건드리지 않고 디자인(CSS)만 수정하여 사이트의 전반적인 분위기를 손쉽게 바꿀 수 있습니다.

### 스타일(Style)과 스타일 시트(Style Sheet)
* **스타일(Style):** 글자 크기, 글자 색상, 배경색, 여백 등 웹 페이지 요소에 지정하는 개별적인 시각적 속성을 의미합니다.
* **스타일 시트(Style Sheet):** 이러한 스타일 규칙들을 체계적으로 모아둔 문서나 코드의 집합을 말합니다. 여러 HTML 문서가 하나의 스타일 시트를 공유하여 동일한 디자인 테마를 갖도록 유도할 수 있습니다.

## 2. CSS의 기본 문법 구조

CSS는 HTML처럼 꺾쇠 괄호(`< >`)를 사용하지 않고, 고유의 문법 규칙을 따릅니다. CSS 코드는 기본적으로 **"무엇을(대상), 어떻게(속성과 값)"** 꾸밀지 결정하는 구조로 작성됩니다.

```css
선택자 {
    속성: 값;
    속성: 값;
}
```

이 구조를 구성하는 세 가지 핵심 요소는 다음과 같습니다.

* **선택자 (Selector):** 스타일을 적용할 대상을 지정합니다. "어떤 HTML 요소를 꾸밀 것인가"를 결정하는 부분입니다. (예: `h1`, `p`, `div` 등)
* **속성 (Property):** 선택한 대상에서 바꾸고 싶은 구체적인 항목(스타일 변수)입니다. 콜론(`:`) 앞에 위치합니다. (예: `color`, `font-size`, `background-color`)
* **값 (Value):** 해당 속성에 부여할 실제 스타일 결과입니다. 속성명 뒤에 작성하며, 한 줄의 스타일 설정이 끝나면 반드시 세미콜론(`;`)을 붙여 구분을 지어주어야 합니다. (예: `blue`, `20px`, `red`)

```css
/* 예시: 모든 h1 태그의 글자 색상을 파란색으로 바꾸고 글자 크기를 24픽셀로 설정 */
h1 {
    color: blue;
    font-size: 24px;
}
```

> [!NOTE]
> **CSS 주석 작성법**\
> CSS 코드 내에서 브라우저가 실행하지 않고 개발자만 볼 수 있는 메모를 남길 때는 `/* 주석 내용 */` 형태로 작성합니다. HTML의 주석 기호(`<!-- -->`)와 혼동하지 않도록 유의하세요.

## 3. 웹 페이지에 스타일을 적용하는 3가지 방법

작성한 CSS 코드를 HTML 문서와 결합하여 화면에 반영하는 방법은 크게 세 가지가 있습니다. 상황과 규모에 따라 알맞은 방식을 선택하여 사용합니다.

### 방법 1. 인라인 스타일 (Inline Style)
HTML 태그 내부에 `style` 속성을 직접 사용하여 해당 요소에만 스타일을 바로 적용하는 방식입니다.

```html
<h1 style="color: red; font-size: 20px;">인라인 스타일 예시</h1>
<p>이 문단에는 스타일이 적용되지 않습니다.</p>
```
* **장점:** 별도의 설정 없이 특정 태그 하나에 신속하게 스타일을 임시 적용할 수 있습니다.
* **단점:** 디자인과 구조가 완전히 뒤섞여 코드가 지저분해지고, 동일한 스타일을 여러 태그에 반복 적용해야 할 때 수정이 극히 번거로워집니다. 현업에서는 특별한 경우가 아니면 사용을 피하는 것을 권장합니다.

### 방법 2. 내부 스타일 시트 (Internal Style Sheet)
HTML 문서 내부의 `<head>` 태그 영역 안에 `<style>` 태그를 열고, 그 안에 CSS 코드를 모아 작성하는 방식입니다.

```html
<head>
    <meta charset="UTF-8">
    <title>내부 스타일 시트 예시</title>
    <style>
        /* 이 문서 안의 모든 p 태그에 일괄 적용됩니다. */
        p {
            color: green;
            line-height: 1.6;
        }
    </style>
</head>
<body>
    <p>첫 번째 문단입니다.</p>
    <p>두 번째 문단도 녹색으로 표현됩니다.</p>
</body>
```
* **장점:** HTML 문서 하나 안에서 스타일을 일괄 제어할 수 있으며, 구조와 스타일이 한 파일에 있어 비교적 규모가 작은 단일 페이지 웹사이트를 만들 때 유용합니다.
* **단점:** 웹사이트의 페이지 수가 늘어나면(예: 수십 개의 HTML 파일), 파일마다 일일이 스타일 코드를 복사해서 붙여넣어야 하므로 전반적인 관리의 비효율성이 발생합니다.

### 방법 3. 외부 스타일 시트 (External Style Sheet)
CSS 코드를 HTML 파일과 분리하여 확장자가 `.css`인 별도의 독립 파일로 저장하고, HTML의 `<head>` 영역 안에서 `<link>` 태그를 사용해 불러오는 방식입니다. **현대 웹 개발에서 표준으로 사용하는 가장 정석적인 방법**입니다.

우선, `style.css`라는 파일을 하나 생성하고 아래와 같이 CSS 코드만 작성합니다. (HTML 태그를 적지 않습니다.)

```css
/* style.css 파일 내용 */
body {
    background-color: #f4f4f4;
}
h1 {
    color: darkblue;
}
```

이후 스타일을 적용할 HTML 문서의 `<head>` 구역에서 다음과 같이 연결합니다.

```html
<head>
    <meta charset="UTF-8">
    <title>외부 스타일 시트 예시</title>
    <!-- link 태그를 사용해 css 파일을 외부에서 불러옵니다. -->
    <link rel="stylesheet" href="./style.css">
</head>
<body>
    <h1>외부 파일로 스타일을 입혔습니다.</h1>
</body>
```

* **장점:** HTML은 구조에만 집중하고, CSS는 스타일에만 집중할 수 있어 코드 관리가 대단히 깔끔해집니다. 수백 개의 HTML 페이지가 있더라도 외부 CSS 파일 하나만 수정하면 사이트 전체의 디자인을 단번에 바꿀 수 있습니다.
* **단점:** 연결할 파일의 경로(`href`)를 잘못 지정하면 스타일이 전혀 로드되지 않으므로 상대 경로 지정에 주의해야 합니다.

> [!IMPORTANT]
> **`<link>` 태그의 필수 속성**\
> 외부 스타일 시트를 연결할 때는 빈 태그인 `<link>`를 사용하며, 다음 속성이 올바르게 작성되었는지 확인해야 합니다.
> * `rel`: 관계(Relation)를 의미하며, 불러올 파일이 스타일 시트임을 브라우저에 알려주기 위해 반드시 `rel="stylesheet"`로 고정 기입합니다.
> * `href`: 연결할 외부 CSS 파일의 경로를 상대 경로 혹은 절대 경로로 올바르게 적어줍니다.
