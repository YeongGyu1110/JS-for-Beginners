# 텍스트 관련 태그 (제목, 문단, 꾸밈)

## 개요
웹 페이지에서 정보를 전달하는 가장 기본적이고 핵심적인 수단은 바로 텍스트입니다. HTML은 단순히 글씨를 화면에 띄우는 것을 넘어, 이 글씨가 제목인지, 일반 본문인지, 아니면 돋보여야 할 중요한 단어인지를 구분할 수 있는 다양한 텍스트 전용 태그를 제공합니다.

본 문서에서는 글의 구조를 잡는 제목과 문단 태그부터, 엔터키를 대신하는 줄바꿈 태그, 다른 글을 인용할 때 쓰는 태그, 그리고 텍스트의 일부분을 다채롭게 꾸미고 의미를 부여하는 다양한 서식 태그들을 알아봅니다.

### 이 모듈에서 배울 내용
* 문서의 뼈대를 잡는 제목 태그 `<h1> ~ <h6>`
* 일반적인 본문을 작성하는 문단 태그 `<p>`
* HTML에서 줄바꿈과 선을 긋는 빈 태그 `<br>`, `<hr>`
* 다른 출처의 글을 인용하는 `<blockquote>`
* 텍스트의 일부분을 꾸미고 의미를 강조하는 다양한 인라인 태그들

---

## 1. 제목과 문단

### 제목 태그 (Heading) : `<h1>` ~ `<h6>`
책에 대제목, 중제목, 소제목이 있듯이 웹 문서에도 제목이 필요합니다. HTML은 제목의 중요도와 크기에 따라 1부터 6까지의 숫자를 가진 제목 태그를 제공합니다. 

숫자가 작을수록(1에 가까울수록) 글씨가 크고 중요한 제목이며, 숫자가 커질수록 글씨가 작아집니다.

```html
<h1>이것은 가장 큰 대제목입니다 (Heading 1)</h1>
<h2>이것은 중제목입니다 (Heading 2)</h2>
<h3>이것은 소제목입니다 (Heading 3)</h3>
<!-- ... h6까지 사용 가능합니다 ... -->
<h6>이것은 가장 작은 제목입니다 (Heading 6)</h6>
```

> [!IMPORTANT]
> **`<h1>` 태그 사용 시 주의사항**\
> `<h1>` 태그는 그 웹 페이지의 **가장 핵심이 되는 단 하나의 주제**를 나타냅니다. 따라서 검색 엔진 봇은 웹사이트를 방문했을 때 `<h1>` 태그의 내용을 가장 먼저 수집합니다. 검색 결과 노출(SEO)을 위해 **하나의 HTML 페이지 안에는 `<h1>` 태그를 가급적 딱 한 번만 사용**하는 것이 훌륭한 관례입니다.

### 문단 태그 (Paragraph) : `<p>`
일반적인 본문 텍스트를 작성할 때 사용하는 가장 기본적인 태그입니다. `<p>` 태그로 감싸인 텍스트는 하나의 독립된 '문단'으로 취급되어, 위아래로 약간의 여백이 자동으로 생깁니다.

```html
<p>이것은 첫 번째 문단입니다. 본문 내용을 작성할 때 주로 사용합니다.</p>
<p>이것은 두 번째 문단입니다. p 태그를 새로 열면 자동으로 줄바꿈이 되며 여백이 생깁니다.</p>
```

## 2. 줄바꿈과 구분선

HTML 문서 안에서는 **우리가 키보드 Enter키를 아무리 많이 쳐서 줄을 띄워도 브라우저 화면에서는 절대 줄바꿈이 일어나지 않습니다.** 브라우저는 연속된 띄어쓰기나 엔터를 단 하나의 공백으로 뭉뚱그려 처리하기 때문입니다.

따라서 강제로 줄바꿈을 하거나 선을 그으려면 전용 태그를 사용해야 합니다. 이들은 감쌀 내용물이 없으므로 <b>종료 태그가 없는 빈 태그(Empty Tag)</b>입니다.

### 줄바꿈 (Break) : `<br>`
텍스트 안에서 강제로 줄을 바꿀 때 사용합니다.

```html
<p>
    안녕하세요. 첫 번째 줄입니다.<br>
    엔터키 대신 br 태그를 써야만<br>이렇게 줄바꿈이 됩니다.
</p>
```

### 수평 구분선 (Horizontal Rule) : `<hr>`
이야기의 흐름이 바뀌거나 구역을 나눌 때 화면에 가로로 긴 선을 그어줍니다.

```html
<p>여기까지가 서론입니다.</p>
<hr> <!-- 화면에 얇은 가로선이 그어집니다. -->
<p>여기서부터는 본론입니다.</p>
```

## 3. 인용문 

### 블록 인용구 : `<blockquote>`
다른 웹사이트나 책, 기사 등에서 발췌한 **비교적 긴 인용문**을 작성할 때 사용합니다. 브라우저는 기본적으로 이 태그 안의 내용을 일반 문단보다 안쪽으로 쑥 들여쓰기하여 다른 글과 구분되게 만들어 줍니다.

```html
<p>아인슈타인은 다음과 같이 말했습니다:</p>
<blockquote>
    상상력은 지식보다 중요하다. 지식은 한계가 있지만 상상력은 세상을 둘러싼다.
</blockquote>
```

## 4. 텍스트 꾸밈 태그 (인라인 서식)

문단(`<p>`) 안에서 특정한 단어의 글씨를 굵게 만들거나, 기울이거나, 밑줄을 치고 싶을 때 사용하는 태그들입니다. 
시맨틱 태그 챕터에서 배웠던 것처럼, 눈에 보이는 시각적 효과뿐만 아니라 <b>스크린 리더(화면 낭독기)가 글을 읽을 때 강세를 주어 읽게 만드는 '의미(Semantic)'</b>를 포함하고 있는 경우가 많습니다.

워낙 종류가 많아 주로 쓰이는 태그들을 아래 표로 정리했습니다.

| 태그 | 역할 및 의미 | 시각적 효과 | 예시 코드 |
| :--- | :--- | :--- | :--- |
| **`<strong>`** | 텍스트의 **중요성, 심각성, 긴급함**을 강조합니다. 스크린 리더가 강한 억양으로 읽습니다. | **굵은 글씨** | `<p>비밀번호는 <strong>절대</strong> 타인에게 알려주지 마세요.</p>` |
| **`<b>`** | (Bold) 특별한 의미 부여 없이, 단순히 시각적으로만 글씨를 굵게 만들 때 사용합니다. | **굵은 글씨** | `<p>오늘의 요리 재료는 <b>당근, 양파, 감자</b>입니다.</p>` |
| **`<em>`** | (Emphasis) 문장 안에서 특정 단어를 **부드럽게 강조**할 때 사용합니다. | *기울임꼴* | `<p>저는 <em>정말로</em> 그 사과를 먹지 않았습니다.</p>` |
| **`<i>`** | (Italic) 기술 용어, 외국어 등 주변 텍스트와 분위기가 다른 글을 단순 표기할 때 씁니다. | *기울임꼴* | `<p>이 식물은 <i>Rosa corymbifera</i>라는 학명을 가집니다.</p>` |
| **`<cite>`** | 책, 영화, 음악, 미술 작품 등의 **제목이나 출처**를 나타낼 때 사용합니다. | *기울임꼴* | `<p>제가 가장 좋아하는 영화는 <cite>인터스텔라</cite>입니다.</p>` |
| **`<mark>`** | 문서에서 형광펜을 칠하듯 **관심을 끌거나 하이라이트**할 때 사용합니다. | <mark>노란색 배경</mark> | `<p>시험 범위는 <mark>3단원부터 5단원</mark>까지입니다.</p>` |
| **`<del>`** | (Delete) 내용이 삭제되었거나 더 이상 유효하지 않음을 나타냅니다. | ~~취소선~~ | `<p>정가: <del>50,000원</del> -> 할인가: 30,000원</p>` |
| **`<ins>`** | (Insert) 문서에 새롭게 추가된 텍스트임을 나타냅니다. | <u>밑줄</u> | `<p>회의 날짜가 <ins>금요일</ins>로 변경되었습니다.</p>` |
| **`<sup>`** | (Superscript) 수학의 거듭제곱 같은 **위첨자**를 만듭니다. | 윗글자 | `<p>물의 화학식은 H<sup>+</sup>가 아닙니다.</p>` |
| **`<sub>`** | (Subscript) 화학식의 원자 수 같은 **아래첨자**를 만듭니다. | 아랫글자 | `<p>물의 올바른 화학식은 H<sub>2</sub>O입니다.</p>` |

> [!TIP]
> **`<strong>`과 `<b>`는 똑같이 굵은 글씨인데 무엇을 써야 할까요?**\
> 웹 접근성에서는 시각장애인과 검색 엔진 봇을 배려하여, 단순히 굵게 보이는 `<b>` 태그보다 **'중요하다'는 의미를 담고 있는 `<strong>` 태그의 사용을 훨씬 더 권장**합니다. 마찬가지로 단순 기울임 꼴인 `<i>` 태그보다는 강조의 의미가 담긴 `<em>` 태그를 사용하는 것이 더 좋은 코딩 습관입니다.
