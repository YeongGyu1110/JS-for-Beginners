# 웹 페이지의 완성도 높이기

## 개요
길었던 HTML 기초 여정의 마지막 장에 오신 것을 환영합니다! 지금까지 웹 페이지의 뼈대를 세우고, 폼을 통해 사용자와 소통하며, 레이아웃을 나누는 방법까지 모두 다뤘습니다. 

마지막 문서에서는 여러분의 웹 페이지를 한 단계 더 프로페셔널하게 만들어 줄 실무 필수 기술들을 다룹니다. 기존 입력창보다 훨씬 다채롭게 꾸밀 수 있는 <b>버튼(`<button>`)</b>태그, 내 웹사이트에 유튜브 영상이나 구글 지도를 액자처럼 걸어두는 <b>아이프레임(`<iframe>`)</b>, 그리고 카카오톡이나 슬랙에 링크를 공유했을 때 예쁜 썸네일과 요약글이 뜨게 만드는 **메타데이터**까지 상세히 알아봅니다.

### 이 모듈에서 배울 내용
* 텍스트와 아이콘을 자유롭게 품을 수 있는 `<button>` 태그
* 다른 웹사이트나 외부 콘텐츠를 내 화면에 삽입하는 `<iframe>` 태그
* 웹 브라우저 탭에 나만의 작은 로고를 띄우는 파비콘
* 링크 공유 시 미리보기 카드를 만들어주는 오픈 그래프 메타 태그

---

## 1. 버튼 만들기: \<button\> 태그

이전 '폼과 사용자 입력' 챕터에서 폼을 제출하기 위해 `<input type="submit">`을 사용했었습니다. 하지만 실무 웹 개발에서는 이 방식보다 <b>`<button>` 태그</b>를 압도적으로 더 많이 사용합니다.

`<input>`은 종료 태그가 없는 빈 태그이기 때문에 `value` 속성으로 단순한 '글자'만 적어 넣을 수 있었습니다. 반면, `<button>`은 시작 태그와 종료 태그를 가지는 온전한 요소이므로 **버튼 안에 텍스트는 물론, 이미지나 돋보기 아이콘 같은 다른 태그들을 자유롭게 자식으로 품을 수 있습니다.**

### 버튼의 타입
`<button>` 태그를 사용할 때는 이 버튼이 어떤 역할을 하는지 <b>`type` 속성</b>으로 명확히 지정해 주는 것이 좋습니다.

* `type="submit"`(기본값) : `<form>` 상자 안의 데이터를 서버로 제출합니다. 
* `type="button"` : 아무런 기본 기능이 없는 순수한 버튼입니다. 자바스크립트(JS)[^1]를 연결하여 "클릭 시 팝업 띄우기" 같은 특정 동작을 실행할 때 주로 사용합니다.
* `type="reset"` : `<form>` 안의 사용자가 입력했던 모든 데이터를 초기화(빈칸)시킵니다.

```html
<!-- 단순한 텍스트 버튼 -->
<button type="button">클릭해보세요</button>

<!-- 버튼 안에 이미지와 텍스트를 함께 넣은 버튼 -->
<button type="submit">
    <img src="send-icon.png" alt="전송 아이콘" width="16"> 
    메시지 전송하기
</button>
```

## 2. 내 화면에 다른 웹사이트 띄우기: \<iframe\> 태그

초보 개발자들이 가장 궁금해하는 것 중 하나가 바로 "내 웹사이트에 유튜브 영상을 어떻게 띄우나요?" 혹은 "오시는 길 안내에 카카오맵을 어떻게 넣나요?"입니다. 

이 마법을 가능하게 해주는 것이 바로 <b>`<iframe>` (Inline Frame)</b> 태그입니다. 이 태그는 내 웹 페이지 안에 네모난 창문을 뚫어놓고, 그 창문을 통해 **다른 서버에 있는 웹 페이지나 콘텐츠를 그대로 불러와 보여주는 역할**을 합니다.

### `<iframe>`의 주요 속성
* `src`: 불러올 외부 콘텐츠의 URL\입니다.
* `width`, `height`: 요소의 가로세로 크기를 지정합니다.

```html
<!-- 내 웹 페이지 안에 위키백과 창을 띄웁니다. -->
<iframe src="https://ko.wikipedia.org" width="800" height="600"></iframe>
```

> [!TIP]
> **유튜브 영상 퍼가기**\
> 유튜브 영상 아래의 [공유] - [퍼가기] 버튼을 누르면 길고 복잡한 코드가 나오는데, 이것이 바로 `<iframe>` 태그입니다. `src`에 유튜브 전용 주소가 적혀있고, 전체화면을 허용하는 `allowfullscreen` 등의 추가 속성들이 포함되어 있습니다. 이를 복사해서 여러분의 HTML 파일 `<body>` 안에 붙여넣기만 하면 영상이 완벽하게 삽입됩니다.

> [!WARNING]
> **모든 웹사이트를 iframe으로 띄울 수 있나요?**
> 아닙니다. 네이버나 구글 같은 대형 포털 사이트를 `src`에 넣고 실행해 보면 화면에 나타나지 않거나 연결이 거부됩니다. 이는 보안상의 이유(클릭 재킹 해킹 방지 등)로 해당 사이트들이 <b>"우리 사이트는 다른 사람의 iframe 안에서 열리지 않게 해 달라"</b>고 서버 설정을 막아두었기 때문입니다.

## 3. 파비콘 (Favicon)

웹 브라우저 상단 탭을 자세히 보면, 웹사이트 제목 옆에 로고 아이콘이 떠 있는 것을 볼 수 있습니다. *(구글은 G 마크, 네이버는 N 마크, 그리고 이 페이지는 `#ff6b00` 색상을 가진 동그라미입니다.)* 이것을 <b>파비콘(Favicon, Favorite Icon)</b>이라고 부릅니다.

파비콘은 사용자가 즐겨찾기를 하거나 여러 개의 탭을 띄워놓았을 때 내 웹사이트를 한눈에 찾을 수 있게 도와주는 중요한 브랜딩 요소입니다. 파비콘 설정은 화면에 보이는 콘텐츠가 아니므로 <b>`<head>` 구역 안의 `<link>` 태그</b>를 사용하여 브라우저에게 아이콘 위치를 알려줍니다.

```html
<head>
    <meta charset="UTF-8">
    <title>나의 멋진 웹사이트</title>
    <!-- .ico, .png 등의 이미지 파일을 파비콘으로 설정합니다. -->
    <link rel="icon" href="./images/favicon.png">
</head>
```
*(웹 루트 폴더에 `favicon.ico`라는 이름으로 파일을 저장해 두면, 코드를 적지 않아도 브라우저가 알아서 찾아 띄우는 기능도 지원합니다.)*

## 4. 오픈 그래프 (Open Graph)

카카오톡이나 슬랙으로 URL만 복사해서 보냈는데, 채팅창에 **예쁜 배경 이미지와 굵은 텍스트 제목, 그리고 짧은 요약글이 하나의 카드 형태로 묶여서 나타나는 경험**을 해보셨을 것입니다. 카카오톡이 어떻게 내 웹사이트의 요약 정보를 귀신같이 알아냈을까요?

이것은 운이나 인공지능이 아니라, 우리가 HTML의 `<head>` 구역 안에 **오픈 그래프라는 특별한 메타데이터**를 미리 심어두었기 때문입니다. 페이스북에서 처음 만든 이 규칙은 현재 전 세계 거의 모든 메신저와 SNS에서 표준처럼 사용됩니다.

오픈 그래프는 <b>`<meta>` 태그의 `property` 속성</b>을 사용하여 설정합니다.

```html
<head>
    <!-- 다른 기본 설정들... -->
    
    <!-- 카톡/페이스북 등에 링크를 공유했을 때 뜨는 미리보기 설정 (Open Graph) -->
    <!-- 1. 미리보기 제목 -->
    <meta property="og:title" content="홍길동의 포트폴리오">
    
    <!-- 2. 미리보기 요약 설명글 -->
    <meta property="og:description" content="신입 프론트엔드 개발자 홍길동의 프로젝트 모음집입니다.">
    
    <!-- 3. 미리보기 썸네일 이미지 주소 -->
    <meta property="og:image" content="https://mywebsite.com/images/thumbnail.jpg">
    
    <!-- 4. 내 웹사이트의 대표 URL -->
    <meta property="og:url" content="https://mywebsite.com">
</head>
```

> [!IMPORTANT]
> **실무 필수 팁**\
> 실무에서 서비스를 런칭할 때 이 `og` 메타 태그를 빼먹으면, 링크를 공유했을 때 썸네일 없이 밋밋한 텍스트 주소만 날아가게 되어 사람들의 클릭률이 현저히 떨어집니다. 웹사이트를 다 만들고 배포하기 직전, **`<head>` 영역에 오픈 그래프 태그가 제대로 세팅되었는지 확인하는 것은 프론트엔드 개발자의 필수 점검 사항**입니다.
