# HTML 문서의 기본 뼈대와 태그

## 개요
이전 실습에서 우리는 웹 페이지를 띄우기 위해 `index.html` 파일에 몇 줄의 코드를 복사해서 붙여넣었습니다. 이 코드는 전 세계의 모든 웹 페이지가 공통으로 가지고 있는 <b>가장 기초적인 뼈대(Boilerplate)</b>입니다.

사람이 쓴 편지에도 '받는 사람 정보'가 적힌 봉투와 '실제 내용'이 적힌 편지지가 나뉘어 있듯이, HTML 문서도 목적에 따라 구역이 엄격하게 나뉘어 있습니다. 본 문서에서는 HTML의 핵심 문법인 <b>태그(Tag)</b>의 개념을 이해하고, 웹 문서를 구성하는 4가지 필수 요소(`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)가 각각 왜 존재해야 하는지 그 역할을 상세히 알아봅니다. 더 나아가, `<body>` 구역 내부를 아무렇게나 나누지 않고 **'의미'에 맞게 구역을 나누는 시맨틱(Semantic) 태그**의 종류와 중요성에 대해서도 학습합니다.

### 이 모듈에서 배울 내용
* 꺾쇠 괄호(`< >`)로 이루어진 태그(Tag)의 기본 문법과 작동 원리
* 문서 구조 태그(`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
* 시맨틱 태그(`<header>`, `<main>`, `<footer>` 등)

---

## 1. 태그(Tag)

HTML은 브라우저에게 "이 텍스트는 제목이야", "이 텍스트는 버튼이야"라고 알려주기 위해 <b>태그(Tag)</b>라는 특별한 문법을 사용합니다. 

데이터를 태그로 감싸는 것은 마치 내용물을 알맞은 상자에 넣고 이름표를 붙여 포장하는 것과 같습니다. 태그는 항상 키보드의 꺾쇠 괄호 `< >`를 사용하여 작성합니다.

* **시작 태그:** `<태그이름>` 형태로 상자를 엽니다.
* **종료 태그:** `</태그이름>` 형태로 이름 앞에 슬래시(`/`)를 넣어 상자를 닫습니다.

```html
<!-- h1 태그는 가장 큰 제목(Heading)을 의미하는 이름표입니다. -->
<h1>이것은 제목입니다</h1>

<!-- p 태그는 하나의 문단(Paragraph)을 의미하는 이름표입니다. -->
<p>이것은 본문 텍스트입니다. 태그로 감싸진 글자들은 브라우저에 의해 알맞게 해석됩니다.</p>
```

이렇게 시작 태그와 종료 태그, 그리고 그 안의 내용물을 모두 합쳐서 <b>요소(Element)</b>라고 부릅니다. 어떤 태그를 쓰느냐에 따라 브라우저는 안의 텍스트를 굵은 글씨로 보여줄지, 표(Table)로 보여줄지 결정하게 됩니다.

> [!NOTE]
> **HTML 주석 작성법**\
> HTML 코드 내에서 브라우저가 실행하지 않고 개발자만 볼 수 있는 메모를 남길 때는 `<!-- 주석 내용 -->` 형태로 작성합니다.

> [!NOTE]
> **닫는 태그가 없는 빈 태그 (Empty Tag)**\
> 모든 태그가 반드시 짝을 이루는 것은 아닙니다. 감쌀 내용물이 없는 태그들은 종료 태그 없이 단독으로 사용됩니다. 이미지를 넣는 `<img>`, 줄바꿈을 하는 `<br>`, 입력창을 만드는 `<input>` 등이 대표적입니다.

## 2. 문서의 시작: \<!DOCTYPE html\>

HTML 문서를 열면 가장 첫 줄에 무조건 등장하는 코드입니다. 

이것은 엄밀히 말해 HTML 태그가 아니라, 브라우저에게 <b>"이 문서는 최신 표준 기술인 HTML5 버전으로 작성되었으니, 그 규칙에 맞게 화면을 그려달라"</b>고 지시하는 <b>선언문(Declaration)</b>입니다.

만약 이 선언을 빼먹으면, 구형 브라우저들은 과거의 낡은 규칙(Quirks Mode)으로 화면을 제멋대로 그려버려 웹 페이지의 디자인이 와장창 깨질 수 있습니다. 따라서 무조건 문서의 맨 윗줄에 작성해야 하는 필수 부적과도 같습니다.

---

## 3. 최상위 뿌리: \<html\>

선언문 바로 다음에는 `<html>` 태그가 열리고, 문서의 맨 마지막 줄에서 `</html>`로 닫힙니다. 

이는 <b>"여기서부터 여기까지가 진짜 HTML 문서입니다"</b>라고 브라우저에게 알려주는 거대한 포장지이자, 문서의 가장 바탕이 되는 최상위(Root) 태그입니다. 이 태그 바깥에는 어떠한 내용도 작성해서는 안 됩니다.

```html
<!DOCTYPE html>
<html lang="ko">
    <!-- 이 안에 모든 문서의 내용이 들어갑니다. -->
</html>
```

`<html>` 태그에는 주로 `lang`이라는 속성을 적어주어 이 웹 페이지가 어떤 언어로 작성되었는지(한국어라면 `ko`, 영어라면 `en`) 검색 엔진이나 시각장애인용 화면 읽기 프로그램에 알려줍니다.

---

## 4. 메타데이터: \<head\>

`<html>` 태그 안쪽은 크게 두 구역으로 나뉩니다. 그중 첫 번째 구역이 바로 `<head>`입니다.

`<head>` 구역은 사람으로 치면 <b>'뇌'</b>나 <b>'신분증'</b>에 해당합니다. 이곳에 작성된 내용은 <b>사용자가 보는 웹 브라우저의 하얀 화면(도화지)에는 절대 나타나지 않습니다.</b> 대신, 브라우저나 구글 같은 검색 엔진이 문서를 읽을 때 필요한 <b>'데이터를 위한 데이터(메타데이터, Metadata)'</b>를 담아둡니다.

* **`<meta charset="UTF-8">`**: 브라우저에게 한글이나 특수문자가 깨지지 않도록 어떤 문자 인코딩(UTF-8)을 써서 읽어야 하는지 알려줍니다.
* **`<title>`**: 웹 브라우저 상단의 '탭 이름'에 표시될 제목을 정합니다. 즐겨찾기를 할 때 기본 이름이 되며, 검색 엔진 결과에도 노출되는 아주 중요한 태그입니다.
* 기타: 디자인 파일(CSS)을 불러오거나 웹 페이지의 요약 설명을 적어둘 때도 모두 이 `<head>` 구역을 사용합니다.

```html
<head>
    <meta charset="UTF-8">
    <title>나의 첫 웹 페이지</title>
</head>
```

## 5. 눈에 보이는 몸통: \<body\>

`<head>`가 닫히고 나면, 두 번째 구역인 `<body>`가 열립니다. 

사람의 <b>'몸통'</b>에 해당하는 구역으로, <b>사용자가 브라우저 화면을 통해 눈으로 직접 보게 될 모든 시각적인 내용</b>은 반드시 이 `<body>` 태그 안에 작성되어야 합니다.

제목, 본문 텍스트, 이미지, 버튼, 표, 링크 등 앞으로 우리가 배우게 될 수많은 HTML 태그들은 전부 100% `<body>`와 `</body>` 사이에 배치됩니다.

```html
<body>
    <h1>환영합니다!</h1>
    <p>여기에 적힌 글자들만 브라우저의 흰 화면에 렌더링되어 나타납니다.</p>
</body>
```

### 기본 뼈대

위에서 배운 4가지 필수 요소를 올바른 순서대로 합치면 아래와 같은 완벽한 기본 뼈대가 완성됩니다. 브라우저는 이 뼈대를 바탕으로 보이지 않는 설정(`<head>`)을 세팅한 뒤, 실제 그림(`<body>`)을 화면에 그려냅니다.

```html
<!-- 1. 나는 HTML5 문서입니다! -->
<!DOCTYPE html>
<!-- 2. 여기서부터 HTML 문서 시작 (언어는 한국어) -->
<html lang="ko">

<!-- 3. 설정(메타데이터) 시작 (화면에 안 보임) -->
<head>
    <meta charset="UTF-8">
    <title>웹 문서의 뼈대</title>
<!-- 설정 끝 -->
</head>

<!-- 4. 실제 콘텐츠 시작 (화면에 보임) -->
<body>
    <h1>이곳이 실제 브라우저 화면에 나타나는 영역입니다.</h1>
<!-- 콘텐츠 끝 -->
</body>

<!-- HTML 문서 끝 -->
</html>
```

> [!IMPORTANT]
> 코드를 작성할 때 `<head>`가 열려있는데 그 안에 `<body>`를 넣거나, 태그를 닫기도 전에 다른 태그를 여닫는 등 <b>순서와 포함 관계(부모 자식 관계)</b>가 꼬이지 않도록 들여쓰기(Tab)를 잘 맞추어 작성하는 것이 매우 중요합니다.

---

## 6. 시맨틱 태그 (Semantic Tag)

앞서 모든 시각적인 콘텐츠는 `<body>` 안에 들어간다고 배웠습니다. 하지만 웹 페이지에는 단순히 글자만 있는 것이 아닙니다. 상단에는 로고와 메뉴바가 있고, 가운데에는 진짜 본문이 있으며, 맨 아래에는 저작권 정보가 있습니다.

과거에는 이러한 구역을 나눌 때 아무런 의미가 없는 빈 상자 태그를 사용했습니다. 하지만 최신 HTML5부터는 **"이 구역이 웹 페이지에서 어떤 역할을 하는지" 그 의미(Semantic)를 브라우저와 검색 엔진에게 명확히 알려주기 위한 전용 태그들**이 등장했습니다. 이를 <b>시맨틱 태그(Semantic Tag)</b>라고 부릅니다.

### 주요 시맨틱 태그의 종류와 역할

* **`<header>` (머리말):** 웹 페이지나 특정 구역의 맨 위쪽을 담당합니다. 주로 웹사이트의 로고나 제목, 검색창 등이 들어갑니다.
* **`<nav>` (내비게이션):** Navigation의 약자로, 다른 페이지나 웹사이트 내의 다른 구역으로 이동할 수 있는 **메뉴 링크**들을 모아두는 곳입니다. 보통 `<header>` 안이나 바로 밑에 위치합니다.
* **`<main>` (주요 콘텐츠):** 해당 웹 페이지에서 **가장 핵심이 되는 본문**을 감싸는 태그입니다. 한 페이지 안에서 `<main>` 태그는 오직 한 번만 사용해야 합니다.
* **`<section>` (구역):** 하나의 명확한 주제를 가진 콘텐츠들의 그룹을 묶어줄 때 사용합니다. 신문의 '정치면', '경제면'처럼 페이지를 논리적으로 나눌 때 쓰며, 내부에는 보통 그 구역의 제목이 포함됩니다.
* **`<article>` (독립된 글):** 블로그 포스트, 뉴스 기사, 게시판의 글 하나처럼 <b>그 자체로 떼어내서 다른 곳에 가져다 놓아도 완전히 독립적으로 이해될 수 있는 콘텐츠</b>를 감쌉니다.
* **`<aside>` (사이드바):** 본문(`<main>`)과는 직접적인 관련이 적은 곁다리 정보들을 모아둡니다. 웹사이트 우측이나 좌측의 '광고 배너', '최근 본 상품', '관련 링크' 등이 들어갑니다.
* **`<footer>` (꼬리말):** 웹 페이지의 맨 아래쪽 바닥을 담당합니다. 저작권 정보, 회사 주소, 연락처, 이용 약관 링크 등이 이곳에 배치됩니다.

### 시맨틱 태그로 구성한 웹 페이지 레이아웃

이 태그들을 활용하여 `<body>` 내부를 구성하면, 코드만 봐도 웹 페이지의 전체적인 디자인과 레이아웃이 한눈에 그려집니다.

```html
<body>
    <!-- 상단 영역 -->
    <header>
        <h1>나의 멋진 블로그</h1>
        <nav>
            <!-- 메뉴 링크들이 들어갈 자리 -->
            <a href="#">홈</a>
            <a href="#">소개</a>
            <a href="#">연락처</a>
        </nav>
    </header>

    <!-- 메인 본문 영역 -->
    <main>
        <!-- 본문 안의 독립적인 글 내용 -->
        <article>
            <h2>시맨틱 태그의 중요성</h2>
            <p>시맨틱 태그를 사용하면 웹 접근성과 SEO가 크게 향상됩니다.</p>
        </article>
        
        <!-- 본문과 관련된 부가 정보 (사이드바) -->
        <aside>
            <h3>인기 글 목록</h3>
            <!-- 목록 내용들 -->
        </aside>
    </main>

    <!-- 하단 바닥 영역 -->
    <footer>
        <p>© 2026 나의 멋진 블로그. All rights reserved.</p>
        <p>이메일: contact@myblog.com</p>
    </footer>
</body>
```

> [!TIP]
> **시맨틱 태그는 왜 꼭 써야 할까요?**\
> 시맨틱 태그를 쓴다고 해서 브라우저가 화면을 당장 예쁘게 꾸며주거나 기능이 생기는 것은 아닙니다. 눈으로 보기에는 일반 텍스트나 빈 상자와 다를 바가 없습니다. 하지만 **눈에 보이지 않는 아주 중요한 두 가지 효과**를 가집니다.
> 1. **검색 엔진 최적화 (SEO):** 구글이나 네이버의 검색 봇이 웹사이트를 방문했을 때, `<main>`이나 `<article>` 안에 있는 글을 "이것이 진짜 핵심 정보구나!"라고 판단하여 검색 결과 상단에 띄워줍니다.
> 2. **웹 접근성 (Accessibility):** 시각장애인들이 사용하는 '스크린 리더(화면 낭독기)' 프로그램이 시맨틱 태그를 인식하여, "여기서부터 메인 본문입니다" 혹은 "여기서부터 메뉴바입니다"라고 사용자에게 정확히 안내해 줄 수 있습니다.
