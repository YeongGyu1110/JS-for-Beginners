# 화면 배치 원리와 그룹화 태그

## 개요
지금까지 우리는 웹 페이지에 제목(`<h1>`), 본문(`<p>`), 이미지(`<img>`), 입력창(`<input>`) 등을 띄우는 다양한 시맨틱 태그들을 배웠습니다. 하지만 배운 태그들을 화면에 막상 적어보면, 어떤 태그는 줄바꿈이 되어 아래로 차곡차곡 쌓이고, 어떤 태그는 줄바꿈 없이 옆으로 나란히 다닥다닥 붙어 나오는 것을 발견할 수 있습니다. 

본 문서에서는 브라우저가 화면에 태그들을 배치하는 두 가지 핵심 원리인 <b>블록(Block)</b>과 <b>인라인(Inline)</b>의 개념을 파헤쳐 봅니다. 더불어, 특별한 의미는 없지만 여러 태그들을 하나의 그룹으로 묶어주는 <b>투명한 만능 상자인 `<div>`와 `<span>` 태그</b>에 대해 학습합니다. 이 개념들은 향후 CSS를 통해 웹 페이지의 레이아웃을 잡을 때 가장 기본이 되는 필수 지식입니다.

### 이 모듈에서 배울 내용
* 블록 요소와 인라인 요소의 차이점
* 블록 요소의 특징과 중첩 규칙
* 인라인 요소의 특징과 한계점
* 여러 블록을 묶어 큰 구역을 만드는 만능 컨테이너 <b>`<div>`</b>
* 문장 안에서 특정 부분만 묶어내는 투명한 끈 <b>`<span>`</b>

---

## 1. 화면 배치의 두 가지 성격

HTML의 모든 태그들은 브라우저 화면에 배치되는 <b>Display 성질</b>을 가지고 있습니다. 이는 크게 **블록**과 **인라인** 두 가지로 나뉩니다.

태그의 Display 성질에 따라 다른 태그와 옆에 나란히 설 수 있는지, 아니면 무조건 혼자서 한 줄을 다 차지하는지가 결정됩니다.

---

## 2. 블록 요소

블록 요소는 이름 그대로 <b>하나의 거대한 벽돌</b>처럼 행동하는 태그들입니다.

### 주요 특징
1. **가로 공간 독차지:** 내용물의 길이에 상관없이, 화면의 **너비 전체를 꽉 채워** 자리를 차지합니다.
2. **자동 줄바꿈:** 가로를 모두 차지하므로, 블록 요소 다음에 오는 태그는 무조건 **새로운 줄**로 밀려나서 렌더링됩니다.
3. **포용성:** 블록 요소 안에는 텍스트는 물론, 인라인 요소와 또 다른 블록 요소를 자유롭게 자식으로 품을 수 있습니다.

### 대표적인 블록 태그
* `<h1>` ~ `<h6>`
* `<p>`
* `<ul>`, `<ol>`, `<li>`
* `<table>`
* `<form>`
* `<header>`, `<main>`, `<footer>` 등 대부분의 시맨틱 태그

```html
<!-- h1과 p는 모두 블록 요소이므로 각각 한 줄씩을 독차지하며 아래로 쌓입니다. -->
<h1 style="background-color: yellow;">저는 블록 요소입니다. 가로를 다 차지합니다.</h1>
<p style="background-color: lightblue;">저는 블록 요소입니다. 새 줄에서 시작합니다.</p>
```

## 3. 인라인 요소

인라인 요소는 <b>'줄 안에 머무는'</b> 조신한 태그들입니다. 텍스트의 흐름을 끊지 않고 함께 어울려 배치됩니다.

### 주요 특징
1. **내용물만큼만 공간 차지:** 자기가 감싸고 있는 <b>텍스트나 알맹이의 너비만큼만</b> 최소한의 자리를 차지합니다.
2. **나란히 배치:** 가로 공간이 남는다면 줄바꿈을 하지 않고, 앞뒤의 다른 인라인 요소들과 **옆으로 나란히** 붙어서 렌더링됩니다.
3. **제한적인 포용성:** 인라인 요소 안에는 텍스트나 또 다른 인라인 요소만 넣을 수 있습니다. <b>인라인 요소 안에는 거대한 블록 요소를 자식으로 넣어서는 안 됩니다.</b>

### 인라인 태그
* `<a>`
* `<input>`, `<label>`
* `<strong>`, `<em>` 등 텍스트 꾸밈 태그
* `<img>` *화면을 차지하는 고유 크기가 있어 '인라인 블록'으로도 불립니다.*

```html
<!-- a와 strong은 인라인 요소이므로 줄을 바꾸지 않고 한 줄에 나란히 붙어 나옵니다. -->
<a href="#" style="background-color: pink;">저는 인라인입니다.</a>
<strong style="background-color: lightgreen;">저도 인라인이라 옆에 붙습니다.</strong>
```

> [!IMPORTANT]
> **잘못된 태그 중첩 (Nesting)**\
> 인라인 요소(작은 끈)로 블록 요소(거대한 상자)를 감싸는 것은 HTML 문법상 어긋나는 행동입니다.
> 
> **오류 예시:** `<strong>` (인라인) 안에 `<p>` (블록)를 넣음
> ```html
> <strong>
>     <p>이렇게 작성하면 안 됩니다!</p>
> </strong>
> ```
> 
> **올바른 예시:** `<p>` (블록) 안에 `<strong>` (인라인)을 넣음
> ```html
> <p>
>     <strong>이렇게 작성하는 것이 맞습니다!</strong>
> </p>
> ```

## 4. 투명한 만능 상자: \<div\> 태그

앞서 `<header>`, `<main>`, `<article>` 같은 시맨틱 태그를 배웠습니다. 하지만 복잡한 쇼핑몰이나 포털 사이트를 만들다 보면, 의미를 부여하기 애매하지만 **단순히 레이아웃을 위해 여러 요소들을 하나로 묶어야 할 때**가 수없이 많습니다.

이럴 때 사용하는 가장 대표적인 태그가 <b>`<div>` (Division)</b>입니다.

* **특징:** `<div>`는 <b>블록 성질</b>을 가진 투명한 컨테이너입니다. 
* **역할:** 그 자체로는 화면에 아무런 시각적 변화나 의미를 주지 않지만, 제목, 이미지, 문단 등을 <b>하나의 큰 박스로 묶어 그룹화</b>하는 껍데기 역할을 합니다.

```html
<!-- 하나의 '프로필 카드' 구역을 만들기 위해 이미지, 제목, 본문을 div로 묶었습니다. -->
<div>
    <img src="profile.jpg" alt="홍길동 프로필 이미지">
    <h3>홍길동</h3>
    <p>안녕하세요, 웹 개발자 홍길동입니다.</p>
</div>

<!-- 또 다른 상품 구역을 div로 묶었습니다. -->
<div>
    <img src="shoes.jpg" alt="운동화">
    <h3>멋진 운동화</h3>
    <p>가격: 50,000원</p>
</div>
```

> [!NOTE]
> <b>시맨틱 태그와 `<div>`의 관계</b>\
> 사실 `<header>`, `<footer>`, `<section>` 같은 시맨틱 태그들은 기능적으로 `<div>`와 100% 똑같은 블록 상자입니다. 단지 컴퓨터가 이해할 수 있도록 <b>"이 상자는 머리말 전용 껍데기야"</b>라고 의미가 담긴 이름표를 붙여둔 `<div>`의 발전된 형태라고 이해하면 쉽습니다.

---

## 5. 텍스트를 묶는 투명한 끈: \<span\> 태그

`<div>`가 여러 요소를 묶는 거대한 블록 상자라면, <b>`<span>`</b>은 문장 안에서 특정 글자들을 묶어내는 <b>인라인성질</b>의 투명한 끈입니다.

`<strong>`처럼 굵어지거나 `<em>`처럼 기울어지는 시각적 효과도, 의미(Semantic)도 전혀 없습니다. 

> [!TIP]
> **언제 사용하나요?**\
> 문단(`<p>`) 속 긴 텍스트 중에서 <b>단어 하나, 혹은 짧은 문구 하나만 콕 집어서</b> CSS[^1]로 글자 색상을 바꾸거나 배경색을 칠하고 싶을 때, 그 부분만 살짝 묶어두는 용도로 사용합니다.

```html
<p>
    오늘 점심 메뉴는 <span>제육볶음</span>과 <span>김치찌개</span>입니다.
</p>
```
*(위 코드를 브라우저에서 실행하면 `<span>`을 쓰지 않았을 때와 화면상 똑같이 보입니다. 줄바꿈도 일어나지 않으며 글자 모양도 변하지 않습니다. 하지만 내부적으로는 두 단어가 각각 투명한 끈으로 잘 묶여있는 상태입니다.)*

[^1]: **C**ascading **S**tyle **S**heets, 웹페이지의 디자인을 다룰 때 사용되는 기술입니다.
