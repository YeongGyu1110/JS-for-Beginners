# 멀티미디어 (이미지, 오디오, 비디오)

## 개요
초창기의 웹 페이지는 오직 텍스트와 링크로만 이루어진 딱딱한 문서였습니다. 하지만 오늘날의 웹은 화려한 사진과 배경음악, 그리고 유튜브와 같은 고화질 동영상이 끊임없이 재생되는 생동감 넘치는 공간입니다. 

본 문서에서는 단순히 글자를 보여주는 것을 넘어, 시각과 청각을 자극하는 **멀티미디어(Multimedia) 요소**들을 웹 페이지에 삽입하는 방법을 알아봅니다. 이미지를 띄우는 `<img>` 태그부터 시작하여 웹 문서의 경로 개념을 이해하고, 소리와 영상을 재생하는 `<audio>`, `<video>` 태그의 다양한 제어 속성들을 상세히 학습합니다.

### 이 모듈에서 배울 내용
* 이미지를 삽입하는 `<img>` 빈 태그와 필수 속성(`src`, `alt`)
* 외부 링크와 내 컴퓨터 파일을 불러오는 절대 경로와 상대 경로의 이해
* 오디오 컨트롤러를 띄우고 음악을 재생하는 `<audio>` 태그
* 웹 페이지에 영상을 삽입하고 썸네일을 설정하는 `<video>` 태그
* 미디어 자동 재생(`autoplay`) 시 주의해야 할 브라우저의 정책

---

## 1. 이미지 삽입하기 (img)

웹 페이지에 사진이나 일러스트 등의 이미지를 넣을 때는 `<img>` 태그를 사용합니다. 이 태그는 텍스트를 감쌀 필요가 없으므로 <b>종료 태그가 없는 빈 태그</b>입니다. 

대신, "어떤 이미지를 가져올 것인가"에 대한 정보를 태그 안의 <b>속성(Attribute)</b>으로 반드시 적어주어야 합니다.

### 필수 속성 1: `src` (Source)
이미지 파일이 있는 경로나 인터넷 주소를 지정합니다. 이 속성이 없으면 이미지를 띄울 수 없습니다.

### 필수 속성 2: `alt` (Alternative Text)
이미지가 삭제되었거나 인터넷이 느려 로딩되지 않을 때, 이미지 대신 <b>화면에 띄워줄 '대체 텍스트'</b>입니다.
시각장애인용 스크린 리더가 이 글자를 읽어주어 어떤 이미지인지 설명해주며, 검색 엔진이 이미지를 분석할 때도 이 속성을 활용하므로 무조건 작성하는 습관을 들여야 합니다.

```html
<!-- 인터넷에 있는 이미지 주소를 가져와 띄우는 예시 -->
<img src="https://example.com/puppy.jpg" alt="들판에서 뛰어노는 귀여운 강아지">

<!-- 너비(width)와 높이(height) 속성을 추가하여 크기를 조절할 수도 있습니다. (픽셀 단위) -->
<img src="https://example.com/logo.png" alt="회사 로고" width="200" height="100">
```

## 2. 파일 경로의 이해 (상대 경로)

인터넷 주소(`https://...`)를 `src`에 넣으면 이미지가 잘 뜨지만, 내 컴퓨터 폴더에 저장해 둔 이미지를 웹 페이지에 띄우려면 <b>경로(Path)</b>라는 개념을 알아야 합니다. 

웹 개발에서는 현재 작업 중인 HTML 파일을 기준으로 목표 파일이 어디에 있는지를 따지는 <b>상대 경로</b>를 주로 사용합니다.

* `./` : 현재 HTML 파일이 있는 <b>같은 폴더(현재 위치)</b>를 의미합니다. 이는 생략할 수 있습니다.
* `../` : 현재 폴더를 감싸고 있는 **상위(부모) 폴더**로 한 칸 빠져나간다는 의미입니다.

```html
<!-- 1. 같은 폴더에 있는 이미지 불러오기 -->
<img src="./cat.jpg" alt="고양이 사진">
<img src="cat.jpg" alt="고양이 사진"> <!-- ./ 는 생략해도 똑같이 작동합니다. -->

<!-- 2. 같은 폴더 안에 있는 'images'라는 하위 폴더 속의 이미지 불러오기 -->
<img src="./images/dog.jpg" alt="강아지 사진">

<!-- 3. 현재 폴더 밖으로 한 칸 나가서 딴 곳에 있는 이미지 불러오기 -->
<img src="../profile.png" alt="프로필 사진">
```

> [!WARNING]
> **절대 경로**\
> 내 컴퓨터의 위치를 통째로 적는 `C:\Users\Desktop\image.jpg` 같은 방식을 '절대 경로'라고 합니다. 이 방식으로 작성하면 내 컴퓨터에서는 사진이 잘 보이지만, 이 HTML 파일을 다른 사람에게 보내거나 인터넷 서버에 올리면 **경로가 달라져 이미지가 모조리 엑스박스로 깨져버립니다.** 반드시 상대 경로(`./`, `../`)를 사용하세요!

## 3. 오디오 삽입하기 (audio)

배경음악이나 효과음, 팟캐스트 같은 음성 파일을 삽입할 때는 `<audio>` 태그를 사용합니다. 
이 태그는 단독으로 쓰기보다는 내부에 <b>`<source>` 태그</b>를 넣어 어떤 파일을 재생할지 브라우저에게 알려주는 방식으로 많이 사용합니다.

### 주요 제어 속성
* `controls`: 화면에 재생, 일시정지, 볼륨 조절 버튼이 있는 컨트롤러를 띄웁니다. (이게 없으면 화면에 아무것도 안 보여서 음악을 켤 수 없습니다!)
* `autoplay`: 페이지가 열리자마자 음악을 자동으로 재생합니다.
* `loop`: 음악이 끝나면 처음부터 다시 반복 재생합니다.
* `muted`: 음악을 음소거 상태로 시작합니다.

```html
<!-- 컨트롤러를 화면에 띄우고, 반복 재생을 설정합니다. -->
<audio controls loop>
    <!-- mp3 파일을 불러옵니다. 브라우저에게 파일 형식을 type으로 알려주면 더 좋습니다. -->
    <source src="./music/bgm.mp3" type="audio/mpeg">
    <source src="./music/bgm.ogg" type="audio/ogg">
    
    <!-- 구형 브라우저에서 오디오 태그를 지원하지 않을 때 이 텍스트가 뜹니다. -->
    오디오 재생을 지원하지 않는 브라우저입니다.
</audio>
```
*(여러 개의 `<source>`를 넣으면 브라우저가 위에서부터 읽으며 자신이 재생할 수 있는 첫 번째 파일을 선택해 재생합니다.)*

## 4. 비디오 삽입하기 (video)

웹 페이지에 동영상을 삽입하는 `<video>` 태그는 `<audio>` 태그와 사용법이 거의 똑같습니다. 하지만 화면에 시각적으로 보여야 하므로 크기를 지정하거나 썸네일을 넣는 속성이 추가로 존재합니다.

### 비디오 전용 추가 속성
* `width` / `height`: 영상의 가로, 세로 크기를 지정합니다.
* `poster`: 영상이 재생되기 전에 화면에 띄워둘 **미리보기 이미지** 파일의 경로를 넣습니다.

```html
<video width="640" controls poster="./images/thumbnail.jpg">
    <source src="./video/movie.mp4" type="video/mp4">
    동영상 재생을 지원하지 않는 브라우저입니다.
</video>
```

> [!TIP]
> **왜 autoplay(자동 재생)가 작동하지 않나요?**\
> 최근의 웹 브라우저들(크롬, 사파리 등)은 사용자가 원치 않는 갑작스러운 소음을 막기 위해 <b>'소리가 나는 미디어의 자동 재생'을 엄격하게 차단</b>하는 정책을 가지고 있습니다. 
> 
> 따라서 동영상을 배경 화면처럼 페이지 진입 즉시 자동으로 재생시키고 싶다면, **반드시 `muted` (음소거) 속성을 함께 적어주어야만** `autoplay`가 정상적으로 작동합니다.
> ```html
> <!-- 음소거 상태여야만 자동 재생이 허락됩니다! -->
> <video autoplay muted loop>
>     <source src="background.mp4" type="video/mp4">
> </video>
> ```
