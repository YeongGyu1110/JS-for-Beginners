# 다크 테마 디자인 시스템 구축하기

사용자의 눈 건강과 몰입감을 위한 다크 테마 설계 방법론입니다.

## 1. 다크 테마의 장점
- 눈의 피로 감소 (특히 저녁 시간대)
- 배터리 절약 (OLED 디스플레이의 경우)
- 디자인의 깊이감 표현

## 2. 디자인 원칙
### 2-1. 순수한 검정색 피하기
너무 밝은 흰색 글자와 순수한 검정색 배경은 대비가 너무 심해 눈을 피로하게 합니다.

### 2-2. 적절한 계층 구조
레이어의 깊이를 색상의 밝기(Surface Color)로 구분하세요.

```css
:root {
  --bg-color: #0c0d0f;    /* 가장 뒤 */
  --surface-color: #13151a; /* 그 위 레이어 */
  --surface-hover: #191c22; /* hover 상태 */
}
```

## 3. 구현 단계
### 3-1. 컬러 팔레트 구축
색상은 너무 많지 않게 5~7개 정도로 제한하세요.

### 3-2. 가독성 테스트
WCAG 기준에 맞게 텍스트 색상 대비를 확인합니다.

## 4. 고려 사항
### 4-1. 테마 스위처
사용자가 직접 테마를 전환할 수 있는 기능을 제공하면 좋습니다.

## 5. 결론
다크 테마는 단순한 색상 변경이 아닙니다. 사용자 경험(UX) 전체를 고려한 설계입니다.
