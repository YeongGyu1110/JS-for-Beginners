# 첫 번째 코드 실행하기

## 개요
자바스크립트 코드를 작성할 에디터와 코드를 실행할 엔진이 준비되었다면, 이제 파일에 코드를 작성하고 컴퓨터에 직접 명령을 내려 코드를 구동해 볼 차례입니다.

이번 모듈에서는 자바스크립트 파일(`.js`)을 생성하고, 가상의 시스템 제어 코드를 복사하여 Node.js 환경에서 실행해 봅니다. 코드가 어떻게 순차적으로 실행되는지 터미널의 출력 결과를 통해 확인하고, 특정 값을 직접 수정하여 시스템의 에러를 해결하는 미션을 수행합니다.

### 준비물
* VS Code와 Node.js가 설치된 PC

### 이 모듈에서 배울 내용
* VS Code에서 작업 폴더 열기 및 자바스크립트 파일 생성
* `node` 명령어를 사용한 코드 실행
* 터미널 출력 결과 분석 및 명시된 코드 값 수정

---

## Task 1. 작업 폴더와 파일 만들기

코드를 작성하기 위해서는 파일들을 모아둘 <b>작업 폴더(디렉터리)</b>가 필요합니다. 

1. 바탕화면이나 원하는 위치에 `js-study`라는 이름으로 새 폴더를 생성합니다.
2. VS Code를 열고 상단 메뉴에서 **[File(파일)]** → <b>[Open Folder...(폴더 열기...)]</b>를 클릭합니다.
3. 방금 생성한 `js-study` 폴더를 선택하여 엽니다.
   *(만약 '이 폴더의 작성자를 신뢰합니까?'라는 경고창이 나타나면 <b>[예, 작성자를 신뢰합니다]</b>를 클릭합니다.)*
4. VS Code 좌측 탐색기 창의 빈 공간을 우클릭하고 <b>[New File...(새 파일...)]</b>을 선택합니다.
5. 파일 이름을 `app.js`로 입력하고 **Enter** 키를 누릅니다.

> **예상 결과:**
> 우측에 `app.js`라는 이름의 빈 텍스트 편집 창이 열립니다. 확장자 `.js`는 이 파일이 자바스크립트 코드로 작성되었음을 의미합니다.

---

## Task 2. 시스템 진단 코드 작성하기

미리 준비된 가상의 시스템 진단 코드를 복사하여 실행해 봅니다.

1. 열려있는 `app.js` 파일에 아래의 코드를 복사하여 붙여넣습니다.

```javascript
console.log("=============================================");
console.log("   시스템 부팅 중... [System Booting...]     ");
console.log("=============================================");

// 1. 시스템 설정 값 
const launchConfig = {
    systemName: "Nuri-V",
    fuelLevel: 65,           // 숫자: 최소 80 이상이어야 함
    isWeatherClear: false,   // 불리언: true 여야 함
    enginePressure: 120      // 숫자: 80 이상 ~ 110 이하여야 정상 범위
};

let isSystemSafe = true;

// 2. 시스템 조건 검증 로직
function runSystemCheck() {
    console.log(`\n▶ [${launchConfig.systemName}] 데이터 검증을 시작합니다.`);

    setTimeout(() => {
        console.log("\n[점검 1] 연료 탱크 잔량 확인 중...");
        if (launchConfig.fuelLevel >= 80) {
            console.log(`[PASS] 연료가 충분합니다. (${launchConfig.fuelLevel}%)`);
        } else {
            console.log(`[FAIL] 연료 부족! (${launchConfig.fuelLevel}% / 최소 80% 필요)`);
            isSystemSafe = false;
        }
    }, 1000);

    setTimeout(() => {
        console.log("\n[점검 2] 발사대 기상 조건 분석 중...");
        if (launchConfig.isWeatherClear === true) {
            console.log("[PASS] 기상 상태가 양호합니다.");
        } else {
            console.log("[FAIL] 기상 조건 부적합. (낙뢰 또는 강풍 위험)");
            isSystemSafe = false;
        }
    }, 2000);

    setTimeout(() => {
        console.log("\n[점검 3] 핵심 엔진 압력 테스트 중...");
        if (launchConfig.enginePressure >= 80 && launchConfig.enginePressure <= 110) {
            console.log(`[PASS] 엔진 압력 정상 범위입니다. (${launchConfig.enginePressure} bar)`);
        } else {
            console.log(`[FAIL] 엔진 압력 비정상! (${launchConfig.enginePressure} bar / 정상범위: 80~110)`);
            isSystemSafe = false;
        }
    }, 3000);

    // 3. 최종 승인 단계
    setTimeout(() => {
        console.log("\n=============================================");
        console.log("시스템 최종 분석 완료...");
        console.log("=============================================");
        
        if (isSystemSafe) {
            console.log("승인: 모든 조건 충족. 카운트다운을 시작합니다.");
            setTimeout(startCountdown, 1000);
        } else {
            console.log("경고: [LAUNCH ABORT] 안전을 위해 시스템을 셧다운합니다.");
            console.log("미션: 코드 상단의 'launchConfig' 설정 값을 수정하여 발사를 성공시키세요!");
            console.log("=============================================\n");
        }
    }, 4500);
}

// 4. 카운트다운 및 실행 로직
function startCountdown() {
    let secondsLeft = 3;
    const timer = setInterval(() => {
        if (secondsLeft > 0) {
            console.log(`T-Minus ... ${secondsLeft}초`);
            secondsLeft--;
        } else {
            clearInterval(timer);
            executeLaunch();
        }
    }, 1000);
}

function executeLaunch() {
    console.log("\n=============================================");
    console.log(`[SUCCESS] ${launchConfig.systemName} 시스템 가동 및 발사 성공!`);
    console.log("=============================================\n");
}

// 프로세스 시작
runSystemCheck();
```

2. 코드를 붙여넣은 후 키보드의 `Ctrl` + `S` (Mac은 `Cmd` + `S`)를 눌러 파일을 **저장**합니다.

## Task 3. Node.js로 코드 실행하기

VS Code에 내장된 터미널을 이용해 코드를 실행합니다.

1. VS Code 상단 메뉴에서 **[Terminal(터미널)]** → <b>[New Terminal(새 터미널)]</b>을 클릭하여 하단에 터미널 창을 엽니다.
2. 터미널의 깜빡이는 커서에 아래의 명령어를 입력하고 **Enter** 키를 누릅니다.

```bash
node app.js
```

> **예상 결과:**
> 터미널 화면에 1초 간격으로 점검 메시지가 출력됩니다. 현재 코드는 고의로 실패하도록 작성되어 있으므로, <b>[FAIL]</b> 메시지들과 함께 **시스템 셧다운** 경고가 출력되고 프로그램이 종료됩니다.

### 개념 짚어보기
* `node` 명령어는 "Node.js 엔진을 사용해라"라는 명령어입니다.
* `node app.js`는 <b>"Node.js 엔진을 사용하여 현재 폴더에 있는 app.js 파일을 읽어서 실행해."</b>라는 의미를 가집니다.

## Task 4. 코드 수정하여 미션 해결하기 (Troubleshooting)

시스템이 성공적으로 가동(발사)되려면 모든 점검이 `[PASS]`를 받아야 합니다. 아직 자바스크립트의 문법을 배우지는 않았지만, 지정된 위치의 값을 직접 수정하여 에러를 해결해 볼 수 있습니다.

1. `app.js` 파일의 10~15번째 줄을 보면 다음과 같은 코드가 있습니다.

```javascript
const launchConfig = {
    systemName: "Nuri-V",
    fuelLevel: 65,           // 숫자: 최소 80 이상이어야 함
    isWeatherClear: false,   // 불리언: true 여야 함
    enginePressure: 120      // 숫자: 80 이상 ~ 110 이하여야 정상 범위
};
```
> [!NOTE] 
> 코드 오른쪽에 `//` 기호와 함께 적힌 한글은 <b>주석(Comment)</b>이라고 부릅니다. 이는 개발자가 읽기 위해 남겨둔 메모이며 컴퓨터는 이 부분을 무시하고 실행하지 않습니다.

2. 시스템이 정상적으로 통과할 수 있도록, 기존의 값을 지우고 아래와 같이 새로운 값을 입력합니다. (오직 숫자와 영어 단어만 변경합니다.)
   * `65`를 지우고 <b>`100`</b>을 입력합니다. (연료 보충)
   * `false`를 지우고 <b>`true`</b>를 입력합니다. (기상 조건 맑음으로 변경)
   * `120`을 지우고 <b>`95`</b>를 입력합니다. (엔진 압력을 정상 범위로 낮춤)

3. 값을 모두 변경했다면 반드시 `Ctrl` + `S` (Mac은 `Cmd` + `S`)를 눌러 파일을 다시 **저장**합니다. (저장하지 않으면 수정한 내용이 반영되지 않습니다.)
4. 하단의 터미널 창을 마우스로 한 번 클릭한 후, 키보드의 <b>위쪽 방향키(↑)</b>를 누릅니다.
   *(방향키 위를 누르면 이전에 입력했던 `node app.js` 명령어가 자동으로 불러와 집니다.)*
5. **Enter** 키를 눌러 코드를 다시 실행합니다.

> **예상 결과:**
> 변경한 값들이 적용되어 모든 점검 항목에서 `[PASS]`가 출력됩니다. 3초간의 카운트다운 후 <b>[SUCCESS]</b> 메시지가 나타나면 미션 완료입니다.
