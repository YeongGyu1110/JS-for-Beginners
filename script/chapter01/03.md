# 나만의 작업실 만들기: VS Code와 Node.js 설치

## 개요
이전 실습에서는 웹 브라우저의 콘솔(Console) 창을 이용해 자바스크립트를 실행해 보았습니다. 하지만 콘솔 창은 코드를 임시로 테스트하기에는 좋지만, 길고 복잡한 프로그램을 만들고 저장하기에는 적합하지 않습니다.

본격적인 개발을 위해서는 코드를 작성할 <b>전문 에디터(VS Code)</b>와 브라우저 밖에서도 자바스크립트를 실행해 줄 <b>엔진(Node.js)</b>이 필요합니다. 이번 모듈에서는 여러분의 PC를 완벽한 개발 환경으로 세팅해 봅니다.

### 준비물
* 인터넷 연결이 가능한 Windows 또는 Mac PC

### 이 모듈에서 배울 내용
* 코드 에디터(VS Code)와 런타임(Node.js)의 역할 이해
* Visual Studio Code 다운로드 및 설치
* Node.js (LTS 버전) 다운로드 및 설치 여부 확인

---

## Task 1. Visual Studio Code 설치하기

<b>Visual Studio Code(이하 VS Code)</b>는 마이크로소프트에서 만든 무료 코드 에디터입니다. 코드를 작성할 때 오타를 찾아주거나 색상을 입혀주어 전 세계에서 가장 많은 개발자가 사용하는 '코딩용 메모장'이라고 생각하면 됩니다.

1. 웹 브라우저를 열고 [VS Code 공식 홈페이지(code.visualstudio.com)](https://code.visualstudio.com/)에 접속합니다.
2. 메인 화면에 있는 **[Download]** 버튼을 클릭하여 설치 파일을 다운로드합니다. (운영체제에 맞는 버전을 자동으로 추천해 줍니다.)
3. 다운로드된 설치 파일을 실행합니다.
4. 설치 마법사의 안내에 따라 <b>[다음]</b>을 계속 눌러 설치를 완료합니다. 
   *(설치 중 체크박스가 나오는 옵션 창에서는 기본 설정 그대로 두어도 무방합니다.)*

> **예상 결과:**
> 설치 완료 후 VS Code를 실행하면, 검은색(또는 어두운 색) 배경의 **'Welcome(시작)'** 화면이 나타납니다.

---

## Task 2. VS Code 한글 패치 적용

코딩을 한다고 해서 반드시 모든 화면을 영어로 봐야 하는 것은 아닙니다. VS Code는 <b>'확장 프로그램(Extensions)'</b>이라는 기능을 통해 사용자 입맛에 맞게 다양한 기능을 추가할 수 있습니다. 

우리의 첫 번째 확장 프로그램으로 한국어 팩을 설치하여, 영어로 가득한 화면이 주는 압박감을 벗어던지고 진입 장벽을 낮춰보겠습니다.

1. VS Code 화면 좌측 메뉴 바에서 4개의 네모가 모여있는 **[Extensions(확장)]** 아이콘을 클릭합니다. 
   *(단축키: `Ctrl` + `Shift` + `X` / Mac은 `Cmd` + `Shift` + `X`)*
2. 좌측 상단에 나타난 검색창(Search Extensions in Marketplace)에 **Korean**을 입력합니다.
3. 검색 결과 중 지구본 모양 아이콘과 함께 Microsoft에서 제작한 <b>[Korean Language Pack for Visual Studio Code]</b>를 찾아 **[Install]** 버튼을 클릭합니다.
![Korean Language Pack for Visual Studio Code 확장 프로그램](script\chapter01\assets\01.png)
4. 설치가 완료되면 화면 우측 하단에 팝업 알림창이 나타납니다. 파란색의 **[Change Language and Restart (언어 변경 및 다시 시작)]** 버튼을 클릭합니다.

> **예상 결과:**
> VS Code가 자동으로 종료되었다가 다시 켜지며, 상단 메뉴(File, Edit 등)를 포함한 에디터의 모든 환경이 친숙한 **한국어**로 변경됩니다.

## Task 3. Node.js 설치하기

자바스크립트는 원래 '웹 브라우저 안에서만' 동작하는 언어였습니다. 하지만 개발자들은 자바스크립트로 웹사이트뿐만 아니라 서버나 데스크톱 프로그램도 만들고 싶어 했습니다. 그래서 브라우저에서 자바스크립트 엔진만 쏙 뽑아내어 컴퓨터에서 직접 실행할 수 있게 만든 것이 바로 **Node.js**입니다.

1. 웹 브라우저를 열고 [Node.js 공식 홈페이지(https://nodejs.org/ko/download)](https://nodejs.org/ko/download)에 접속합니다.
![Node.js 공식 설치 페이지](script\chapter01\assets\02.png)
2. **LTS**가 표시된 버전 중 원하는 버전을 선택 후, 사용중인 운영체제에 맞는 운영체제를 선택하고 <b>[설치 프로그램(.msl)]
</b>을 클릭해 다운로드합니다 
3. 다운로드된 설치 파일을 실행하고, <b>[Next]</b>를 계속 눌러 설치를 완료합니다.

> [!TIP]
> **LTS 버전이란 무엇인가요?**\
> LTS는 'Long Term Support'의 약자로, 장기적으로 안정적인 지원을 보장하는 버전입니다. 최신 기능이 포함된 'Current' 버전은 버그가 발생할 수 있으므로, 학습 및 일반적인 개발 시에는 항상 **LTS 버전**을 사용하는 것을 권장합니다.

## Task 4. 정상 설치 확인하기

두 프로그램이 내 컴퓨터에 제대로 설치되었는지 확인해 볼 차례입니다. VS Code 안에는 컴퓨터에 직접 명령을 내릴 수 있는 **'터미널(Terminal)'** 기능이 내장되어 있습니다.

1. 앞서 설치한 **VS Code**를 실행합니다.
2. 화면 상단의 메뉴 바에서 **[Terminal (터미널)]** → <b>[New Terminal (새 터미널)]</b>을 클릭합니다.
3. 화면 하단에 명령어를 입력할 수 있는 창이 나타납니다. 깜빡이는 커서에 아래의 명령어를 입력하고 **Enter** 키를 누릅니다.

```bash
node -v
```

> **예상 결과:**
> `v24.12.0` (설치한 시기에 따라 숫자는 다를 수 있음)과 같이 설치된 Node.js의 **버전 번호**가 출력됩니다.

4. 연달아 아래의 명령어도 입력하고 **Enter** 키를 누릅니다.

```bash
npm -v
```

> **예상 결과:**
> `11.6.2`와 같이 버전 번호가 정상적으로 출력됩니다. (`npm`은 Node.js를 설치할 때 자동으로 함께 설치되는 패키지 관리 도구입니다. 추수 과정에서 유용하게 쓰일 예정입니다.)
