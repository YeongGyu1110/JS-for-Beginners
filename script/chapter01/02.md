# 브라우저와 대화하기: 콘솔(Console)과 팝업

## 개요
자바스크립트를 실행하기 위해 복잡한 프로그램을 설치할 필요가 없습니다. 여러분이 매일 사용하는 웹 브라우저 안에는 이미 훌륭한 자바스크립트 실행 환경이 숨겨져 있기 때문입니다.

이번 문서에서는 직접 크롬(Chrome) 브라우저의 '개발자 도구'를 열어보고, 브라우저가 사용자에게 메시지를 전달하는 가장 기본적인 방법인 `alert`와 `confirm`을 실습해 봅니다.

### 준비물
* **Google Chrome 브라우저**가 설치된 PC 또는 노트북

### 이 모듈에서 배울 내용
* 크롬 개발자 도구(Console) 실행 방법
* `alert()` 함수를 사용해 알림창 띄우기
* `confirm()` 함수를 사용해 사용자의 선택(확인/취소) 입력받기

---

## Task 1. 개발자 도구(Console) 열기

브라우저에는 개발자들이 웹페이지의 상태를 확인하고 코드를 테스트할 수 있는 <b>개발자 도구(Developer Tools)</b>가 내장되어 있습니다. 그중에서도 **콘솔(Console)** 탭은 자바스크립트 코드를 직접 입력하고 결과를 즉시 확인할 수 있는 연습장 같은 곳입니다.

1. 크롬 브라우저를 열고 빈 페이지를 띄웁니다.
2. 키보드에서 다음 단축키를 눌러 개발자 도구를 실행합니다.
   * **Windows / Linux:** `F12` 또는 `Ctrl` + `Shift` + `J`
   * **Mac:** `Cmd` + `Option` + `J`
3. 화면 우측이나 하단에 창이 나타나면, 상단의 **Console** 탭이 선택되어 있는지 확인합니다.

> **예상 결과:**
> 화면에 `>` 기호와 함께 깜빡이는 커서가 보인다면 코드를 입력할 준비가 완료된 것입니다.

---

## Task 2. `alert()`로 알림창 띄우기

자바스크립트가 세상과 소통하는 가장 단순한 방법은 경고/알림창을 띄우는 것입니다. 이때 사용하는 명령어가 `alert` 입니다.

1. 열려있는 Console 창의 `>` 커서 옆에 아래의 코드를 붙여넣습니다.
```javascript
alert("Hello, JavaScript!");
```

2. 키보드의 **Enter** 키를 누릅니다.

> **예상 결과:**
> 브라우저 화면 중앙 상단에 <b>"Hello, JavaScript!"</b>라는 메시지와 함께 [확인] 버튼이 있는 팝업창이 나타납니다.

### 개념 짚어보기
* `alert`는 영어로 '알리다, 경고하다'라는 뜻입니다.
* 괄호 `()` 안에는 띄우고 싶은 메시지를 적습니다. 
* 이때 글자(텍스트)를 입력하려면 반드시 <b>큰따옴표(`""`)나 작은따옴표(`''`)</b>로 감싸주어야 브라우저가 문장으로 인식합니다.

---

## Task 3. `confirm()`으로 질문하기

`alert`가 일방적인 통보라면, `confirm`은 사용자에게 질문을 던지고 **예/아니오**의 대답을 들을 수 있는 명령어입니다.

1. 팝업창의 [확인] 버튼을 눌러 창을 닫은 뒤, Console 창에 아래의 코드를 붙여넣습니다.

```javascript
confirm("자바스크립트 학습이 재미있나요?");
```

2. 키보드의 **Enter** 키를 누릅니다.

> **예상 결과:**
> 이번에는 메시지와 함께 <b>[확인]</b>과 **[취소]** 두 개의 버튼이 있는 팝업창이 나타납니다.

3. 팝업창에서 **[확인]** 버튼을 클릭해 봅니다.
4. Console 창에 어떤 단어가 출력되었는지 확인합니다.

### 개념 짚어보기
Console 창을 자세히 보면 `true`라는 단어가 출력된 것을 볼 수 있습니다. 만약 <b>[취소]</b>를 눌렀다면 `false`가 출력됩니다.
* **확인 (Yes) → `true` (참)**
* **취소 (No) → `false` (거짓)**

컴퓨터는 이렇게 사용자의 선택을 `true`와 `false`라는 두 가지 데이터로 변환하여 기억합니다. 이 개념은 추후 '조건문'을 배울 때 아주 중요하게 사용됩니다.
