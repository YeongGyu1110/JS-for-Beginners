# 마크다운(Markdown) 완벽 가이드

마크다운은 텍스트 기반의 마크업 언어입니다. 학습용 블로그의 핵심이죠.

## 1. 기본 문법 알아보기
마크다운은 간단한 기호를 사용하여 텍스트를 구조화합니다.

### 1-1. 제목 (Headings)
`#` 개수에 따라 제목의 크기가 결정됩니다.

### 1-2. 강조 (Emphasis)
- **굵게** 사용하려면 `**`를 감쌉니다.
- *기울임*을 사용하려면 `*`를 감쌉니다.

## 2. 코드 블럭 작성법
개발 블로그에서 가장 중요한 코드 블럭입니다.

```javascript
function greet() {
  console.log("Hello, Markdown!");
}
```

### 2-1. 언어 지정
언어를 지정하면 Prism.js가 적절한 하이라이팅을 제공합니다.

```python
def hello():
    print("Hello from Python")
```
