# switch문

## 개요
`if ... else if`문을 사용하면 여러 개의 조건을 순차적으로 검사할 수 있습니다. 하지만 특정 변수 하나가 "A일 때, B일 때, C일 때..."처럼 **정확히 어떤 값과 일치하는지** 여러 갈래로 나누어 검사해야 할 때는 `if`문이 다소 길고 반복적으로 변할 수 있습니다.

본 문서에서는 하나의 데이터를 여러 가지 명확한 값들과 비교할 때 가독성을 크게 높여주는 제어문인 <b>`switch`문</b>에 대해 알아봅니다. `switch`문의 고유한 작동 방식과 `break`의 역할, 그리고 비교할 때 적용되는 자료형의 엄격한 규칙을 상세히 학습합니다.

### 이 모듈에서 배울 내용
* `switch`문의 기본 문법과 구조 (`switch`, `case`, `default`)
* `switch`문의 소괄호에 들어가는 표현식(Expression)의 이해
* `break` 키워드의 중요성과 생략 시 발생하는 현상 (폴스루, Fallthrough)
* 일치 연산자(`===`)를 기반으로 하는 엄격한 자료형 비교
* 의도적으로 `break`를 생략하여 여러 개의 `case`를 묶어 처리하는 기법

## 1. switch문의 기본 구조

`switch`문은 소괄호 `()` 안에 있는 <b>표현식(데이터)</b>의 값을 평가한 후, 그 결과와 정확히 일치하는 값을 가진 `case` 블록으로 점프하여 코드를 실행합니다.

* `switch (표현식)` : 검사할 기준이 되는 데이터나 식을 넣습니다.
* `case 값:` : 표현식의 결과가 이 '값'과 일치하면 이 아래의 코드를 실행합니다. (콜론 `:`으로 끝남에 주의하세요)
* `break;` : 코드를 다 실행했으면 `switch`문을 빠져나가라는 명령입니다.
* `default:` : `if`문의 `else`와 같은 역할로, 일치하는 `case`가 단 하나도 없을 때 실행됩니다. (생략 가능)

```javascript
let job = "마법사";

switch (job) {
    case "전사":
        console.log("검과 방패를 지급합니다.");
        break; // 코드가 끝났으니 switch문을 빠져나감
    case "마법사":
        console.log("마법 지팡이를 지급합니다."); // job이 "마법사"이므로 이 부분이 실행됨
        break;
    case "도적":
        console.log("단검을 지급합니다.");
        break;
    default:
        console.log("직업이 올바르지 않습니다. 기본 옷을 지급합니다.");
        break;
}
```

> [!TIP]
> `switch`의 소괄호 안에는 단순한 변수뿐만 아니라, 계산식이나 함수 등 <b>결과값이 나오는 모든 표현식</b>이 들어갈 수 있습니다. `case` 옆에 오는 값 역시 수식이 될 수 있습니다.
> ```javascript
> let a = 2;
> let b = 2;
> 
> switch (a + b) { // 4라는 결과값을 가지고 비교 시작
>     case 3:
>         console.log("결과는 3입니다.");
>         break;
>     case 4:
>         console.log("결과는 4입니다."); // 이 코드가 실행됨
>         break;
> }
> ```

## 2. 자료형의 엄격한 비교 (===)

`switch`문을 사용할 때 가장 주의해야 할 점 중 하나는, `case` 값을 비교할 때 동등 연산자(`==`)가 아닌 <b>엄격한 일치 연산자(`===`)</b>를 사용한다는 것입니다. 

즉, 값뿐만 아니라 **자료형(Type)까지 완벽하게 동일해야만** 해당 `case`가 실행됩니다. 자동 형변환이 일어나지 않습니다.

```javascript
let selectedNumber = "1"; // 문자열 "1"

switch (selectedNumber) {
    case 1: // 숫자 1 (자료형이 다르므로 일치하지 않음)
        console.log("숫자 1을 선택했습니다.");
        break;
    case "1": // 문자열 "1" (자료형까지 완벽히 일치!)
        console.log("문자열 1을 선택했습니다."); // 이 코드가 실행됨
        break;
    default:
        console.log("알 수 없는 값입니다.");
        break;
}
```
문자열(String) 값을 변환하지 않고 `switch`에서 숫자 `case`와 비교하면 영원히 일치하지 않으므로 주의해야 합니다.

## 3. break의 중요성과 의도적인 누락 (Fallthrough)

`case` 블록 안에서 코드를 실행한 뒤 `break` 키워드를 만나면 컴퓨터는 더 이상 아래를 보지 않고 `switch`문을 종료합니다. 만약 실수로 `break`를 빼먹으면 어떻게 될까요?

자바스크립트는 일치하는 `case`를 찾아 들어간 순간부터, <b>`break`를 만나거나 `switch`문이 끝날 때까지 조건 검사를 무시하고 그 아래에 있는 모든 `case`의 코드를 몽땅 실행해 버립니다.</b> 이를 프로그래밍 용어로 **폴스루(Fallthrough)**라고 부릅니다.

```javascript
let currentFloor = 2;

switch (currentFloor) {
    case 1:
        console.log("1층 문이 열립니다.");
        // break가 없지만 조건이 안 맞아서 여긴 애초에 들어오지 않음
    case 2:
        console.log("2층 문이 열립니다."); // 여기서부터 실행 시작!
        // break를 빼먹음!
    case 3:
        console.log("3층 문이 열립니다."); // 조건(3)이 안 맞는데도 실행되어 버림!
        break;
    case 4:
        console.log("4층 문이 열립니다.");
        break;
}

// 출력 결과:
// 2층 문이 열립니다.
// 3층 문이 열립니다.
```

> [!IMPORTANT]
> 초보 시절에 `switch`문을 작성할 때 `break`를 누락하여 원치 않는 코드가 쏟아져 나오는 버그를 아주 자주 겪게 됩니다. `case`를 하나 작성할 때마다 습관적으로 `break`를 세트로 작성해 주는 것이 좋습니다.

### 여러 개의 case 묶기 (의도적인 Fallthrough 활용)
`break`를 누락하면 발생하는 폴스루(Fallthrough) 현상을 역이용하면, <b>여러 개의 값을 하나의 결과로 묶어서 처리</b>할 수 있습니다. `if`문에서 논리합(`||`) 연산자를 쓰는 것과 같은 효과를 냅니다.

```javascript
let month = 4;

switch (month) {
    // 3, 4, 5월일 때는 아무 일도 안하고 밑으로 줄줄이 떨어짐(Fallthrough)
    case 3:
    case 4:  // month가 4이므로 여기서부터 진입하여 아래로 떨어짐
    case 5:
        // 결국 3, 4, 5일 때는 모두 이 코드를 만나게 됨
        console.log("따뜻한 봄입니다."); 
        break;
        
    case 6:
    case 7:
    case 8:
        console.log("더운 여름입니다.");
        break;
        
    default:
        console.log("가을 또는 겨울입니다.");
        break;
}
```
이처럼 동일한 동작을 공유하는 여러 값이 있을 때는 빈 `case`를 겹겹이 쌓아 올려 코드를 매우 깔끔하게 정리할 수 있습니다.
