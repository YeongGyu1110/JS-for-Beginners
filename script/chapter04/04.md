# 실습: 제어문을 활용한 거스름돈 계산기

## 개요
지금까지 조건문(`if`, `switch`)과 반복문(`while`, `for`)을 학습하며 프로그램의 실행 흐름을 자유자재로 제어하는 방법을 익혔습니다. 

본 실습에서는 편의점이나 마트의 포스기(POS)에서 필수적으로 작동하는 <b>'최소 화폐 개수를 구하는 거스름돈 계산 로직'</b>을 직접 구현해 봅니다. 조건문을 사용해 금액이 부족한 예외 상황을 처리하고, 한국의 최소 화폐 단위(10원)보다 작은 자투리 금액을 걸러낸 뒤, 반복문을 통해 가장 큰 지폐부터 차례대로 거스름돈을 계산하는 알고리즘을 작성해 봅시다.

### 준비물
* VS Code와 Node.js가 설치된 PC

### 이 모듈에서 배울 내용
* `if ... else`문을 활용한 결제 예외 상황(금액 부족) 처리
* 나머지 연산자(`%`)를 활용하여 반환 불가능한 자투리 금액 계산하기
* `for` 반복문과 배열을 결합하여 반복적인 계산 코드를 획기적으로 줄이기

## Task 1. 기본 변수 설정 및 예외 처리

먼저 물건의 가격과 손님이 낸 돈을 변수로 만들고, 결제가 불가능한 상황을 `if`문으로 걸러내는 방어적인 코드를 작성해 봅니다.

1. VS Code를 열고 원하는 폴더에 `change.js`라는 이름의 새 파일을 생성하세요.
2. 물건 가격과 손님이 지불한 금액을 나타내는 변수를 선언하고, 거스름돈을 계산합니다.
   ```javascript
   let price = 14320;       // 물건 가격
   let paidAmount = 50000;  // 손님이 낸 돈
   let change = paidAmount - price; // 거스름돈
   ```
3. `if`문을 사용하여 손님이 낸 돈이 부족한 경우와 정상적인 경우를 나눕니다.
   ```javascript
   if (change < 0) {
       // 거스름돈이 마이너스라면 돈이 부족하다는 뜻입니다.
       console.log(`금액이 부족합니다. ${-change}원을 더 내주세요.`);
   } else {
       console.log(`총 거스름돈은 ${change}원입니다.`);
       // 앞으로 작성할 거스름돈 계산 로직은 모두 이 else 블록 안에 작성합니다!
   }
   ```
4. 터미널을 열고 `node change.js`를 실행하여 결과를 확인하세요. `paidAmount`를 `10000`으로 바꿔서 금액 부족 메시지가 잘 뜨는지도 테스트해 봅니다.

## Task 2. 최소 단위(10원) 미만 자투리 금액 처리

한국의 현금 결제에서 최소 단위는 10원입니다. 만약 가격이 14323원이고 50000원을 냈다면, 거스름돈은 35677원이 됩니다. 이 중 7원은 현금으로 돌려줄 수 없으므로 미리 분리해 주어야 합니다. 

1. 작성해 둔 `else` 블록 안에서, 나머지 연산자(`%`)를 사용하여 1원 단위의 자투리 금액을 구합니다.
   *(10으로 나눈 나머지를 구하면 1원 단위만 딱 떨어져 나옵니다!)*
   ```javascript
   // else 블록 내부에 작성합니다.
   let unreturnable = change % 10; // 10원 단위로 나누어 떨어지지 않는 1원짜리들
   
   if (unreturnable > 0) {
       console.log(`안내: 10원 미만의 잔돈 ${unreturnable}원은 현금 반환이 불가하여 절삭합니다.`);
       change = change - unreturnable; // 거스름돈에서 자투리 금액을 뺌
       console.log(`실제 반환할 거스름돈: ${change}원`);
   }
   ```
2. `price` 값을 `14323`으로 변경한 뒤 `node change.js`를 실행해 보세요. 7원이 절삭되었다는 메시지가 뜨고 실제 반환할 거스름돈이 35670원으로 맞춰지는 것을 확인합니다.

## Task 3. for문을 이용한 화폐 개수 계산

이제 5만원권부터 10원짜리 동전까지 차례대로 나누어가며 최소한의 화폐 개수를 구해볼 차례입니다. 
이를 변수마다 일일이 작성하면 코드가 8번이나 중복되지만, 배열과 `for`문을 사용하면 단 몇 줄로 끝낼 수 있습니다.

> [!TIP]
> **Math.floor() 함수**
> 자바스크립트에서 나눗셈(`/`)을 하면 소수점까지 모두 계산됩니다. (예: `35670 / 10000` = `3.567`)
> 화폐 개수는 무조건 정수여야 하므로, 소수점을 버려주는 자바스크립트 내장 함수인 `Math.floor(계산식)`을 사용해야 합니다.

1. 이전 Task의 코드 바로 밑(여전히 `else` 블록 내부)에 한국의 화폐 단위를 내림차순으로 담은 배열을 만듭니다.
   ```javascript
   const UNITS = [50000, 10000, 5000, 1000, 500, 100, 50, 10];
   ```
2. `for`문을 사용하여 `UNITS` 배열에 들어있는 화폐 종류(총 8개)만큼 반복을 수행합니다. 
   ```javascript
   console.log("--- 거스름돈 내역 ---");
   
   for (let i = 0; i < 8; i++) {
       let currentUnit = UNITS[i]; // 현재 계산할 화폐 단위 (예: 50000)
       
       // 현재 거스름돈을 화폐 단위로 나눈 뒤 소수점을 버려 개수를 구합니다.
       let count = Math.floor(change / currentUnit); 
       
       // 해당 화폐를 1개 이상 줘야 한다면 출력하고 거스름돈을 차감합니다.
       if (count > 0) {
           console.log(`${currentUnit}원권: ${count}개`);
           
           // 이미 계산된 금액만큼 거스름돈에서 빼고, 남은 금액을 다시 저장합니다.
           // 복합 할당 연산자와 나머지 연산자를 사용하면 아주 짧게 구현할 수 있습니다!
           change %= currentUnit; 
       }
   }
   ```
3. 터미널에서 `node change.js`를 실행하여 최종 결과를 확인합니다.

> **예상 결과 (price: 14323, paidAmount: 50000 일 때):**
> 안내: 10원 미만의 잔돈 7원은 현금 반환이 불가하여 절삭합니다.
> 실제 반환할 거스름돈: 35670원
> \-\-\- 거스름돈 내역 \-\-\-
> 10000원권: 3개
> 5000원권: 1개
> 500원권: 1개
> 100원권: 1개
> 50원권: 1개
> 10원권: 2개
