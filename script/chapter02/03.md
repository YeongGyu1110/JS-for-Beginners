# 데이터의 종류: 자료형(Data Type)과 typeof

## 개요
컴퓨터에게 숫자 `1`과 문자 `"1"`은 완전히 다른 데이터입니다. 숫자는 값 더하거나 뺄 수 있지만, 문자는 글자 그대로 이어 붙여지기 때문입니다. 이렇게 프로그래밍에서 데이터의 종류를 분류하는 기준을 <b>자료형(Data Type)</b>이라고 부릅니다.

본 문서에서는 자바스크립트에서 사용하는 가장 기본적인 데이터 타입(원시형)들과 복잡한 데이터를 다루는 타입(참조형)들을 알아보고, 특정 데이터가 어떤 자료형인지 확인하는 방법을 학습합니다.

### 이 모듈에서 배울 내용
* 원시 자료형(`String`, `Number`, `Boolean` 등)
* 참조 자료형(`Object`, `Array`, `function`)
* `typeof` 연산자를 활용한 데이터 타입 확인 방법

---

## 1. 원시 자료형 (Primitive Type)

원시 자료형은 문자열이든 숫자든 한 가지만 표현할 수 있는 가장 기본적인 타입입니다.

### 숫자형 (Number)
정수, 소수점(실수), 그리고 음수를 모두 포함하는 숫자 데이터입니다. 수학적 연산(`+`, `-`, `*`, `/`)이 가능합니다.

```javascript
let age = 25;           // 정수
let temperature = -5.5; // 실수 및 음수

console.log(age + 5);   // 출력: 30
```

### 매우 큰 숫자형 (BigInt)
Number 타입은 안전하게 표현할 수 있는 최대치(9,007,199,254,740,991, 약 900경)가 정해져 있습니다. 이보다 더 큰 숫자를 다뤄야 할 때, 숫자 끝에 `n`을 붙여서 사용하는 자료형입니다. (일반적인 개발에서는 자주 사용되지 않습니다.)

```javascript
let veryBigNumber = 123456789012345678901234567890n;
```

### 문자열 (String)
텍스트 데이터를 의미합니다. 문자를 작성할 때는 반드시 <b>큰따옴표(`""`), 작은따옴표(`''`), 또는 백틱(``)</b>으로 감싸주어야 합니다. 따옴표로 감싸진 숫자는 Number가 아닌 String으로 취급됩니다.

```javascript
let greeting = "Hello";
let stringNumber = "100";

// 문자열끼리 더하면 글자가 옆으로 이어붙습니다.
console.log(stringNumber + stringNumber); // 출력: "100100" (200이 아님)
```

### 논리형 (Boolean)
오직 <b>참(`true`)</b>과 <b>거짓(`false`)</b> 두 가지 값만 가지는 자료형입니다. 주로 특정 조건이 맞는지 확인할 때 스위치처럼 사용됩니다.

```javascript
let isSystemSafe = true;
let isGameOver = false;
```

### undefined (정의되지 않음)
`undefined` 자료형는 특수합니다. 오로지 `undefined`만 `undefined`형에 속합니다.

`undefined`는 아직 값이 할당되지 않은 상태를 의미합니다. 변수를 선언했지만, 값을 할당을 하지 않았다면 해당 변수에 `undefined`가 자동으로 할당됩니다. 또한 직접 `undefined`를 할당할 수 있지만, 더 나은 `null`이 존재하기 때문에 추천하지는 않습니다.
```javascript
let emptyBox;
console.log(emptyBox); // 출력: undefined
```

### null (비어있음)
`null` 역시 `undefined`와 동일합니다. 오로지 `null`만 `null`형에 속합니다.

**빈 값**을 표현할 때 사용하는 값입니다. 기존에 들어있던 값을 지우고 싶을 때 주로 사용합니다.

```javascript
let currentTarget = "데이터들";
currentTarget = null; // 값을 의도적으로 비움

console.log(currentTarget); // 출력: null
```

## 2. 참조 자료형 (Reference Type)
원시형과 달리, **여러 개의 데이터나 복잡한 동작**을 묶어서 하나의 변수에 저장할 수 있는 타입입니다.
자세한 사용법은 이후 별도의 문서에서 깊게 다루며, 생김새만 확인하고 넘겨도 무관합니다.

### 배열 (Array)
여러 개의 데이터를 순서대로 나열하여 대괄호(`[]`) 안에 모아두고 쉼표(`,`)를 이용해 값을 분리하는 형태의 리스트입니다.

```javascript
let luckyNumbers = [7, 14, 21, 28];
```

### 객체 (Object)
이름(Key)과 값(Value)을 한 쌍으로 묶어서 중괄호(`{}`) 안에 저장하는 데이터 덩어리입니다. 특정 사물이나 사람의 정보를 묘사할 때 사용합니다.

```javascript
let userProfile = {
    name: "Hero",
    level: 99
};
```

### 함수 (Function)
반복해서 사용할 코드를 중괄호(`{}`)으로 묶어둔 작업의 단위입니다.
`function` 키워드와 함수 이름, 함수 본문으로 구성됩니다

```javascript
// 'sayHello'가 함수의 이름입니다. 변수처럼 이름을 바꿀 수 있습니다.
function sayHello() {
    // 중괄호 내부의 코드는 함수 본문(body)입니다.
    console.log("안녕하세요!");
}
```

## 3. typeof

코드를 작성하다 보면 변수 안에 들어있는 데이터가 어떤 자료형인지 확인해야 할 때가 있습니다. 이때 `typeof` 명령어를 사용합니다.

`typeof`는 두 가지 형태로 작성할 수 있으며, 결과는 완전히 동일합니다.
1. **연산자 형태:** `typeof 대상` (띄어쓰기 사용)
2. **함수 형태:** `typeof(대상)` (괄호 사용)

```javascript
console.log(typeof 100);          // 출력: "number"
console.log(typeof "Hello");      // 출력: "string"
console.log(typeof(true));        // 출력: "boolean"
console.log(typeof(undefined));   // 출력: "undefined"
console.log(typeof(null));        // 출력: "object" (!)

// 참조 자료형의 확인
console.log(typeof [1, 2, 3]);    // 출력: "object" (배열도 객체입니다.)
console.log(typeof function(){}); // 출력: "function"
```

> [!NOTE] 
> **자바스크립트의 유명한 버그: typeof null**\
> `typeof null`을 실행하면 `"null"`이 아니라 `"object"`가 출력됩니다. 이는 자바스크립트가 처음 만들어질 때 발생한 언어 자체의 설계 오류(버그)입니다. 하지만 이미 너무 많은 웹사이트가 이 버그를 바탕으로 만들어졌기 때문에, 현재까지도 고치지 못하고 그대로 유지되고 있습니다.
> ```javascript
> console.log(typeof null); // 출력: "object"
> ```
