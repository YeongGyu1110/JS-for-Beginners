# 변수와 console.log

## 개요
프로그램이 제대로 동작하려면 수많은 데이터를 기억하고, 필요할 때마다 꺼내 쓸 수 있어야 합니다. 자바스크립트에서는 이러한 역할을 '변수'가 담당합니다.

본 문서에서는 자바스크립트 코드의 기본 단위인 <b>문(Statement)</b>을 이해하고, 터미널에 데이터를 출력하는 `console.log` 명령어, 그리고 데이터를 저장하고 꺼내 쓰는 <b>변수(Variable)</b>의 생성 및 활용법을 다룹니다.

### 이 모듈에서 배울 내용
* 코드의 실행 단위인 문(Statement)의 개념과 세미콜론(`;`)의 역할
* `console.log()`를 활용한 데이터 출력
* 변수의 선언(Declaration), 할당(Assignment), 그리고 값의 호출
* 하나의 키워드로 여러 변수를 동시에 선언하는 방법

---

## 1. 문(Statement)

자바스크립트 코드는 컴퓨터에게 내리는 명령문들의 집합입니다. 이렇게 어떤 작업을 수행하도록 하는 하나의 명령 단위를 <b>문(Statement)</b>이라고 부릅니다.

사람이 글을 쓸 때 문장의 끝에 마침표(`.`)를 찍는 것처럼, 자바스크립트에서는 하나의 문(Statement)이 끝날 때마다 <b>세미콜론(`;`)</b>을 작성하여 명령이 끝났음을 엔진에게 알려줍니다.

만약 세미콜론을 적절히 사용한다면, 아래처럼 줄바꿈 없이 한 줄에 여러 명령을 작성해도 코드는 정상적으로 작동합니다. 하지만 사람이 읽기에는 가독성이 매우 떨어집니다.

```javascript
// 세미콜론이 있어 정상 작동하지만 가독성이 나쁜 코드
console.log("Hello"); console.log("JavaScript"); console.log("World");
```

반대로, 한 줄에 여러 명령을 작성하면서 세미콜론조차 생략한다면 컴퓨터는 어디서 명령이 끝났는지 알 수 없어 <b>에러(SyntaxError)</b>를 발생시킵니다.

```javascript
// 세미콜론과 줄바꿈이 모두 없어 에러가 발생하는 코드
console.log("Hello") console.log("JavaScript") // SyntaxError 발생
```

> [!NOTE]
> 최신 자바스크립트 환경에서는 <b>줄바꿈(Enter)</b>만으로도 문의 끝을 인식하는 기능(ASI)이 있습니다. 따라서 명령마다 줄바꿈을 잘 해주었다면 세미콜론을 생략해도 에러가 나지 않지만, 예상치 못한 오류를 완벽히 예방하기 위해 **명령어 끝에는 항상 세미콜론을 작성하는 습관**을 들이는 것이 좋습니다.\
> \
> 두 코드는 동일하게 작동합니다.
> ```javascript
> console.log("Hello")
> console.log("JavaScript")
> ```
> ```javascript
> console.log("Hello");
> console.log("JavaScript");
> ```

## 2. console.log()

코드 내부에서 어떤 데이터가 오가고 있는지 확인하려면 화면에 값을 출력해 보아야 합니다. 이때 사용하는 명령어가 바로 `console.log()`입니다.

괄호 `()` 안에 출력하고 싶은 텍스트, 숫자, 또는 데이터를 넣으면 해당 값이 터미널이나 콘솔 화면에 나타납니다.

```javascript
console.log(100);
console.log("데이터 출력 테스트");
```

## 3. 변수(Variable)

<b>변수(Variable)</b>는 프로그램이 실행되는 동안 데이터를 임시로 저장해 두는 '이름이 붙은 상자'입니다. 값이 저장된 상자에 이름을 붙여두면, 나중에 데이터가 필요할 때 상자의 이름만 불러서 값을 꺼내 쓸 수 있습니다.

### 선언 (Declaration)
변수를 사용하려면 먼저 상자를 만들어야 합니다. 이를 **변수 선언**이라고 하며, 자바스크립트에서는 주로 `let`이라는 키워드를 사용합니다.

```javascript
let myBox; // 'myBox'라는 이름의 빈 변수 상자를 생성
```

### 할당 (Assignment)
선언된 상자에 데이터를 넣는 과정을 **할당**이라고 합니다. 수학에서는 `=` 기호가 "같다"는 뜻이지만, 프로그래밍에서는 <b>"오른쪽의 값을 왼쪽 상자에 집어넣어라"</b>라는 뜻의 **대입(할당) 연산자**로 사용됩니다.

```javascript
myBox = 50; // myBox 변수에 숫자 50을 저장      
```

### 호출 (Reference)
변수 상자에 저장된 값을 사용하고 싶을 때는, 코드에 **변수의 이름**을 그대로 적어주면 됩니다. 컴퓨터는 코드 안에서 변수 이름을 발견하면, 해당 이름표가 붙은 상자를 열어보고 그 안에 든 **'실제 값'**으로 치환하여 명령을 실행합니다.

```javascript
let applePrice = 1000;
let bananaPrice = 2000;

// 컴퓨터는 아래 코드를 console.log(1000 + 2000); 으로 치환하여 계산합니다.
console.log(applePrice + bananaPrice); // 출력 결과: 3000
```

### 초기화 (Initialization)
실제 개발에서는 상자를 만들고 나중에 값을 넣기보다, 상자를 생성함과 동시에 초기 값을 넣는 방식을 훨씬 자주 사용합니다. 이를 **초기화**라고 합니다.

```javascript
let playerName = "Hero"; 
let playerLevel = 1;

console.log(playerName); // 출력 결과: Hero
```

### 여러 변수 한 번에 선언하기
`let` 키워드를 여러 번 쓰지 않고, 쉼표(`,`)를 사용하여 여러 개의 변수를 한 줄에 선언할 수도 있습니다.

```javascript
let score = 100, isGameOver = false, coin = 5;

console.log(score); // 출력 결과: 100
console.log(coin);  // 출력 결과: 5
```

> [!TIP]
> 쉼표를 사용한 연속 선언은 코드를 짧게 만들어 주지만, 변수의 개수가 많아지면 가독성이 떨어질 수 있습니다. 일반적으로는 한 줄에 하나의 변수만 선언하는 것이 코드를 읽고 관리하기에 좋습니다.
> ```javascript
> let score = 100;
> let isGameOver = false;
> let coin = 5;
> 
> console.log(score); // 출력 결과: 100
> console.log(coin);  // 출력 결과: 5
> ```

### 문자열과 변수 같이 출력하기
이전의 코드는 모두 변수의 값만 출력하거나, 지정된 텍스트만 출력했습니다. <b>"안녕하세요! [사용자 이름]님!"</b>처럼 일반 텍스트와 변수 같은 값을 출력하고 싶을 때는 어떻게 해야 할까요? 자바스크립트에서는 백틱(`` ` ``) 기호를 사용하는 **템플릿 리터럴** 문법을 제공합니다.

문자열을 따옴표가 아닌 백틱(키보드 1번 왼쪽의 기호)으로 감싸고, 그 안에서 `${표현식 또는 변수 이름}`을 작성하면 컴퓨터가 해당 부분을 실제 값으로 바꾸어 줍니다.

```javascript
let userName = "홍길동";
console.log(`안녕하세요! ${userName}님!`); // 안녕하세요! 홍길동님!

// 숫자 형태의 값이 담긴 변수
let currentYear = 2026;
console.log(`올해는 ${currentYear}년입니다. 내년은 ${currentYear + 1}년이에요!`); // 올해는 2026년입니다. 내년은 2027년이에요!
```

> [!NOTE]
> 템플릿 리터럴 방법을 사용하지 않고 이를 구현하는 방법도 존재합니다.\
> 더하기(`+`) **연산자**를 사용해 문자와 값을 연결시키는 방법입니다.\
> 연산자에 대한 자세한 내용은 [연산자]() 문서에서 다룹니다.
> ```javascript
> let userName = "홍길동";
> console.log("안녕하세요! " + userName + "님!");
> 
> let currentYear = 2026;
> console.log("올해는 " + currentYear + "년입니다. 내년은 " + (currentYear + 1) + "년이에요!");
> ```
