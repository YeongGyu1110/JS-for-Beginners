# 변수의 종류와 이름 짓기 규칙: let, const, var

## 개요
자바스크립트에서 변수 상자를 만드는 키워드는 `let` 하나만 있는 것이 아닙니다. 목적에 따라 `let`, `const`, `var` 세 가지 키워드를 사용할 수 있으며, 각각 작동하는 규칙이 다릅니다.

본 문서에서는 값을 변경하거나 변수를 중복해서 만들 때 발생하는 세 가지 키워드의 차이점을 코드로 직접 비교해 보고, 에러 없이 안전하게 코드를 작성하기 위한 <b>변수 이름 짓기 규칙(Naming Convention)</b>을 알아봅니다.

### 이 모듈에서 배울 내용
* 값의 변경(재할당) 가능 여부에 따른 `let`과 `const`의 차이
* 구형 변수 선언 방식인 `var`의 문제점과 피해야 하는 이유
* 에러를 발생시키는 잘못된 변수 이름 규칙
* 개발자들 사이의 변수 이름 짓기 관례 (카멜 케이스 등)

---

## 재할당

이미 값이 들어있는 변수 상자의 내용물을 버리고 새로운 값을 넣는 것을 <b>재할당(Reassignment)</b>이라고 합니다. 키워드에 따라 재할당 가능 여부가 결정됩니다.

### 값이 변할 수 있는 변수: let
`let`은 처음에 저장한 값을 언제든지 다른 값으로 바꿀 수 있습니다. 게임의 점수나 캐릭터의 체력처럼 **상황에 따라 계속 변하는 데이터**를 저장할 때 사용합니다.

```javascript
let currentScore = 10;
console.log(currentScore); // 출력: 10

// 새로운 값을 대입하여 기존 값을 덮어씌웁니다. (이때 let 키워드는 다시 쓰지 않습니다.)
currentScore = 50; 
console.log(currentScore); // 출력: 50
```

### 값이 변하지 않는 상수: const
`const`는 Constant(상수)의 약자로, 한 번 상자에 값을 넣고 뚜껑을 닫으면 **절대 안의 내용물을 바꿀 수 없습니다.** 상수는 재할당을 허용하지 않습니다.

```javascript
const birthYear = 2000;

// 이미 값이 들어있는 const 변수에 새로운 값을 넣으려 하면 에러가 발생합니다.
birthYear = 2001; // TypeError: Assignment to constant variable.
```

> [!NOTE] 
> `const`는 상자를 만들자마자 뚜껑이 닫혀버리는 특성이 있기 때문에, 변수를 선언함과 동시에 <b>반드시 값을 할당(초기화)</b>해야 합니다. 빈 상자만 만드는 것은 불가능합니다.
> ```javascript
> const myName; // SyntaxError: Missing initializer in const declaration
> ```

## 중복 선언

이미 존재하는 변수의 이름과 완전히 똑같은 이름으로 새로운 변수를 만드는 것을 <b>중복 선언(Redeclaration)</b>이라고 합니다.
`let`과 `const`는 중복 선언을 허용하지 않지만, `let`과 `const`가 등장하기 전에 쓰인 `var`은 다릅니다.

### 엄격하고 안전한 규칙: let, const
`let`과 `const`는 똑같은 이름의 상자가 두 개 이상 존재하는 것을 허용하지 않습니다. 이는 개발자가 실수로 기존 데이터를 날려버리는 것을 막아주는 훌륭한 방어막 역할을 합니다.

```javascript
let playerLevel = 5;
let playerLevel = 10; // SyntaxError: Identifier 'playerLevel' has already been declared
```

### 과거의 잔재, var
`var`는 `let`과 `const`가 등장하기 전, 과거의 자바스크립트에서 변수를 만들 때 사용하던 구형 변수 선언 키워드입니다. `var`는 <b>똑같은 이름으로 변수를 여러 번 선언해도 아무런 에러를 띄우지 않고 기존 값을 조용히 덮어씌워 버립니다.</b>

```javascript
var password = "KingGodGeneralEmperorChungmugongMajestySecretPassword1234";

var password = "0000"; // 아무런 에러 없이 기존 비밀번호가 날아가고 0000이 저장됨
```

위와 같은 특징 때문에 코드가 길어지면 치명적인 버그를 유발하기 쉽습니다. 따라서 **현대의 자바스크립트 개발에서는 `var`를 사용하지 않으며, `let`과 `const`을 사용합니다.**

## 변수 이름 짓기 필수 규칙 (문법 규칙)

변수의 이름을 아무렇게나 지을 수는 없습니다. 컴퓨터가 코드를 제대로 읽기 위해 정해둔 문법적 규칙을 어기면 <b>SyntaxError(문법 에러)</b>가 발생합니다.

1. **숫자로 시작할 수 없습니다.** (글자, `_`, `$`로만 시작 가능)
2. **대소문자를 엄격하게 구분합니다.** (`apple`과 `Apple`은 완전히 다른 상자입니다.)
3. **자바스크립트의 예약어(Reserved Word)는 사용할 수 없습니다.** (`let`, `const`, `if`, `for` 등 이미 문법으로 사용 중인 단어)

```javascript
// 올바른 변수 이름
let userName = "Hero";
let player1 = "John";
let _secretCode = 777;
let $price = 5000;

// 에러가 발생하는 변수 이름
let 1player = "John";  // SyntaxError: 숫자로 시작할 수 없음
let my name = "Hero";  // SyntaxError: 띄어쓰기 포함 불가
let let = 100;         // SyntaxError: 예약어 사용 불가
```

## 네이밍 컨벤션

문법적으로 에러가 나지는 않지만, 전 세계의 수많은 개발자들이 코드를 쉽게 읽고 협업하기 위해 암묵적으로 지키는 이름 짓기 관례가 있습니다. 자바스크립트에서는 변수의 성격에 따라 크게 두 가지 규칙을 사용합니다.

### 카멜 케이스 (camelCase)
자바스크립트에서 **일반적인 변수(`let`)나 함수 이름**을 지을 때 사용하는 가장 핵심적인 표준 방식입니다.
* 첫 번째 단어는 모두 소문자로 작성합니다.
* 두 번째 단어부터는 **첫 글자만 대문자**로 작성하여 띄어쓰기 대신 단어를 구분합니다.
* 중간에 솟아오른 대문자가 마치 낙타(Camel)의 혹 같다고 하여 붙여진 이름입니다.

```javascript
let userfirstname = "John"; // (X) 단어 구분이 안 되어 읽기 힘듦
let userFirstName = "John"; // (O) 카멜 케이스 적용
let isGameOver = false;     // (O) 카멜 케이스 적용
```

### 스크리밍 스네이크 케이스 (SCREAMING_SNAKE_CASE)
특수한 경우에 스크리밍 스네이크 케이스를 사용할 수 있습니다. 프로그램 내부에서 값 가공 없이 개발자가 직접 텍스트나 숫자로 박아 넣은 **하드코딩된 데이터**이면서, 프로그램이 끝날 때까지 <b>절대 변하지 않는 중요한 상수(`const`)</b>를 선언할 때만 예외적으로 사용하는 방식입니다.

* 모든 글자를 <b>대문자(Upper Case)</b>로 작성합니다.
* 띄어쓰기 대신 <b>언더바(`_`)</b>를 사용하여 단어를 연결합니다.

```javascript
// 프로그램 전체에서 공통으로 사용되는 중요한 하드코딩 상수
const MAX_PLAYER_LEVEL = 99;
const API_KEY = "x1y2z3-secret-key";
const ERROR_MESSAGE = "시스템에 문제가 발생했습니다.";
```

> [!TIP]
> 카멜 케이스나 스크리밍 스네이크 케이스 말고도 변수 이름을 지을 때 추가로 지켜야할 규칙이 있습니다. 변수명은 명확해야 하고, 무엇을 담고 있는지 직관적으로 나타내야 합니다.
> - 최대한 서술적이고 간결하게 명명해 주세요. `data`, `color` 같은 이름은 아무것도 설명해주지 않습니다.
>   ```javascript
>   let data;                         // 어떤 데이터인지 알 수 없음!
>   const COLOR = "RGB(10, 255, 117)" // 어떤 색상인지 알 수 없음!
>   
>   let userData = "(유저 데이터들)";
>   const COLOR_MEDIUM_PURPLE = "RGB(153, 117, 225)";
>   const COLOR_FOREST_GREEN = "RGB(24, 140, 49)";
>   ```
> - `name`, `birthday`처럼 사람이 읽을 수 있는 이름을 사용해야합니다.
>   ```javascript
>   let برمجة = "즐거운 자바스크립트 되세요!";  // 기술적으로는 문제가 없지만, 읽을 수 없기에 올바르지 않은 이름에 해당됨
>   ```
