# 사용자 입력과 연산: prompt와 형변환 실습

## 개요
지금까지는 코드 안에 직접 데이터를 입력하여 변수에 저장했습니다. 하지만 실제 프로그램은 사용자로부터 새로운 데이터를 입력받고 이를 처리할 수 있어야 합니다.

본 실습에서는 사용자의 값을 입력 받을 수 있는 `prompt` 창을 띄우고, 입력받은 데이터를 변수로 저장, 숫자로 변환하여 연산한 뒤, 템플릿 리터럴을 활용해 깔끔한 결과 문장으로 출력하는 전체 과정을 진행합니다.

### 준비물
* Google Chrome 브라우저

### 이 모듈에서 배울 내용
* `prompt()` 함수를 사용하여 사용자 입력받기
* 입력받은 문자열(String)을 숫자(Number)로 형변환하여 연산하기
* 백틱(`` ` ``)을 이용한 템플릿 리터럴로 변수와 문자열을 조합하여 출력하기

## prompt()
본 실습은 이전 문서에서 다룬적이 없는 `prompt()`함수를 사용하는 과제가 있습니다. `prompt()` 사용법을 모른다면 실습에 어려움이 있을 수 있으니 `prompt()`의 사용법에 대해 안내합니다.

`prompt()`는 [이전 문서](index.html?id=browser-console)에서 다뤘던 `alert()`, `confirm()`처럼 Node.js 환경에서 사용할 수 없고, 오로지 브라우저에서만 사용할 수 있는 함수입니다.\
`prompt()`는 `alert()`, `confirm()`과 비슷하게 창 띄우는 역할을 하며 4개의 요소로 구성되어 있습니다.

- **안내 메시지**
- 사용자의 입력을 받는 **입력 필드**
- 누르면 입력 필드에 입력된 값을 반환하는 <b>[확인]</b> 버튼
- 누르면 항상 `null`을 반환하는 <b>[취소]</b> 버튼

`prompt()`는 소괄호(`(`,`)`) 내부의 값을 안내 메시지로 출력합니다.
```javascript
prompt("나이를 입력하세요");
```

`prompt()`의 소괄호에 최대 두개의 값을 넣을 수 있습니다. 두번째 값은 기본값을 지정하는 역할을 합니다.
```javascript
prompt("나이를 입력하세요", "20");
```

## Task 2. 입력값을 숫자로 변환하고 연산하기
물건 두개를 구매하려할때 두 물건의 가격을 모두 합해 지불해야하는 총 금액을 계산해야할 것입니다.
이번 과정에서는 `prompt`를 통해 서로 다른 물건의 가격을 입력받고, 두 값을 더해 최종적으로 지불해야하는 금액을 계산합니다.


1. `price1`이라는 이름으로 변수를 선언하고 `prompt()`으로 가상의 물건의 첫 번째 가격을 입력받습니다.
2. `price2`이라는 이름으로 변수를 선언하고 `prompt()`으로 가상의 물건의 두 번째 가격을 입력받습니다.

`prompt()`의 아주 중요한 특징 중 하나는, **사용자가 숫자를 입력하더라도 무조건 문자열(String) 형태로 반환**한다는 것입니다. 값 연산을 하려면 반드시 형변환이 필요합니다.

3. `price1`에 저장된 값을 `Number`형으로 값을 변환하고 그 값을 `num1`에 저장합니다.
4. `price2`에 저장된 값을 `Number`형으로 값을 변환하고 그 값을 `num2`에 저장합니다.

이제 아래 코드를 콘솔에 붙어넣습니다. `num1`과 `num2`의 값을 더해 `totalPrice`에 저장하는 코드입니다. *`+`연산자에 대한 내용은 다음 챕터 [연산자]()에서 본격적으로 다룹니다.*
```javascript
let totalPrice = num1 + num2;
```
5. `console.log()`를 통해 `totalPrice`에 저장된 결과를 불러옵니다.

> **예상 결과:**
> 만약 1000과 2000을 입력했다면 `3000`이 출력되어야 합니다. 만약 `Number()` 변환을 누락했다면 글자가 그대로 이어 붙은 `"10002000"`이 출력될 것입니다. 결과가 올바른지 확인하세요.

## Task 3. 템플릿 리터럴로 최종 결과 출력하기

이제 Task 1에서 구한 이름(`userName`)과 Task 2에서 구한 총합(`totalPrice`)을 조합하여, 사용자에게 보여줄 최종 안내 메시지를 만들 차례입니다.

변수와 일반 텍스트를 부드럽게 이어 붙이기 위해 백틱(`` ` ``) 기호와 `${}` 문법을 사용하는 **템플릿 리터럴**을 활용합니다.

1. Console 창에 아래 코드를 입력하고 실행합니다.

```javascript
let finalMessage = `${userName}님이 구매하신 물건의 총 가격은 ${totalPrice}원 입니다.`;
```

### 테스트 및 검증

```javascript
alert(finalMessage);
```
