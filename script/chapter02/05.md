# prompt를 이용해 입력값 받기

## 개요
지금까지는 코드 안에 직접 데이터를 입력하여 변수에 저장했습니다. 하지만 실제 프로그램은 사용자로부터 새로운 데이터를 입력받고, 이를 알맞게 처리할 수 있어야 합니다.

본 실습에서는 사용자에게 값을 입력받을 수 있는 `prompt()` 함수를 활용합니다. 입력받은 데이터를 변수에 저장하고, 숫자로 변환하여 연산한 뒤, 템플릿 리터럴을 활용해 깔끔한 결과 문장으로 출력하는 '입력 → 처리 → 출력'의 전체 과정을 경험해 봅니다.

### 준비물
* Google Chrome 브라우저

### 이 모듈에서 배울 내용
* `prompt()` 함수를 사용하여 사용자로부터 데이터 입력받기
* 입력받은 문자열(String) 데이터를 숫자(Number)로 형변환하기
* 백틱(`` ` ``)을 이용한 템플릿 리터럴로 변수와 문자열을 조합하여 출력하기

## prompt()
본격적인 실습에 앞서, 사용자로부터 값을 입력받는 데 사용하는 `prompt()` 함수에 대해 알아봅니다. 

`prompt()`는 브라우저 환경에서만 사용할 수 있는 함수로, 사용자에게 텍스트 입력을 요청하는 팝업창을 띄웁니다. 창은 다음과 같은 요소로 구성됩니다.

- 사용자에게 보여줄 **안내 메시지**
- 텍스트를 입력할 수 있는 **입력 필드**
- 입력한 값을 반환하는 **[확인]** 버튼
- 입력을 취소하고 `null`을 반환하는 **[취소]** 버튼

소괄호(`()`) 내부에 문자열을 넣어 안내 메시지를 지정할 수 있습니다.
```javascript
prompt("나이를 입력하세요");
```

두 번째 값을 쉼표(`,`)로 구분하여 넣으면 입력 필드의 기본값(Default)을 지정할 수 있습니다.
```javascript
prompt("나이를 입력하세요", "20");
```

> [!IMPORTANT]
> `prompt()`를 통해 입력받은 값은 사용자가 숫자를 입력하더라도 **항상 문자열(String) 형태로 반환**됩니다. 따라서 덧셈 등의 수학 연산을 하려면 반드시 숫자로 변환(형변환)하는 과정이 필요합니다.

## Task 1. 사용자 이름 입력받기

이제 개발자 도구를 열고 직접 코드를 작성해 봅니다. *(개발자 도구를 여는 방법은 [콘솔(Console)과 팝업] 문서에서 다루었습니다.)*

1. 크롬 브라우저를 열고 빈 페이지(또는 새 탭)에서 개발자 도구의 **Console** 탭을 엽니다.
2. `userName`이라는 이름의 변수를 선언하세요.
3. `prompt()` 함수를 사용하여 `"당신의 이름을 입력하세요:"`라는 안내 메시지를 띄우고, 사용자가 입력한 값을 `userName` 변수에 할당하세요.
4. 브라우저 상단에 나타난 입력창에 본인의 이름(예: `홍길동`)을 입력하고 <b>[확인]</b>을 누르세요.
5. `console.log()`를 사용하여 `userName` 변수에 값이 잘 저장되었는지 확인하세요.

> **예상 결과:**
> 팝업창에서 입력했던 이름이 콘솔 화면에 그대로 출력되어야 합니다.

## Task 2. 물건 가격 입력받고 계산하기

물건 두 개를 구매한다고 가정해 봅시다. 두 물건의 가격을 각각 입력받고, 총합을 계산해야 합니다.

1. `price1`이라는 변수를 선언하고, `prompt()`를 사용하여 첫 번째 물건의 가격을 입력받으세요.
2. `price2`라는 변수를 선언하고, `prompt()`를 사용하여 두 번째 물건의 가격을 입력받으세요.
3. 앞서 배운 대로 `prompt()`의 결과값은 문자열입니다. `Number()`를 사용하여 `price1`의 값을 숫자로 변환하고, 그 결과를 `num1` 변수에 저장하세요.
4. 동일한 방법으로 `price2`의 값을 숫자로 변환하여 `num2` 변수에 저장하세요.
5. `num1`과 `num2`를 더한 값을 `totalPrice`라는 새로운 변수에 할당하세요. *(덧셈 기호 `+`를 사용합니다.)*
6. `console.log()`를 통해 `totalPrice`의 값을 확인하세요.

> **예상 결과:**
> 만약 가격으로 1000과 2000을 입력했다면 콘솔에 `3000`이 출력되어야 합니다. 만약 숫자 변환을 누락했다면 글자가 그대로 이어 붙은 `"10002000"`이 출력될 것입니다. 결과가 올바른지 확인하세요.
