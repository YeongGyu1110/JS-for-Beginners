# 함수 매개변수와 반환값

## 개요
전반부에서 함수는 외부 변수에 접근하여 작업을 수행할 수 있다고 배웠습니다. 하지만 함수가 무분별하게 외부 변수에 의존하게 되면, 코드가 길어졌을 때 어떤 함수가 어떤 변수를 건드렸는지 추적하기 매우 어려워져 스파게티 코드가 되기 십상입니다.

좋은 함수는 **자판기**처럼 외부와 철저히 독립되어야 합니다. 동전을 넣는 투입구와 음료수가 나오는 배출구만 있을 뿐, 자판기 내부에서 어떤 일이 일어나는지는 바깥에서 신경 쓸 필요가 없어야 합니다.

본 문서(후반부)에서는 함수 외부에서 내부로 데이터를 안전하게 전달하는 통로인 **매개변수(Parameter)와 인수(Argument)**, 그리고 함수 내부의 처리 결과를 밖으로 내뱉는 <b>반환(Return)</b>에 대해 깊이 있게 파헤칩니다.

### 이 모듈에서 배울 내용
* 함수 외부의 데이터를 내부로 전달하는 매개변수(Parameter)의 원리
* 함수를 호출할 때 괄호 안에 넣는 인수(Argument)의 개념
* 전달된 값이 없을 때를 대비하는 기본값(Default Parameter) 설정
* 함수의 실행을 즉시 멈추고 결과값을 밖으로 내보내는 `return` 키워드

---

## 4. 매개변수와 인수 (데이터 투입구)

함수가 자판기라면, 매개변수와 인수는 자판기의 **동전 투입구**와 그 구멍에 넣는 **실제 동전**입니다. 

### 매개변수 (Parameter / 파라미터)
매개변수는 함수를 **선언할 때** 소괄호 `()` 안에 적어주는 <b>임시 변수(이름표)</b>입니다. 함수 외부에서 들어올 데이터가 담길 빈 상자(지역 변수)를 미리 만들어 두는 것과 같습니다.

```javascript
// 'from', 'text' 라는 두 개의 매개변수(빈 상자)를 쉼표로 구분하여 선언합니다.
function showMessage(from, text) {
    // 함수 안에서는 이 매개변수들을 마치 일반 지역 변수처럼 사용할 수 있습니다.
    console.log(from + ": " + text);
}
```

### 인수 (Argument / 아규먼트)
인수는 함수를 **호출(실행)할 때** 소괄호 `()` 안에 실제로 집어넣는 <b>진짜 데이터(값)</b>입니다. 이 값들은 순서대로 매개변수 상자 안으로 쏙쏙 들어갑니다.

```javascript
// "Hero"라는 값(인수)은 매개변수 'from'에, "안녕하세요!"라는 값은 'text'에 전달됩니다.
showMessage("Hero", "안녕하세요!"); // 출력: Hero: 안녕하세요!

// 다른 값(인수)을 넣으면 전혀 다른 결과를 만들어냅니다!
showMessage("System", "경고: 체력이 부족합니다."); // 출력: System: 경고: 체력이 부족합니다.
```

이처럼 매개변수와 인수를 활용하면, 굳이 외부 변수에 의존하지 않고도 함수를 호출할 때마다 매번 새로운 데이터를 주입하여 재사용성을 극대화할 수 있습니다.

> [!TIP]
> **용어가 헷갈리나요?**\
> 실무에서는 파라미터, 인자, 인수, 아규먼트 등의 용어를 마구 섞어 쓰는 경우가 많습니다. 엄밀히 따지면 선언할 때의 괄호 안(이름표)은 **파라미터(매개변수)**, 호출할 때의 괄호 안(실제 값)은 <b>아규먼트(인수)</b>입니다.

## 5. 매개변수의 기본값 (Default Parameter)

함수를 호출할 때, 선언된 매개변수의 개수보다 적은 인수를 전달하면 어떻게 될까요? 에러가 나지는 않지만, 값을 받지 못한 매개변수는 `undefined`가 되어버립니다.

```javascript
function showMessage(from, text) {
    console.log(from + ": " + text);
}

// text에 해당하는 인수를 전달하지 않았습니다!
showMessage("Hero"); // 출력: Hero: undefined
```

이런 불상사를 막기 위해, 인수가 전달되지 않았을 때 대신 사용할 **기본값**을 미리 지정해 둘 수 있습니다. 매개변수 이름 뒤에 `=` 기호를 붙여서 작성합니다.

```javascript
// text에 값이 들어오지 않으면 "내용 없음" 이라는 기본값을 대신 사용합니다.
function showMessage(from, text = "내용 없음") {
    console.log(from + ": " + text);
}

showMessage("Hero"); // 출력: Hero: 내용 없음
showMessage("Hero", "반갑습니다"); // 값이 정상적으로 들어오면 기본값은 무시됨 (출력: Hero: 반갑습니다)
```

## 6. 반환 (Return / 데이터 배출구)

지금까지의 함수들은 무언가를 계산한 뒤 그 결과를 그저 `console.log()`로 화면에 띄우고 끝냈습니다. 하지만 자판기에 동전을 넣었으면 진짜 음료수 캔이 밖으로 나와야 합니다. 

함수가 계산한 결과값을 함수의 유리벽 바깥으로 던져주어, 다른 코드에서 그 값을 변수에 담아 써먹을 수 있게 해주는 것이 바로 <b>`return` (반환)</b>입니다. 

```javascript
// 두 개의 숫자를 받아(매개변수), 더한 뒤, 그 결과를 뱉어내는(return) 완벽한 자판기 함수
function sum(a, b) {
    let result = a + b;
    return result; // 계산된 result 값을 함수 바깥으로 내보냅니다!
}

// sum(10, 20) 이라는 코드는 자판기가 뱉어낸 '30' 이라는 실제 값으로 치환됩니다.
let totalScore = sum(10, 20);

// 반환된 값을 변수에 담았으므로, 자유롭게 활용할 수 있습니다.
console.log(totalScore); // 출력: 30
console.log(totalScore * 2); // 출력: 60
```

`prompt()` 함수가 사용자의 입력을 받아 문자열을 뱉어내고, `Number()` 함수가 문자를 숫자로 변환해서 뱉어내는 것도 모두 내부적으로 이 `return`이 구현되어 있기 때문입니다.

### return의 또 다른 역할: 함수 즉시 종료
`return` 키워드는 값을 뱉어내는 역할뿐만 아니라, <b>'그 즉시 함수의 실행을 멈추고 밖으로 빠져나가라'</b>는 강력한 제어 기능도 함께 가지고 있습니다. 반복문의 `break`와 아주 비슷합니다.

```javascript
function checkAge(age) {
    if (age < 18) {
        // age가 18 미만이면 false를 뱉어내고, 여기서 함수는 즉시 폭파(종료)됩니다!
        return false; 
    }
    
    // 위의 return을 만나지 않은 사람(18세 이상)만 이 코드를 실행하게 됩니다.
    console.log("성인 인증이 완료되었습니다.");
    return true; 
}

console.log(checkAge(15)); // false 출력 (콘솔 로그는 무시됨)
```

값을 반환하지 않고 단순히 함수만 멈추고 싶을 때는 값을 생략하고 `return;` 만 단독으로 사용할 수도 있습니다. 이 경우 함수는 `undefined`를 뱉어내며 종료됩니다.
