# 함수 표현식과 콜백 함수

## 개요
이전 문서에서는 `function 함수이름()` 형태로 함수를 만드는 **함수 선언문(Function Declaration)** 방식에 대해 배웠습니다. 대부분의 프로그래밍 언어에서 함수는 특별한 '동작의 묶음'으로 취급되지만, 자바스크립트는 함수를 바라보는 관점이 완전히 다릅니다.

자바스크립트에서 <b>함수는 단순한 '값(Value)'</b>입니다. 숫자나 문자열처럼 변수에 담을 수도 있고, 다른 함수에 전달할 수도 있습니다. 

본 문서에서는 자바스크립트의 이러한 독특한 철학을 바탕으로 만들어진 <b>함수 표현식(Function Expression)</b>에 대해 알아봅니다. 그리고 기존의 함수 선언문과 함수 표현식이 문법, 자바스크립트 엔진의 내부 생성 시점, 그리고 스코프(Scope) 측면에서 어떤 결정적인 3가지 차이점을 가지는지 상세히 분석합니다. 마지막으로 이 철학의 꽃이라고 할 수 있는 **콜백(Callback) 함수**의 개념까지 도달해 봅니다.

### 이 모듈에서 배울 내용
* 자바스크립트에서 함수를 일반적인 '값'으로 취급하는 특성 이해
* 변수에 함수를 할당하는 함수 표현식의 문법
* 함수 선언문과 함수 표현식의 3가지 핵심 차이점 (문법, 생성 시점, 스코프)
* 함수를 값처럼 다른 함수의 인수로 전달하는 콜백(Callback) 함수의 원리

---

## 1. 함수는 '값'이다

자바스크립트에서 함수는 숫자 `100`이나 문자열 `"Hello"`와 근본적으로 다르지 않은 <b>값(Data)</b>입니다. 단지 '소괄호 `()`를 붙이면 안의 코드가 실행될 수 있는 특별한 능력'을 가진 값일 뿐입니다.

값이기 때문에, 우리는 함수를 변수에 복사해서 담을 수 있습니다.

```javascript
function sayHi() {
    console.log("안녕하세요!");
}

// sayHi 함수 자체를 funcCopy라는 변수에 '값'으로서 복사합니다.
// 소괄호 ()를 붙이지 않았다는 점에 극도로 주의하세요! 소괄호를 붙이면 실행 결과(반환값)가 담깁니다.
let funcCopy = sayHi;

// 이제 funcCopy도 sayHi와 완전히 똑같은 능력을 가지게 되었습니다.
funcCopy(); // 출력: 안녕하세요!
sayHi();    // 출력: 안녕하세요!
```

## 2. 함수 표현식 (Function Expression) 문법

함수가 어차피 '값'이라면, 처음부터 함수를 이름 없이 만들어서 변수에 값처럼 쏙 집어넣어도 되지 않을까요? 이것이 바로 <b>함수 표현식</b>입니다.

```javascript
// 변수 sayHello를 선언하고, 그 안에 이름이 없는 함수(익명 함수)를 값으로 할당합니다.
let sayHello = function() {
    console.log("Hello!");
}; // 변수 할당문의 끝이므로 세미콜론(;)을 붙이는 것이 문법에 맞습니다.

sayHello(); // 출력: Hello!
```

형태만 다를 뿐, 결과적으로 변수 `sayHello`를 통해 함수를 호출할 수 있다는 점은 함수 선언문과 동일합니다. 하지만 이 둘은 내부적으로 아주 큰 차이점을 가지고 있습니다.

---

## 3. 함수 선언문 vs 함수 표현식의 3가지 차이점

### 차이점 1: 문법과 세미콜론
* **함수 선언문:** `function` 키워드로 시작하며, 반드시 함수의 **이름**이 있어야 합니다. 독립적인 코드 블록이므로 끝에 세미콜론(`;`)을 붙이지 않습니다.
* **함수 표현식:** 함수가 변수에 할당되는 <b>식(Expression)</b>의 일부로 존재합니다. 보통 이름을 생략(익명 함수)하며, 변수 할당문이 끝나는 것이므로 끝에 세미콜론(`;`)을 붙입니다.

### 차이점 2: 자바스크립트 엔진의 함수 생성 시점 (호이스팅)
이것이 가장 중요한 차이점입니다. 자바스크립트 엔진이 코드를 위에서부터 아래로 읽어 내려가며 실행할 때, 두 방식은 태어나는 시점이 완전히 다릅니다.

* **함수 선언문 (호이스팅 O):** 자바스크립트 엔진은 스크립트를 실행하기 **전**에, 코드 전체를 훑어보고 <b>`function` 키워드로 시작하는 함수 선언문들을 모두 찾아서 먼저 생성</b>해 둡니다. (이를 호이스팅이라고 합니다.) 따라서 함수를 선언하기 전에 위에서 먼저 호출해도 정상적으로 작동합니다.
  ```javascript
  greet(); // 정상 출력됨! (엔진이 함수를 이미 맨 위로 끌어올려 놓았기 때문)

  function greet() {
      console.log("선언문입니다.");
  }
  ```

* **함수 표현식 (호이스팅 X):** 변수에 값을 넣는 과정이므로, 실제 실행 흐름이 <b>해당 줄(해당 표현식)에 도달했을 때 비로소 함수가 생성</b>됩니다. 따라서 그 줄에 도달하기 전에는 함수를 호출할 수 없습니다.
  ```javascript
  greetExpression(); // ReferenceError: Cannot access 'greetExpression' before initialization

  let greetExpression = function() {
      console.log("표현식입니다.");
  };
  ```

### 차이점 3: 스코프 (Scope, 유효 범위)
[엄격 모드(Modern JavaScript)](https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Strict_mode) 환경에서, 코드 블록(예: `if`문의 중괄호 `{}`) 안에서 함수를 생성할 때 두 방식의 생존 범위가 다릅니다.

* **함수 선언문:** 자신이 선언된 **블록 `{}` 안에서만** 살아있습니다. 블록 바깥에서는 호출할 수 없습니다.
* **함수 표현식:** 블록 바깥에 미리 `let`으로 변수를 만들어두고, 블록 안에서 함수 표현식을 할당하면 블록 바깥에서도 함수를 사용할 수 있습니다.

```javascript
let age = 20;
let welcome; // 블록 바깥에 빈 상자(변수)를 미리 준비합니다.

if (age >= 18) {
    // 1. 함수 선언문으로 만든 함수 (이 블록이 끝나면 죽어버립니다.)
    function welcomeDeclaration() {
        console.log("성인입니다.");
    }
    
    // 2. 함수 표현식으로 만든 함수 (바깥에 있는 상자에 담았으므로 살아남습니다.)
    welcome = function() {
        console.log("성인입니다. (표현식)");
    };
}

welcomeDeclaration(); // Error! 블록 바깥에서는 선언문 함수를 찾을 수 없음
welcome(); // "성인입니다. (표현식)" 정상 출력!
```

## 4. 콜백 함수 (Callback Function)

함수가 값으로 취급된다는 사실을 응용하면 아주 놀라운 패턴을 만들 수 있습니다. <b>어떤 함수를 호출할 때, 인수(Argument)로 숫자나 문자가 아니라 '또 다른 함수'를 던져주는 것</b>입니다.

이렇게 다른 함수에 인수로 전달되어, <b>"나중에 특정 상황이 되면(조건이 맞으면) 나를 다시 불러줘(Call Back)"</b>라고 맡겨두는 함수를 **콜백(Callback) 함수**라고 부릅니다.

```javascript
// 질문(question)을 하고, 동의하면 yes 함수를, 거절하면 no 함수를 실행하는 함수
function ask(question, yes, no) {
    let answer = prompt(question);
    
    if (answer === "네") {
        yes(); // 매개변수로 전달받은 함수를 실행!
    } else {
        no();  // 매개변수로 전달받은 함수를 실행!
    }
}

// --------------------------------------------------

// 콜백 함수로 사용할 함수들을 미리 만들어 둡니다.
function showOk() {
    console.log("동의하셨습니다.");
}

function showCancel() {
    console.log("거절하셨습니다.");
}

// ask 함수를 실행하면서, 뒤의 두 인수로 '함수 값 자체(소괄호 없음!)'를 던져줍니다.
ask("이용 약관에 동의하십니까? (네/아니오)", showOk, showCancel);
```

> [!TIP]
> **익명 함수를 활용한 콜백**\
> 실무에서는 위처럼 콜백 함수를 밖에서 일일이 이름 붙여 만들지 않고, <b>함수 호출 괄호 안에 '함수 표현식'을 직접 작성(익명 함수)</b>하여 집어넣는 방식을 훨씬 더 많이 사용합니다. 코드가 훨씬 간결해지기 때문입니다.
> ```javascript
> ask(
>     "이용 약관에 동의하십니까?",
>     function() { console.log("동의하셨습니다."); }, // yes 위치에 익명 함수 전달
>     function() { console.log("거절하셨습니다."); }  // no 위치에 익명 함수 전달
> );
> ```
