# 실습: 함수형 챗봇 만들기

## 개요
함수의 선언문과 표현식, 화살표 함수, 그리고 매개변수와 반환값(return)까지 함수의 모든 핵심 개념을 학습했습니다. 함수는 코드를 깔끔하게 정리하고 재사용성을 높이는 프로그래밍의 가장 중요한 도구입니다.

본 실습에서는 Node.js 환경에서 사용자와 터미널 창을 통해 대화를 나눌 수 있는 <b>간단한 챗봇(Chatbot)</b>을 직접 구현해 봅니다. 

웹 브라우저에서는 `prompt()` 함수를 사용해 쉽게 입력을 받을 수 있었지만, 터미널(Node.js) 환경에는 사용자의 입력을 곧바로 받아오는 단순한 명령어가 기본적으로 존재하지 않습니다. 
이러한 한계를 극복하기 위해 터미널 입출력을 도와주는 `readline`이라는 내장 라이브러리를 활용합니다.
미리 준비된 라이브러리 설정 코드를 바탕으로, 여러분이 직접 배운 다양한 방식의 함수들을 조립하고 챗봇의 두뇌를 완성해 보세요.

> [!NOTE]
> **라이브러리?**\
> 라이브러리(Library)란 다른 개발자들이 복잡한 기능들을 쉽게 가져다 쓸 수 있도록 미리 만들어둔 '유용한 코드 도구 상자'를 의미합니다. 


### 준비물
* VS Code와 Node.js가 설치된 PC

### 이 모듈에서 배울 내용
* 함수 선언문을 사용한 문자열 처리 및 기본값(Default Parameter) 활용
* 화살표 함수와 조건문을 결합한 챗봇 응답 로직(두뇌) 구현
* 익명 화살표 함수를 콜백(Callback)으로 전달하여 대화의 흐름 제어하기

## 1. 터미널 입출력을 위한 라이브러리 설정

Node.js에서 터미널 입력을 받으려면 `readline` 라이브러리의 여러 가지 설정이 필요합니다. 여러분이 함수의 핵심 로직 구현에만 집중할 수 있도록, 이 설정 과정을 한 줄로 짧게 정리한 코드를 제공해 드립니다.

1. VS Code를 열고 `chatbot.js`라는 이름의 새 파일을 생성합니다.
2. 파일의 맨 윗줄에 아래의 코드를 그대로 복사해서 붙여넣습니다.

```javascript
// 터미널 입출력 설정을 위해 극단적으로 압축된 코드입니다. 분석하지 마세요!
const _=require('readline').createInterface({input:process.stdin,output:process.stdout}),ask=(q,c)=>_.question(q,c),exit=()=>_.close();
```

> [!TIP]
> **우리가 사용할 2가지 마법의 함수**
> 위 코드를 통해 우리는 복잡한 내부 구조를 몰라도 바로 사용할 수 있는 아주 유용한 두 개의 함수를 얻게 됩니다.
> 1. **`ask(질문텍스트, 콜백함수)`** : 터미널에 질문을 띄우고, 사용자가 엔터를 치면 입력한 텍스트를 콜백 함수의 인수로 전달하여 실행합니다.
> 2. **`exit()`** : 프로그램(챗봇)을 완전히 종료합니다.

## Task 2. 인사말 생성 함수 만들기 (함수 선언문)

가장 먼저 챗봇이 사용자에게 건넬 인사말을 만들어주는 함수를 작성합니다. 

1. `function` 키워드를 사용하여 `createGreeting`이라는 이름의 함수를 선언하세요.
2. 이 함수는 `userName`이라는 <b>매개변수</b>를 하나 받습니다. 만약 이름을 전달하지 않았을 때를 대비해 <b>기본값(Default)으로 `"익명"`</b>을 설정하세요.
3. 템플릿 리터럴을 사용하여 `"[챗봇] 환영합니다, userName님! 무엇을 도와드릴까요?"`라는 문자열을 만들고, 이 값을 바깥으로 <b>반환(`return`)</b>하세요.

```javascript
// Task 1 코드를 작성할 위치
function createGreeting(userName = "익명") {
    return `[챗봇] 환영합니다, ${userName}님! 무엇을 도와드릴까요?`;
}
```

## Task 3. 챗봇의 두뇌 만들기 (화살표 함수)

이제 사용자가 입력한 메시지를 분석하고 알맞은 대답을 내놓는 챗봇의 뇌를 만들 차례입니다. 코드를 짧고 깔끔하게 만들기 위해 **화살표 함수**를 사용합니다.

1. `botBrain`이라는 이름의 변수를 선언하고, <b>화살표 함수</b>를 할당하세요. 이 함수는 `message`라는 매개변수를 딱 하나 받습니다. 
2. 함수 본문(중괄호 `{}`) 안에 `if ... else if` 또는 `switch`문을 작성하여, `message`의 내용에 따라 다른 문자열을 <b>반환(`return`)</b>하도록 만드세요.
   * "안녕"이 포함된 경우 -> `"[챗봇] 안녕하세요! 좋은 하루입니다."` 반환
   * "날씨"가 포함된 경우 -> `"[챗봇] 창밖을 보세요. 저도 컴퓨터 안에 있어서 잘 모릅니다!"` 반환
   * 그 외의 모든 경우 -> `"[챗봇] 아직 배우는 중이라 무슨 말씀이신지 잘 모르겠어요."` 반환

```javascript
// Task 2 코드를 작성할 위치
const botBrain = (message) => {
    if (message === "안녕") {
        return "[챗봇] 안녕하세요! 좋은 하루입니다.";
    } else if (message === "날씨") {
        return "[챗봇] 창밖을 보세요. 저도 컴퓨터 안에 있어서 잘 모릅니다!";
    } else {
        return "[챗봇] 아직 배우는 중이라 무슨 말씀이신지 잘 모르겠어요.";
    }
};
```

## Task 4. 콜백 함수로 대화 흐름 연결하기

이제 우리가 만든 함수들과 마법의 `ask` 함수를 결합하여 실제 대화를 시도해 봅니다. 함수 안에 함수를 인수로 던져주는 **콜백(Callback)**의 강력함을 느껴보세요.

1. 파일의 맨 아래에 다음과 같이 `ask` 함수를 호출하는 코드를 작성합니다. 콜백 함수 자리에는 짧고 간결한 <b>익명 화살표 함수</b>를 직접 쑤셔 넣습니다.
   ```javascript
   ask("당신의 이름은 무엇인가요? ", (nameInput) => {
       // 사용자가 입력한 이름(nameInput)이 빈 문자열이면 undefined를 전달해 기본값("익명")이 작동하게 합니다.
       let greeting = createGreeting(nameInput || undefined);
       console.log(greeting);
   
       // 인사말이 끝나면, 다시 ask 함수를 호출하여 챗봇에게 말을 겁니다. (콜백 안의 콜백!)
       ask("챗봇에게 메시지를 입력하세요: ", (chatInput) => {
           let answer = botBrain(chatInput); // Task 2에서 만든 두뇌 함수에 입력을 전달!
           console.log(answer);
           
           exit(); // 대화가 끝났으므로 프로그램을 종료합니다.
       });
   });
   ```
2. 터미널을 열고 `node chatbot.js`를 실행하세요.
3. 이름을 묻는 창에 본인의 이름을 치거나, 엔터만 쳐서 "익명"이 잘 나오는지 확인하세요.
4. 챗봇에게 건네는 메시지로 "안녕"이나 "날씨"를 입력해 보고 챗봇이 알맞은 반응을 보인 뒤 깔끔하게 종료되는지 확인하세요.
