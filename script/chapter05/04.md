# 화살표 함수

## 개요
이전 문서에서 함수 표현식과 익명 함수를 활용하여 콜백 함수를 만드는 방법을 배웠습니다. 하지만 매번 `function`이라는 단어를 입력하고, 중괄호를 여닫고, `return`을 작성하는 과정은 코드가 길어지면 다소 번거롭게 느껴질 수 있습니다.

자바스크립트는 개발자들의 이러한 귀찮음을 덜어주기 위해, <b>기존의 함수 표현식을 훨씬 더 짧고 간결하게 작성할 수 있는 '화살표 함수(Arrow Function)'</b> 문법을 제공합니다. 

본 문서에서는 최신 자바스크립트(ES6)에서 도입되어 현재 실무에서 가장 널리 쓰이는 함수 선언 방식인 화살표 함수의 기본 문법과, 상황에 따라 코드를 극한으로 줄일 수 있는 다양한 축약 형태에 대해 학습합니다.

### 이 모듈에서 배울 내용
* `=>` (화살표) 기호를 사용한 기본적인 함수 표현식 작성법
* 매개변수 개수에 따른 소괄호 `()` 생략 규칙
* 실행할 코드가 한 줄일 때 중괄호 `{}`와 `return`을 생략하는 암묵적 반환
* 화살표 함수를 활용하여 콜백 함수를 극도로 깔끔하게 다듬는 방법

---

## 1. 화살표 함수 기본 문법

화살표 함수는 이름 그대로 <b>화살표 모양의 기호 `=>`</b> (등호 `=`와 닫는 꺾쇠 `>`의 조합)를 사용하여 함수를 만듭니다. `function`이라는 단어를 완전히 대체한다고 생각하면 이해하기 쉽습니다.

```javascript
// 1. 기존의 함수 표현식
let sum = function(a, b) {
    return a + b;
};

// 2. 화살표 함수로 변환
// function 단어를 지우고, 소괄호와 중괄호 사이에 => 를 넣습니다.
let arrowSum = (a, b) => {
    return a + b;
};

console.log(arrowSum(10, 20)); // 출력: 30
```

이렇게만 봐서는 "고작 `function` 단어 하나 없어진 것 아닌가?" 싶을 수 있습니다. 하지만 화살표 함수의 진정한 강력함은 <b>특정 조건이 맞을 때 괄호들을 생략하여 코드를 획기적으로 줄일 수 있다는 점</b>에 있습니다.

---

## 2. 화살표 함수의 축약 규칙 (더 짧게 쓰기)

화살표 함수는 매개변수의 개수와 본문 코드의 길이에 따라 소괄호 `()`와 중괄호 `{}`를 생략할 수 있는 유연한 규칙을 가지고 있습니다.

### 매개변수가 딱 1개일 때: 소괄호 `()` 생략 가능
매개변수가 하나뿐이라면, 매개변수를 감싸는 소괄호를 생략할 수 있습니다.
*(단, 매개변수가 아예 없거나 2개 이상일 때는 반드시 소괄호를 써야 합니다.)*

```javascript
// 매개변수가 1개인 경우 (n)
let double = n => {
    return n * 2;
};

// 매개변수가 아예 없는 경우 (빈 괄호를 반드시 작성해야 함)
let sayHi = () => {
    console.log("안녕하세요!");
};
```

### 코드가 딱 한 줄일 때: 중괄호 `{}`와 return 생략 가능 (암묵적 반환)
함수 본문(중괄호 안의 내용)이 단 한 줄의 코드, 즉 어떤 값을 계산해서 바로 반환하는 식(Expression)이라면 <b>중괄호 `{}` 자체를 생략</b>할 수 있습니다. 

이때 <b>`return` 키워드도 반드시 함께 생략</b>해야 합니다. 중괄호를 지우면 자바스크립트는 화살표 뒤의 결과값을 '자동으로 반환(Implicit Return)'해 주기 때문입니다.

```javascript
// 기존 화살표 함수
let double = n => { return n * 2; };

// 중괄호와 return을 생략한 극한의 축약형태!
let shortDouble = n => n * 2;

console.log(shortDouble(5)); // 출력: 10
```

## 3. 본문이 여러 줄인 화살표 함수

만약 함수 안에서 변수도 만들고, `if`문도 쓰고, 여러 가지 계산을 거쳐야 해서 코드가 여러 줄이 된다면 어떻게 해야 할까요? 

이때는 다시 <b>중괄호 `{}`를 명시적으로 열어주어야 합니다.</b> 그리고 중괄호를 열었다면, 결과값을 내보내기 위해 <b>반드시 `return` 키워드를 직접 적어주어야 합니다.</b> (중괄호를 쓰면 자동 반환이 되지 않습니다.)

```javascript
let calculateScore = (level, points) => {
    // 본문이 여러 줄이므로 중괄호 {} 를 사용합니다.
    let bonus = level * 10;
    let total = points + bonus;
    
    // 중괄호를 사용했으므로 return을 명시해야만 값이 반환됩니다!
    return total; 
};

console.log(calculateScore(5, 100)); // 출력: 150
```

> [!IMPORTANT]
> 초보자가 가장 많이 하는 실수 중 하나는 중괄호 `{}`를 열어놓고 `return`을 빼먹는 것입니다.
> ```javascript
> // 에러는 안 나지만 undefined가 반환되는 잘못된 코드
> let multiply = (a, b) => { a * b }; 
> 
> // 올바른 코드 1 (중괄호를 뺐으면 return도 뺌)
> let multiply1 = (a, b) => a * b;
> 
> // 올바른 코드 2 (중괄호를 썼으면 return도 씀)
> let multiply2 = (a, b) => { return a * b; };
> ```

## 4. 콜백 함수와 화살표 함수의 만남

화살표 함수는 함수를 값으로 만들어서 변수에 넣을 때도 좋지만, <b>다른 함수의 인수(Argument)로 함수를 직접 던져주는 '콜백 함수'를 작성할 때 진정한 빛을 발합니다.</b>

이전 문서에서 보았던 동의/거절 콜백 함수 예제를 화살표 함수로 바꿔보면 코드가 얼마나 깔끔해지는지 눈으로 확인할 수 있습니다.

**[이전 방식: 익명 함수 사용]**
```javascript
ask(
    "이용 약관에 동의하십니까?",
    function() { console.log("동의하셨습니다."); },
    function() { console.log("거절하셨습니다."); }
);
```

**[현대 방식: 화살표 함수 사용]**
```javascript
// function 단어와 중괄호가 싹 사라져서 코드가 한눈에 들어옵니다.
ask(
    "이용 약관에 동의하십니까?",
    () => console.log("동의하셨습니다."),
    () => console.log("거절하셨습니다.")
);
```

> [!NOTE]
> **화살표 함수는 만능일까요?**\
> 화살표 함수는 짧고 편리하지만, 기존의 `function` 키워드를 100% 대체하지는 않습니다. 나중에 객체(Object)나 클래스(Class) 같은 심화 개념을 배울 때 등장하는 `this`라는 아주 특별한 키워드를 다룰 때, 화살표 함수와 일반 함수는 완전히 다르게 동작합니다. 
> 지금 단계에서는 <b>"단순한 계산을 하거나 콜백 함수를 넘길 때는 화살표 함수를 쓰고, 그 외에 복잡한 구조를 짤 때는 섞어 쓸 수도 있다"</b> 정도로만 기억해 두시면 충분합니다.
