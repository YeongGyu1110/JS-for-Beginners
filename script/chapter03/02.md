# 연산자 심화

## 개요
기본적인 사칙연산만으로도 프로그램의 계산을 모두 구현할 수 있지만, 자바스크립트는 개발자가 코드를 더 짧고 간결하게 작성할 수 있도록 돕는 다양한 응용 연산자들을 제공합니다. 

본 문서에서는 변수의 값을 자신의 원래 값에 기반하여 업데이트할 때 사용하는 <b>복합 할당 연산자</b>의 작동 원리를 상세히 알아보고, 값을 1씩 올리거나 내리는 <b>증감 연산자</b>, 그리고 데이터를 컴퓨터의 가장 깊은 단위(0과 1)에서 다루는 <b>비트 연산자</b>에 대해 학습합니다.

### 이 모듈에서 배울 내용
* 일반 할당 연산자와 복합 할당 연산자(`+=`, `-=`, `*=`, `/=`)의 차이 및 작동 원리
* 값을 1씩 더하거나 빼는 증감 연산자(`++`, `--`)
* 증감 연산자의 위치에 따른 차이 (전위 연산과 후위 연산)
* 이진수 단위로 데이터를 조작하는 비트 연산자(Bitwise Operator)의 개념

---

## 1. 복합 할당 연산자 (Compound Assignment)

게임을 만들 때 캐릭터가 데미지를 입어 체력(HP)이 깎이거나, 몬스터를 잡아 경험치를 획득하는 상황을 생각해 봅시다. 이때는 완전히 새로운 값을 변수에 넣는 것이 아니라, <b>'현재 변수가 가진 값'에서 얼마를 더하거나 빼야</b> 합니다.

### 일반 할당 연산자를 사용한 값의 업데이트
일반적인 할당 연산자(`=`)만을 사용해서 체력을 20 깎으려면 아래와 같이 작성해야 합니다.

```javascript
let hp = 100;

// 현재 hp(100)에서 20을 뺀 값(80)을 계산한 뒤, 그 결과를 다시 hp 변수에 덮어씌웁니다.
hp = hp - 20; 

console.log(hp); // 출력: 80
```
이 방식의 핵심은 <b>오른쪽 수식(`hp - 20`)이 먼저 완전히 계산된 후, 마지막에 왼쪽 변수(`hp`)로 값이 할당된다</b>는 점입니다. 하지만 변수 이름(`hp`)을 두 번이나 적어야 해서 코드가 길어집니다.

### 복합 할당 연산자의 도입
개발자들은 이처럼 '자기 자신의 값에 연산을 수행한 뒤 다시 자기 자신에게 넣는' 패턴을 매우 자주 사용합니다. 이를 짧게 줄여 쓰기 위해 만든 것이 바로 <b>복합 할당 연산자</b>입니다.

연산기호와 등호(`=`)를 붙여서 작성하며, 의미는 위의 코드와 완전히 똑같습니다.

```javascript
let score = 50;

// score = score + 10; 과 완벽하게 동일한 코드입니다.
score += 10; 
console.log(score); // 출력: 60

// score = score * 2; 와 동일합니다. (현재 값 60 * 2)
score *= 2;
console.log(score); // 출력: 120

// score = score / 3; 과 동일합니다. (현재 값 120 / 3)
score /= 3;
console.log(score); // 출력: 40
```

`+=` 연산자는 숫자뿐만 아니라 **문자열을 이어 붙일 때**도 아주 유용하게 쓰입니다.

```javascript
let text = "Hello";
text += " World!"; // text = text + " World!" 와 동일
console.log(text); // 출력: "Hello World!"
```

> [!WARNING]
> **주의할 점 3가지**
> 1. **할당 연산자(`=`)는 무조건 기호 뒤에 붙여야 합니다.** 기호의 순서가 헷갈려 `=+`나 `=-`로 작성하면 복합 할당 연산자로 동작하지 않습니다. (예를 들어 `score =+ 10`이라고 쓰면, 10을 더하라는 뜻이 아니라 단순히 '양수 10(+10)을 변수에 할당하라'는 뜻이 되어 기존 값이 날아가 버립니다.)
> 2. **기호 사이에 띄어쓰기를 하면 에러가 발생합니다.** (예: `+ =` (X), `+=` (O))

## 2. 증감 연산자 (Increment & Decrement)

프로그래밍을 하다 보면 복합 할당 연산자 중에서도 <b>값을 딱 `1`만큼 더하거나 뺄 때(`+= 1` 또는 `-= 1`)</b>가 가장 빈번하게 발생합니다. (예: 방문자 수 1 증가, 남은 기회 1 감소 등)

이를 위해 자바스크립트는 1을 더하고 빼는 전용 연산자인 <b>증감 연산자(`++`, `--`)</b>를 제공합니다.

```javascript
let count = 0;

// 아래 세 줄은 모두 count의 값을 1 올려주는 완벽히 똑같은 동작을 합니다.
count = count + 1;
count += 1;
count++; // 증감 연산자를 사용한 가장 짧은 형태

console.log(count); // 출력: 3
```

### 전위(Prefix)와 후위(Postfix)의 차이
증감 연산자는 변수의 **앞에 붙이느냐, 뒤에 붙이느냐**에 따라 다른 명령과 섞여 쓰일 때 작동하는 순서가 달라집니다. (단독으로 쓰일 때는 차이가 없습니다.)

* **전위 연산자 (`++count`):** 변수의 값을 **먼저 증가**시킨 후, 그 줄의 다른 명령을 실행합니다.
* **후위 연산자 (`count++`):** 그 줄의 명령을 **먼저 실행**한 뒤, 맨 마지막에 변수의 값을 증가시킵니다.

```javascript
// 1. 전위 연산자 (증가가 먼저)
let a = 10;
console.log(++a); // a를 먼저 11로 만든 뒤 출력함 (출력: 11)
console.log(a);   // 출력: 11

// 2. 후위 연산자 (사용이 먼저)
let b = 10;
console.log(b++); // 현재 값인 10을 먼저 출력한 뒤, 뒤늦게 b를 11로 만듦 (출력: 10)
console.log(b);   // b는 이미 11이 되어있음 (출력: 11)
```

> [!TIP]
> 처음에는 이 순서가 매우 헷갈릴 수 있습니다. 코드가 복잡해지는 것을 막기 위해, 실무에서는 증감 연산자를 `console.log`나 다른 수식과 한 줄에 섞어 쓰지 않고 **단독으로 한 줄을 차지하게 작성**하는 것을 권장합니다.

## 3. 비트 연산자 (Bitwise Operators)

컴퓨터는 모든 데이터를 0과 1로 이루어진 **이진수(Binary)** 로 기억합니다. 예를 들어 숫자 `5`는 이진수로 `0101`이고, 숫자 `1`은 `0001`입니다.

지금까지 배운 연산자들이 사람이 보는 일반적인 숫자(십진수) 단위에서 계산을 했다면, <b>비트 연산자</b>는 데이터를 가장 깊은 곳의 **0과 1 단위(Bit)로 분해하여 직접 조작**하는 연산자입니다.

* **AND (`&`):** 두 비트가 모두 1일 때만 1을 반환
* **OR (`|`):** 두 비트 중 하나라도 1이면 1을 반환
* **XOR (`^`):** 두 비트가 서로 다를 때만 1을 반환
* **NOT (`~`):** 0은 1로, 1은 0으로 반전
* **시프트 (`<<`, `>>`):** 비트를 지정한 수만큼 왼쪽이나 오른쪽으로 밀어냄

```javascript
// 숫자 5 (이진수 0101)와 숫자 1 (이진수 0001)의 비트 AND 연산
// 0101
// 0001
// ----
// 0001 (십진수로 1)
console.log(5 & 1); // 출력: 1
```

> [!NOTE]
> **이걸 당장 외워야 할까요?**
> 아닙니다! 비트 연산자는 하드웨어 제어, 암호화, 화상 처리 등 극도로 높은 성능이나 세밀한 제어가 필요한 특수한 분야에서 주로 사용됩니다.
> 일반적인 웹 개발이나 입문 단계의 프로그래밍에서는 거의 사용되지 않으므로, <b>"자바스크립트에 이런 기호(`&`, `|` 등)도 있구나"</b> 정도만 눈에 익혀두고 넘어가셔도 충분합니다. 나중에 조건문에서 배울 논리 연산자(`&&`, `||`)와 기호가 헷갈리지 않게만 주의하세요.
