# 단축 평가를 활용한 로그인 및 환경 설정

## 개요
이전까지 자바스크립트의 다양한 연산자들에 대해 학습했습니다. 특히 자바스크립트의 논리 연산자(`&&`, `||`, `??`)는 단순히 참과 거짓을 판별하는 것을 넘어, 값 자체를 반환하는 특별한 기능(단축 평가)을 가지고 있습니다.

본 실습에서는 조건문(`if`문)을 전혀 사용하지 않고, 오직 **논리 연산자의 단축 평가와 비교 연산자만을 활용**하여 사용자 로그인 기능과 프로필 환경 설정 기능을 직접 구현해 봅니다. 

### 준비물
* VS Code와 Node.js가 설치된 PC

### 이 모듈에서 배울 내용
* 비교 연산자(`===`)를 활용한 데이터 일치 여부 확인
* `&&`와 `||`의 단축 평가를 결합하여 결과 메시지 출력하기
* `||`와 `??`의 차이점을 코드로 직접 확인하고 예외 상황 처리하기

## Task 1. 로그인 데이터 준비하기

가장 먼저 데이터베이스에 저장된 '기존 회원 정보'와 사용자가 로그인 창에 '입력한 정보'를 변수로 만들어야 합니다. VS Code를 열고 실습을 진행해 봅시다.

1. VS Code를 열고 원하는 폴더에 `login.js`라는 이름의 새 파일을 생성하세요.
2. 데이터베이스에 저장된 아이디와 비밀번호를 뜻하는 상수를 만듭니다. (변하지 않는 하드코딩된 데이터이므로 스크리밍 스네이크 케이스를 사용해 봅니다.)
   ```javascript
   const SAVED_ID = "admin";
   const SAVED_PW = "1234";
   ```
3. 그 아래에 사용자가 로그인 창에 입력했다고 가정할 변수를 만듭니다. (일단은 성공하는 상황을 가정하여 똑같이 작성합니다.)
   ```javascript
   let inputId = "admin";
   let inputPw = "1234";
   ```

## Task 2. 조건문 없이 로그인 기능 구현하기

이제 입력한 정보와 저장된 정보가 일치하는지 비교하고, 그 결과에 따라 로그인 성공 또는 실패 메시지를 변수에 담아보겠습니다.

1. 비교 연산자(`===`)를 사용하여 아이디와 비밀번호가 각각 일치하는지 확인하는 변수를 작성하세요.
```javascript
// 일치하면 true, 다르면 false가 저장됩니다.
let isIdMatch = (inputId === SAVED_ID);
let isPwMatch = (inputPw === SAVED_PW);
```

2. `loginMessage`라는 변수를 선언하고 `isIdMatch`와 `isPwMatch`가 모두 `true`인 경우 `"로그인 성공!"`을 `loginMessage`에 저장하세요. *(`&&`와 `??`을 사용할 수 있습니다.)*
3. 2번 코드를 확장하여 `isIdMatch`, `isPwMatch` 둘 중 하나라도 `false`라면 `"아이디 또는 비밀번호가 틀렸습니다."`를 저장하세요. *(`||`을 사용할 수 있습니다.)*

> **예상 결과:**
> 코드는 다음과 같을겁니다.
> ```javascript
> let loginMessage = (isIdMatch && isPwMatch && "로그인 성공!") || "아이디 또는 비밀번호가 틀렸습니다.";
> ```

3. 터미널을 열고 `node login.js` 명령어를 입력하여 코드를 실행해 보세요.
4. 실행 결과가 <b>로그인 성공!</b>으로 나왔다면, `inputId`나 `inputPw`의 값을 임의로 수정한 뒤 다시 실행하여 **실패 메시지**가 정상적으로 뜨는지 확인하세요.

> **예상 결과:**
> 입력값을 맞게 주었을 때는 `[로그인 시도 결과] 로그인 성공!`이 출력되고, 값을 틀리게 바꾸면 `[로그인 시도 결과] 아이디 또는 비밀번호가 틀렸습니다.`가 출력됩니다.

## Task 3. 환경 설정: || 와 ?? 의 차이 확인하기

로그인에 성공한 사용자의 프로필 이름을 화면에 띄워준다고 가정해 봅시다. 사용자가 닉네임을 설정하지 않으면 기본값으로 "Guest"를 보여주어야 합니다.

1. `login.js` 파일의 맨 아래에 다음 코드를 추가하여 사용자가 의도적으로 닉네임을 모두 지워버린(빈 문자열) 상황을 가정해 봅니다.
   ```javascript
   let userNickname = ""; // 사용자가 닉네임을 지워버림 (정상적인 데이터)
   ```
2. `||` 연산자를 사용하여 기본값을 설정해 봅니다.
   ```javascript
   let displayWithOR = userNickname || "Guest";
   console.log(`|| 연산자 사용: 환영합니다, ${displayWithOR}님!`);
   ```
3. 이번에는 `??` (Nullish 병합 연산자)를 사용하여 기본값을 설정해 봅니다.
   ```javascript
   let displayWithNullish = userNickname ?? "Guest";
   console.log(`?? 연산자 사용: 환영합니다, ${displayWithNullish}님!`);
   ```
4. 터미널에서 `node login.js`를 다시 실행하고 결과를 비교해 봅니다.

> **예상 결과:**
> * `||` 연산자 결과: **환영합니다, Guest님!** (빈 문자열 `""`을 Falsy로 인식해 기본값으로 덮어씌워버리는 버그 발생)
> * `??` 연산자 결과: **환영합니다, 님!** (빈 문자열 `""`을 정상적인 값으로 인정하여 원본을 유지함)

5. (추가 테스트) `userNickname`의 값을 `null` 이나 `undefined`로 바꾸고 다시 실행해 보세요. 이때는 두 연산자 모두 "Guest"를 출력하는 것을 확인할 수 있습니다.
