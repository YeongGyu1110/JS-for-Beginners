# 논리 연산자와 Nullish 병합 연산자

## 개요
프로그램은 상황에 따라 다른 행동을 해야 할 때가 많습니다. "로그인을 했고, 관리자 권한이 있는가?" 또는 "나이가 18세 이상이거나, 부모님의 동의가 있는가?"처럼 여러 조건을 동시에 판단할 때 사용하는 것이 <b>논리 연산자</b>입니다. 

논리 연산자를 제대로 다루기 위해서는 앞서 [자료형]과 [형변환] 챕터에서 배웠던 <b>참(`true`)과 거짓(`false`), 그리고 `Truthy`와 `Falsy` 값에 대한 이해</b>가 필수적입니다. 본 문서에서는 이러한 자료형의 특성을 바탕으로 여러 조건을 결합하거나 뒤집는 논리 연산자들, 그리고 값이 비어있을 때를 안전하게 처리해 주는 최신 문법인 Nullish 병합 연산자에 대해 학습합니다.

### 이 모듈에서 배울 내용
* NOT(`!`), OR(`||`), AND(`&&`) 연산자의 기본 논리
* 단축 평가(Short-circuit evaluation)
* Nullish 병합 연산자(`??`)
* `||`와 `??`의 차이점

---

## 1. 기본 논리 연산자

가장 기본적으로 논리 연산자는 불리언(Boolean) 값인 `true`와 `false`를 조합하거나 뒤집을 때 사용됩니다.

### 부정 연산자: NOT (!)
느낌표(`!`) 기호를 사용하는 NOT 연산자는 데이터가 가진 <b>논리값(참/거짓)을 반대로 뒤집는 역할</b>을 합니다. 변수나 데이터의 바로 앞에 붙여서 사용합니다.

* `true`는 `false`로 만듭니다.
* `false`는 `true`로 만듭니다.

```javascript
let isGameOver = false;

// 게임 오버 상태가 "아니라면(true)" 이라는 뜻이 됩니다.
console.log(!isGameOver); // 출력: true
```

NOT 연산자는 논리형(`Boolean`) 데이터가 아니더라도 사용할 수 있습니다. 이때 자바스크립트는 해당 데이터를 먼저 `Boolean`형으로 바꾼(`Truthy`나 `Falsy` 판단) 뒤, 그 결과를 반대로 뒤집습니다.

```javascript
// 0은 Falsy 값(거짓)이므로, 이를 뒤집으면 true가 됩니다.
console.log(!0); // 출력: true

// "Hello"는 Truthy 값(참)이므로, 이를 뒤집으면 false가 됩니다.
console.log(!"Hello"); // 출력: false
```

> [!TIP]
> **연달아 두 번 쓰기 (`!!`)**
> `!`를 두 번 연달아 쓰면 논리값이 두 번 뒤집히기 때문에 결국 원래의 논리값으로 돌아옵니다. 이 특성을 이용해 어떤 데이터가 `Truthy`인지 `Falsy`인지 빠르게 확인할 때(즉, 순수한 `Boolean` 타입으로 변환할 때) `!!`를 실무에서 종종 사용합니다.
> ```javascript
> console.log(!!"Hello"); // 출력: true
> ```

### 논리합 연산자: OR (||)
`||` (파이프라인 두 개, 보통 엔터키 위에 있습니다) 기호는 <b>"또는(OR)"</b>을 의미합니다. 양쪽에 있는 조건 중 **단 하나라도 참(`true`)이라면** 최종 결과가 `true`가 됩니다. 양쪽 모두 거짓일 때만 `false`가 됩니다.

```javascript
console.log(true || true);   // 출력: true
console.log(true || false);  // 출력: true
console.log(false || false); // 출력: false
```

### 논리곱 연산자: AND (&&)
`&&` (앰퍼샌드 두 개) 기호는 <b>"그리고(AND)"</b>를 의미합니다. 양쪽에 있는 조건이 **모두 참(`true`)일 때만** 최종 결과가 `true`가 됩니다. 하나라도 거짓이면 결과는 `false`입니다.

```javascript
console.log(true && true);   // 출력: true
console.log(true && false);  // 출력: false
console.log(false && false); // 출력: false

let age = 20;
let hasTicket = true;

// 나이가 18 이상 '이고', 티켓을 가지고 있어야 입장 가능
console.log(age >= 18 && hasTicket); // 출력: true
```

## 2. 자바스크립트 논리 연산자의 특별한 기능

대부분의 프로그래밍 언어에서 `&&`와 `||`는 항상 `true` 아니면 `false`만을 결과로 내놓습니다. 하지만 <b>자바스크립트에서는 진짜 원본 값 자체를 반환</b>하는 아주 특별한 기능을 가지고 있습니다. 이 연산자들은 내부적으로 데이터를 `Boolean`으로 임시 변환하여 판단(Truthy/Falsy)한 뒤, 조건이 만족되면 그 값을 바로 내뱉고 연산을 멈춥니다. 이를 <b>단축 평가(Short-circuit evaluation)</b>라고 합니다.

### OR (||) : 첫 번째 Truthy를 찾는 사냥꾼
`||` 연산자는 왼쪽부터 오른쪽으로 코드를 읽으면서 <b>가장 먼저 만나는 Truthy(참 같은 값)를 찾아서 그 원본 값을 반환</b>합니다. 만약 모두 Falsy라면 맨 마지막 값을 반환합니다.

```javascript
// "Hello"가 Truthy이므로 바로 "Hello"를 반환하고 끝냅니다.
console.log(false || "Hello" || "World"); // 출력: "Hello"

// null과 undefined는 모두 Falsy이므로 마지막 값인 "기본값"이 반환됩니다.
// 이 패턴은 변수에 값이 없을 때를 대비한 '기본값 설정'에 아주 자주 쓰입니다.
let currentName = null;
let defaultName = "이름없음";
console.log(currentName || defaultName); // 출력: "이름없음"
```

### AND (&&) : 첫 번째 Falsy를 찾는 사냥꾼
`&&` 연산자는 `||`와 반대로, 왼쪽부터 읽으며 <b>가장 먼저 만나는 Falsy(거짓 같은 값)를 찾아서 반환</b>합니다. 만약 모두 Truthy라면 맨 마지막 값을 반환합니다.

```javascript
// 0은 Falsy이므로 뒤는 더 보지도 않고 0을 반환합니다.
console.log(true && 0 && "Hello"); // 출력: 0

// 모두 Truthy 값이라면 제일 마지막 값을 반환합니다.
console.log("Apple" && "Banana" && "Cherry"); // 출력: "Cherry"
```

## 3. Nullish 병합 연산자 (??)

최신 자바스크립트에 추가된 `??` 연산자는 물음표 두 개로 표기합니다. 이 연산자는 `||`와 비슷하게 '기본값'을 설정할 때 쓰이지만, 판별하는 기준이 다릅니다.

`??` 연산자는 오직 왼쪽 값이 <b>`null` 이거나 `undefined`일 때만</b> 오른쪽 값을 반환합니다. 그 외의 값(숫자 0, 빈 문자열 등)이 들어오면 그대로 왼쪽 값을 유지합니다.

```javascript
// null이나 undefined면 오른쪽 값을 반환합니다.
console.log(null ?? "기본값");      // 출력: "기본값"
console.log(undefined ?? "기본값"); // 출력: "기본값"

// 그 외의 데이터는 그대로 반환합니다.
console.log("데이터" ?? "기본값");    // 출력: "데이터"
```

## 4. ||와 ??의 결정적 차이

이 두 연산자는 비슷한 역할을 하지만, 취급하는 '비어있음'의 범위가 다르기 때문에 실무에서 버그를 유발하는 주요 원인이 되곤 합니다.

* **`||` 연산자:** Falsy 값을 모두 건너뜁니다. (`0`, `""`, `NaN`, `false`, `null`, `undefined` 모두)
* **`??` 연산자:** 오직 Nullish 값만 건너뜁니다. (`null`, `undefined` 두 개만)

### 어떤 문제가 발생할 수 있을까요?
게임을 만들 때 플레이어의 점수가 `0`점인 상황을 생각해 봅시다. `0`은 엄연히 유효한 데이터입니다. 하지만 `||` 연산자를 사용하면 `0`을 Falsy(비정상적인 빈 값)로 취급해버려 문제가 생깁니다.

```javascript
let playerScore = 0; // 플레이어가 게임을 못해서 0점을 받음!

// 1. || 를 사용했을 때의 대참사
// playerScore가 0(Falsy)이므로 건너뛰고 기본값인 100을 할당해 버립니다.
let finalScore1 = playerScore || 100; 
console.log(finalScore1); // 출력: 100 (0점이 100점으로 조작됨!)

// 2. ?? 를 사용했을 때의 올바른 처리
// ??는 null이나 undefined가 아니면 무조건 원본을 보존합니다. 0은 유효한 값으로 인정받습니다.
let finalScore2 = playerScore ?? 100;
console.log(finalScore2); // 출력: 0 (정상 유지됨)
```

> [!TIP]
> **결론: 언제 무엇을 써야 할까요?**
> * 숫자 `0`이나 빈 문자열 `""`도 **정상적인 데이터로 인정해야 한다면** 무조건 `??`를 사용하세요.
> * `0`이나 `""`조차도 비정상적인 값으로 간주하고 다른 값으로 덮어씌우고 싶을 때만 `||`를 사용하세요. 최근 개발 트렌드에서는 예기치 못한 버그를 막기 위해 변수의 기본값을 설정할 때 가급적 `??`를 사용하는 것을 권장합니다.
